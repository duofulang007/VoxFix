The ten SVG files named logical-pixels, physical-pixels, refresh-capture, recording-cursor,
and screenshot-region-{add,reduce,curved,freehand,polyline,rectangle} are unmodified originals.
Their Git blob hashes were checked against the pinned commit tree before conversion.
The corresponding snow_*.xml drawables preserve path geometry, fill rules and stroke widths;
SVG rounded rectangles are represented by Android paths. currentColor becomes tintable white.

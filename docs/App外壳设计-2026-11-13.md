# VoxFix 输入法 · App 外壳设计（2026-11-13）

> 把「真机验证宿主 + 输入法 + 无障碍悬浮工具」封装为正式 App 的设计基线。
> 视觉语言取自 Snow Shot 1.1.8（固定提交 `afdc340b…`，Ant Design Qt 令牌），
> 信息架构按手机重排，新增模块开关体系。

## 1. 定位与信息结构

一句话：**一个能截图的输入法**。首页必须在一屏内回答三件事——能不能用、能干什么、哪些开着。

底部四栏（已确认）：

| 栏 | 职责 | 对应原版页面 |
|---|---|---|
| 首页 | 就绪状态 + 四个动作 + 已启用模块 + 最近剪贴板 | 无（手机新增的总览页） |
| 屏幕 | 贴边弧线、截图与标注、录屏、识别与翻译、截图历史 | 截图历史 / 翻译 / 贴图管理（合并） |
| 输入 | 键盘、语音、剪贴板、表情、个人词库 | 功能设置中的输入相关项 |
| 设置 | 模块管理、外观、存储、权限、关于 | 界面设置 / 存储与隐私 / 系统设置 / 关于 |

子页：模块管理（挂在设置下，回退到设置）。

## 4. 模块开关体系

### 4.1 模型

```kotlin
enum class Module(val key: String, val defaultOn: Boolean, val parent: Module? = null) {
    VOICE("voice", true),
    DICTIONARY("dictionary", true, VOICE),      // 个人词典
    EMOJI("emoji", true),
    SCREENTEXT("screentext", true),
    SCREENSHOT("screenshot", true, SCREENTEXT),
    SCROLL("scroll", true, SCREENSHOT),         // 长截屏
    WATERMARK("watermark", true, SCREENSHOT),
    RECORD("record", true, SCREENSHOT),
    TRANSLATE("translate", false, SCREENTEXT),  // 默认关：需下载 462MB
    CLIPBOARD("clipboard", true),
    PCSYNC("pcsync", false, CLIPBOARD),         // 电脑同步
}
```

- 存储：`SharedPreferences("voxfix-modules")`，键 `m.<key>`，`schema=1`，首启写默认值。
- `isOn(ctx, m)` = 自身 && 全部祖先。
- `set(ctx, m, on)`：关闭时级联关闭子项；置位后 `sendBroadcast(ACTION_MODULE_CHANGED)`。
- 键盘本身不设开关（核心）。只允许换布局。
- 翻译默认关：模型不进包，开关默认值按真实可用状态取「关」。

### 4.2 语义

| 行为 | 规则 |
|---|---|
| 关闭 | 隐藏全部入口（键盘菜单、截图工具条、首页卡片、子页） + 不初始化运行时；**数据保留** |
| 打开 | 立即恢复入口；运行时下次使用时按需加载 |
| 父项关闭 | 子项整行 45% 禁用；点子项提示「需同时开启『父项』」并可一键开启 |
| 关闭父项 | 二次确认，列出将一并关闭的子项 |
| 恢复默认 | 模块管理页底部 |

### 4.3 生效点

| 位置 | 改动 |
|---|---|
| `VoxFixImeService.prewarmEngine()` / `beginVoice()` | 前置 `if (!Modules.isOn(this, VOICE)) return` |
| `VoxFixImeService.KeyboardBridge` | 新增 `@JavascriptInterface fun modules(): String`（JSON） |
| `preview/app.mjs` | 按 `VoxFixIme.modules()` 过滤功能菜单项与长按空格手势 |
| `ScreenshotToolbarState.visible(action)` | TRANSLATE / RECORD / SCROLL / WATERMARK 加门控；**加默认参数 `gate: ModuleGate = ALL_ON`**，保住 463 项 JVM 测试 |
| `ScreenTextService.showHandle()` | 增加 `Modules.isOn(SCREENTEXT)`；监听 `ACTION_MODULE_CHANGED` 立即重算（复用现有 3 处 `enabled()` 判断位置） |
| `HomeActivity` / 模块管理页 | 读取同一份状态驱动卡片灰态与计数 |

## 5. 应用图标

构成：**四角取景框（500/1024，线宽 42，臂长 104）+ 居中 V（宽 224，笔画 54，圆头）**。
不用闭合方框——闭合方框 + V 在小尺寸会被读成「勾选框」；四角框是截图/扫描的通用符号，也与应用内「取字」图标一致。

三套底色：**已定 C `#FFFFFF` 白底黑标**（A 蓝底 / B 近黑保留在 `design/icon/` 里备查）。

# App 外壳视觉 v2（2026-11-15）

> 触发：用户在真机上直接指出「你确定这个是用户使用界面吗？没有一点设计感」「图标很多错位了，
> 导航栏图标和底色错位」，并要求补交互动画、按可商业化成品打磨。
> 本文记录诊断、令牌、组件、动画与验收，作为外壳视觉的唯一依据；v1（Ant Design 令牌）作废。

---

## 1. 诊断：为什么会像调试工具

v1 直接采用 Snow Shot 1.1.8 的 Ant Design Qt 令牌，那是**桌面后台管理面板**的语言：

| 现象 | 根因 |
|---|---|
| 灰底 + 白卡 + 1dp 描边 + 10 圆角 | Ant Design 卡片在桌面上成立，手机上像配置面板 |
| 22/15/12.5 三档字号几乎同权 | 层级靠颜色深浅，不靠尺度 |
| 每页只有 2–3 张卡，下面 2/3 空白 | 信息架构只有「列表」，没有总览与图形表达 |
| 绿字状态（已连接/已启用）与蓝色导航并存 | `success` 被当装饰色，语义色没有软底承载 |
| 键盘 accent 是 `#4a86c8`，外壳是 `#1677FF` | 同一产品两种蓝 |
| 底栏图标相对胶囊偏左上 | 图标自带 `LinearLayout.LayoutParams`，`FrameLayout.addView` 转成默认左上角 |
| 行尾箭头被压扁 | 给 17dp 的 ImageView 加 8dp 左 padding，实际绘制区只剩 9dp |
| 开关轨道是浅蓝 | 平台 Switch 的轨道底图自带半透明，染主色后必然发灰 |

结论：**不是实现糙，是视觉基线选错了**（桌面工具令牌 + 纯文字列表），外加三处布局参数错误。

## 2. 设计令牌 v2

原则：与键盘同源的中性墨色 + 单一钢蓝 accent + 低饱和语义色；不再引第二套色系。

| 令牌 | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `bg` | `#F1F4F8` | `#0E1216` | 页面画布 |
| `surface` | `#FFFFFF` | `#161C22` | 卡片 |
| `surfaceSunken` | `#EDF1F6` | `#121820` | 输入框、图标砖底、进度轨道 |
| `border` | `#0E243A14` | `#1FFFFFFF` | 分隔线、图标砖细边 |
| `textPrimary` | `#111820` | `#E9EFF5` | 标题/正文 |
| `textSecondary` | `#59646F` | `#A5B0BB` | 次行说明 |
| `textTertiary` | `#8A949F` | `#79848F` | 分组标题/页脚 |
| `primary` | `#2F6EA8` | `#7CB6E0` | 选中、主按钮、进度 |
| `primarySoft` | `#E6F0F9` | `#1A2B39` | 图标砖/胶囊/胶囊选中底 |
| `onPrimary` | `#FFFFFF` | `#0E1216` | 主色块上的文字（深色必须换深字） |
| `success` | `#177A50` | `#58C795` | 已连接/已完成 |
| `warning` | `#9A6413` | `#E3B369` | 未授权/未就绪 |
| `danger` | `#B5483C` | `#E8907F` | 删除 |

accent 取键盘 `--accent: #4a86c8` 压深一档得到 `#2F6EA8`（白底 13sp 对比度 ≥ 4.5:1）；
深色反过来提亮到 `#7CB6E0`，主按钮文字必须用 `onPrimary` 的深色，否则白字糊在浅蓝上。

## 3. 几何与组件

- 页边距 **20**；卡片间距 **12**；卡片圆角 **18**，1dp 抬升，`clipToOutline`（水波纹裁进圆角）。
- 行高 ≥ **58**，行内距 18/11；图标砖 **34dp / 11 圆角 / 19dp 图标**。
- 顶栏：返回圆钮 **44dp**（含 12dp 内距）+ 标题 **24sp**（首页 29sp 品牌字）+ 可选 12.5sp 副标题。
- 分组标题 13sp、字距 0.04、tertiary；页脚说明改「小图标 + 一句话」（`hintRow`），不再整段灰字。
- 状态一律用 `pill`（12sp 软底同色字），禁止再写「绿色小字」。
- 首页 hero：`primarySoft → surface` 渐变卡 + 62dp 就绪环 + 一句状态 + 唯一主按钮（按缺口动态换文案：
  启用输入法 / 设为默认 / 试用键盘）。
- 快捷入口 4 砖等宽，全部指向真实页面；不放假入口。
- 底栏：54dp 项高，46×28 选中胶囊（`primarySoft`）+ 22dp 图标 + 11.5sp 文字，选中加粗。

自绘块（`ui/VoxFixBlocks.kt`，全部 Canvas，不引依赖）：

| 类 | 作用 |
|---|---|
| `StatusRing` | 就绪环：轨道 + 主色弧 + 中心 `3/3`，进场 520ms 扫过 |
| `MeterBar` | 6dp 进度条，480ms 补间（模块比例、下载进度共用） |
| `KeyboardPreview` | 三行字母键 + 空格麦克风缩略图，首页/输入页说明「这是输入法」 |
| `ArcPreview` | 屏框 + 三条内容线 + 右缘弧线把手（带 18dp 让位槽，避免弧被卡片裁成半个 C） |
| `VxSwitch` | 44×26 自绘开关：实色轨道 + 白拇指 + 170ms 缓动；无障碍声明为 `android.widget.Switch` |

新增图标（1.75 线性，与既有 `ic_vx_*` 同风格）：`ic_vx_book`、`ic_vx_mark`（品牌标记）、
`ic_vx_plus`、`ic_vx_upload`。

## 4. 交互动效

| 场景 | 动效 | 参数 |
|---|---|---|
| 切 tab | 页面淡入 + 10dp 上浮 | 220ms `Decelerate` |
| 选中胶囊 | 0.74 → 1 回弹 | 200ms `Decelerate` |
| 就绪环 | 0 → 目标比例扫过 | 520ms `Decelerate` |
| 进度条 | 0 → 目标比例 | 480ms `Decelerate` |
| 自绘开关 | 轨道混色 + 拇指位移 | 170ms `Decelerate` |
| 返回钮 / 快捷砖 | 按下 0.97、抬手回 1 | 90ms / 160ms |
| 二级页进出 | 淡入 + 4% 上浮；返回淡出 + 3% 下沉 | 主题 `VoxFixWindowAnimation`，页面不再各写 transition |

动效只做「状态变化」，不加循环呼吸、不加装饰性动画；`prefers-reduced-motion` 级别的手势在原生侧
由系统动画缩放接管（开发者选项关动画即时生效）。

## 5. 本轮修掉的具体错位

1. **底栏图标偏左上**：`FrameLayout.addView(icon)` 会把 ImageView 自带的 `LinearLayout.LayoutParams`
   转成默认左上角；改为显式 `FrameLayout.LayoutParams(22,22, Gravity.CENTER)`。
2. **行尾箭头被压扁**：17dp 图标 + 8dp 左 padding；改为 24dp 盒子 + 17dp 图标居中。
3. **开关发浅**：平台 Switch 轨道底图带 alpha；换 `VxSwitch` 自绘。
4. **深色主按钮白字**：新增 `onPrimary`，深色用深字。
5. **弧线示意被裁**：屏框右侧留 18dp 让位槽，弧线不再被卡片边界切掉。
6. **品牌图标白底套白底**：设置/关于页改用 `primarySoft` 品牌砖 + `ic_vx_mark`。
7. **卡片水波纹露直角**：`clipToOutline = true`。

## 6. 页面级改动

- 首页：hero（就绪环 + 动态主按钮）→ 快捷入口 4 砖 → 就绪状态 3 步（对勾/序号徽标 + 胶囊）→
  功能管理（进度条）→ 隐私提示行；电脑辅助一键切换降级为末行。
- 屏幕：贴边弧线预览卡（弧线 + 开关 + 恢复 + 权限）→ 截图与取字入口。
- 输入：键盘缩略图卡（试用按钮）→ 语音输入卡（自绘开关）→ 词库两行。
- 设置：品牌头卡 → 模块管理（进度条）→ 权限（输入法/屏幕取字胶囊）→ 关于 →（开发者模式可选）。
- 二级页：截图设置加图标砖/状态胶囊/危险色图标；工具栏画布收进 18 圆角深色卡；
  拼音词库压缩说明、四个动作行加图标；关于页改品牌头 + 版本/更新日志分卡；统一 `hintRow` 页脚。

## 2. 修改与兼容边界

- 新建 `ScreenshotPenControls`，只替换画笔及已选画笔对象的样式界面。描边、线宽、填充依次排列；控件可见尺寸28dp、间距4dp，手机按组换为三行，各行能横滚，触摸热区扩展不改变图标大小。这属于手机排布适配，不能说原版桌面本来就是三行。
- 预设线宽改图形预览；新增当前线宽循环、描边弹出选项与三种填充预览。保留可访问名称，其他工具继续使用既有控件。
- `ScreenshotDrawingStyle` 增加 `strokePattern` 和 `fillPattern`，默认均为 `SOLID`；参数记忆与工程编解码同时覆盖。旧文档缺字段按原实线／实心默认读取，不更改工程版本和存储修订协议。
- 新建 `ScreenshotPenRendering`，线型和填充只用于画笔，使用独立 Paint，避免污染后画的箭头、高亮或滤镜。预览和导出共用此实现；闭合填充内部可被对象选择命中。
- 截图和贴图编辑器都复用 `ScreenshotDrawingControls`，因此两处进入同一画笔控件与渲染路径；不是只给截图增加一套不能重开的效果。
- 保留已有触摸折线几何、对象编号、撤销历史和框外起笔／框内导出约定。曲线算法后续需要带兼容标记处理，避免重开旧笔画时外形突然改变。

影响项：T06／T07 历史、T17 工程、T22 选择、T24 贴图，以及共享样式／渲染路径的其他绘图工具。没有改键盘、语音、网页、OCR／翻译模型和用户布局。

### 5.2 本轮修改

- 重写 `ScreenshotColorPanel`：面板 6dp 内边距、8dp 圆角、`#1F1F1F`；SV 区按内容宽 0.73 比例（原版 224×163），色相／透明度改为整宽 8dp 圆角轨（不再使用 6dp 内缩与 16dp 高条）；右侧 28dp 方块既是当前色预览也是滴管入口（原版 previewContent 语义）；格式行 28dp，字段 `#111111` 底＋`#3A3A3A` 1dp 边＋4dp 圆角，HEX／RGB／HSB 切换与百分比输入在同排。

### 5.5 与原版的已知差异（不计为完成）

1. 原版采样源是冻结的截图原图（`display->image`），当前手机实现把已绘对象一起纳入采样：所见即所取，且能在对象上取色。属有意差异，需用户确认保留。
2. 原版放大镜跟随悬停指针并移动，手机没有悬停，改为按住拖动松手取色；面板位置与间距按原版数值。

4. 绘制几何平滑（点过滤／简化／Catmull-Rom／端点接续）与纹理 4 倍采样仍未移植，沿用第 1–4 节结论。

## 6. 第三轮：点稳定、简化与 Catmull-Rom（2026-11-04 晚）

第 5.5／5.7 节把“绘制平滑”列为 T08 唯一的技术缺口；本节补齐它。父项仍是**实现中**：纹理 4 倍采样、同尺度叠图和真人手感没做。

### 6.1 原版依据（固定提交 `afdc340b`）

| 原版文件 | 采用的事实 |
| --- | --- |
| `snow_draw_engine_core/src/stroke.rs` | `StrokePointFilter`：按距离重采样（与事件频率无关）、自适应响应 `0.18–0.82`、第二级固定极点 `0.5`、`settle_endpoint` 把末样本钉到真实抬手点 |
| `free_draw_workflow.rs`（`StreamingFreeDrawBuilder::new`） | `sample_spacing=clamp(w*0.03, 0.75, 1.5)/zoom`、`response_distance=max(w*0.35, 6)/zoom`、`rdp_tolerance=clamp(w*0.06, 0.35, 1.25)/zoom`、`closure_radius=max(10, w*0.5)/zoom`；`MAX_PENDING_SAMPLES=128`、`PENDING_OVERLAP=4` |
| `free_draw_workflow.rs`（`finish`／`simplify_rdp`） | 收尾先 settle 再 flush；闭合判定要求简化后顶点 ≥4、首尾距离 ≤ 闭合半径，命中则**丢掉末顶点**再标记 closed；无移动的点击补一段 `1e-3` 的短段当圆点 |
| `snow_draw_engine_core/src/path.rs`（`catmull_rom_path_commands`） | 向心参数化 Catmull-Rom 转三次贝塞尔；开放端缺邻居时用 `reflect` 镜像，退化弦长回退直线段 |

手机没有相机缩放，`zoom` 取 1，因此公式里只剩 `w`（位图像素宽度）。按本机密度折算后的实测值：`w=5.25px` → 间距 0.75、响应 6、容差 0.35、闭合半径 10；`w=40px` → 1.2／14／1.25／20（`tuningMatchesOriginalScreenSpaceFormulas` 断言）。

### 6.2 本轮修改

- 新增 `ScreenshotStrokeGeometry.kt`：`Filter`（稳定器）、`simplify`（RDP，同样的栈式扫描与严格 `>` 比较）、`buildPath`（向心 Catmull-Rom → `cubicTo`）、`Tuning`，以及流式构建器 `PenStrokeBuilder`（committed 前缀 + 128 样本窗口 + 4 重叠，`preview()` 与 `finish()` 共用同一条简化路径）。

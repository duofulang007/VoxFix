## 2. 本轮修改

- `ScreenshotDrawingStyle` 新增 `shape: ScreenshotRectangleShape`，默认 `RECTANGLE`；工程编解码与工具参数记忆同时覆盖。旧工程没有该键 → 读成矩形，外观不变。
- 新增 `ScreenshotShapeRendering`：`path(shape, box)`（矩形 `addRect`／椭圆 `addOval`／菱形四点闭合）、`fill(...)`、`draw(...)`、`contains(...)`、`strokeContains(...)`。填充纹理从 `ScreenshotPenRendering` 抽到此处共用，画笔的填充输出未变（同一函数、同一参数）。
- 渲染器：`RECTANGLE` 分支改为按 `style.shape` 走 `ScreenshotShapeRendering.draw`；命中改为**路径级**——`outline` 只判描边带，`outline=false` 判「内部或描边带」。椭圆／菱形的包围盒角落不再误命中；矩形内部与边线的命中与旧行为一致（原为「不在内缩矩形内即命中」，现为「在内部或描边带内」，选择流程仍是先 outline 再 body，测试全过）。
- 新增 `ScreenshotShapeControls`：形状三选一（用原版图标矢量化的 `snow_shape_{rectangle,ellipse,diamond}.xml`，选中蓝框）→ 描边色＋线型 → 线宽 → 填充色＋四档填充。行结构与 `ScreenshotPenControls` 一致（28dp 格、横向滚动、`ScreenshotTouchTargets` 扩热区）。
- `ScreenshotDrawingControls`：`RECTANGLE` 走新的形状控件；高亮／滤镜／箭头／文字等其余工具仍走原逻辑。
- 顺带修掉一个共享 paint 的隐患：`drawStroke` 开头清 `pathEffect`，避免上一笔的虚线滴到下一个箭头／矩形。
- 新资源：`res/drawable/snow_shape_{rectangle,ellipse,diamond}.xml`；原版 SVG 归档在 `assets/licenses/snow-shot/icons/`。

## 7. 等比约束＝Shift 修饰键，判为桌面专属（2026-11-07）

- **上游依据**（固定提交）：`editor-snapping.rs:165` 的 `constrained_current = if modifiers.shift { square_constrained_rectangle_end(start, current) } else { current }`；同一 `modifiers.shift` 还传给 `preview_rectangle(start, current, style, shift, alt)`（`:170`）与缩放分支（`:244/270/312`）。`shapes.rs:97` 的 `square_constrained_rectangle_end` 取 `side = max(|dx|, |dy|)`，两轴符号各自取所在增量方向，增量为 0 时回退另一轴的方向。
- **结论**：等比约束只能由**键盘修饰键**触发，与 T08 的 Shift 段模式同性质。触摸屏没有等价输入（长按／双指在本项目里都不是修饰键语义），按既定约定记为平台差异、不虚构手机入口，也不写进已复刻。`Modifiers` 在手机上只有外接键盘的 `MotionEvent.metaState` 才可能带上 Shift，当前触屏路径不读取，未实现。
- **因此 T09 剩余项只剩**：原版同尺度窗口叠图（需 Windows 原版环境，与 §72 那批同批处理）与真人手感；圆角、三种形状、线型／填充、命中、工程往返均已过设备断言。

# Snow Shot T10：直线

2026-11-04。父编号 T10（原为占位入口）。本轮结论：**直线工具已能落对象**，带「直线／曲线」两档、描边色／线型／线宽；曲线走原版的三次贝塞尔链。父项仍记「待验收」——端点单独拖拽、原版像素叠图与真人手感未做。

## 1. 原版依据（固定提交 `afdc340b`）

| 原版文件 | 采用的事实 |
| --- | --- |
| `snow_canvas_types.h`（155–164） | 直线不是独立元素类型：它是 `ArrowData` 去掉箭头（`into_line`），`arrow_type` 取 `Straight`／`Curve` |
| `screenshottoolpalettestylecontrols.cpp`（1398–1432） | Line 的样式行在描边之后插入一个两档单选：`Straight line` / `Curved line`，**`initialId = 1`（默认曲线）** |
| `arrow/data.rs`（270–292） | `is_curve()` → `curve_path_commands(points, tension=1.0, use_open_endpoint_phantom_points=false, …)`；否则 `linear_path_commands`（**逐点折线**，不是首尾直连） |
| `arrow/data.rs`（838–985） | `curve_bezier_segments`：相邻点链成三次贝塞尔；开放端缺邻居时取**段端点自身**（不是镜像幽灵点）；控制点 `c1 = start + (end − prev)/6`、`c2 = end − (next − start)/6`（`tension/6`，tension=1） |
| `arrow/ops.rs`（87–107） | `preview_arrow_from_points` 接受任意点列，说明曲线可以由拖拽路径的多个采样点构成 |

箭头首尾、锥形轴、比例（`arrowRatio`）属于 Arrow 工具（T11），不在直线这一行。

## 2. 本轮修改

- `ScreenshotDrawingTool` 增加 `LINE`；`ScreenshotDrawingStyle.curved`（默认 false，**直线工具的默认样式 curved=true**，对应原版 `initialId=1`）。工程编解码与参数记忆同时覆盖，旧工程缺键＝直线档。
- 入口：`ScreenshotDrawingTools.actions` 加入 `LINE → ScreenshotAction.LINE`，删掉原来的「直线暂未支持」占位动作；`ScreenshotToolbarState` 把 LINE 从占位组移到绘图工具组，标签改为「直线」。图标沿用已有 `snow_line`。
- 渲染 `ScreenshotDrawingRenderer.linePath()`：
  - 直线档＝**逐点折线**（与原版 `linear_path_commands` 一致；曲线档切回直线时保留原有拐点，不塌成弦）。
  - 曲线档＝逐段三次贝塞尔，控制点公式与开放端处理按原版 `curve_bezier_segments`（tension=1，缺邻居取端点自身）。
  - 命中用 `Paint.getFillPath` 生成描边带再取 `Region`，曲线与直线同一套。
- 输入 `ScreenshotDrawingLayer`：直线档拖拽只更新末点（两点对象）；曲线档按 1.5×unit 间距采样拖拽路径（对应 `preview_arrow_from_points` 的点列）。
- 新增 `ScreenshotLineControls`：直线／曲线两档（默认曲线）＋描边色（含线型弹层）＋线宽 2/4/8。没有填充与箭头选项。

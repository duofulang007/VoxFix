# Snow Shot T12：橡皮擦

2026-11-04。父编号 T12。本轮结论：**行为已按原版对齐并通过设备断言**（8px 视口半径、半半径采样、半透明预览、抬手原子提交）；原版本来就没有参数栏，所以没有新增控件。父项记「待验收」——真人手感与多指语义未定。

## 2. 本轮修改

- 命中半径从 `7*unit` 改为 **`8*unit`**（对齐 `ERASER_RADIUS_VIEW`）；采样间距仍是 `4*unit`（半半径），与原版一致。
- 拖动期间不再把命中的对象直接隐藏，改为**按 50% 不透明度预览**（`marks()` 对 `erased` 索引返回 `style.opacity*0.5` 的副本），抬手才真正 `history.remove`。
- 未新增控件：原版没有橡皮擦参数栏，`ScreenshotDrawingControls` 对 ERASER 仍返回空卡片。

## 5. 未完成／已知差异

1. **多指语义**：原版允许多指一起擦、等最后一根手指抬起再提交（测试 `multiple_pointers_commit_only_after_final_pointer_ends`）。手机首版沿用「第二根手指＝取消本次手势」，属差异；**2026-11-07 已按原版改写，见 §6**。
2. **悬停与右键**：原版悬停不触发、次要键不触发；手机没有悬停与右键，天然满足。
3. 对象内部判定沿用各工具的 `hit`（描边带／内部），与原版 `elements_at_with_tolerance` 的精确轮廓判定未逐形状比对。
4. 真人连续快擦的手感、误擦率未走查。

## 6. 多指同擦（2026-11-07）

- **原版取证**（固定提交，`.android/snow-filter-20261107/reference/eraser_workflow.rs`）：`Editor::process_eraser_pointer_event` 以 `state.eraser.active_pointers: HashMap<pointer_id, Point>` 逐指记录上一位置——`Down` 插入该指并单点命中，`Move` 只取**该指自己**的 `previous → canvas_point` 线段采样，`Up | Cancel` 先按该指线段采样再移除，**只有 `active_pointers.is_empty()`（最后一根手指离开）才把 `pending_ids` 交给 `delete_elements`**。所以多指同擦整体只产生一条历史。
- 同一文件的 `eraser_segment_samples`（12–47）被提为纯函数 `ScreenshotEraserSamples.segment`：非法/非正容差按 0、首尾重合不插值、`count = ceil(distance / (tolerance * 0.5))`、`include_start` 只影响首点。本地传 `ERASER_RADIUS * unit`（8 逻辑像素），与上游 `eraser_tolerance() = 8 / zoom` 同域，实际步长仍是半半径 4px。
- `ScreenshotDrawingLayer`：`lastEraser` 单点字段换成 `eraserPointers: HashMap<pointerId, Point>`；`ACTION_POINTER_DOWN` 对橡皮擦改为「该指加入并各自擦」，不再置 `cancelled`；新增 `ACTION_POINTER_UP` 逐指收尾；`ACTION_UP` 在最后一指离开时 `commitEraser()`；`ACTION_CANCEL` 按上游与 `Up` 同等处理（已命中的对象照样提交一条历史）。**其他工具的多指取消语义完全不动**——`screenshot-pen-feedback` 的 `multitouch` 子项仍 PASS。
- 验收：JVM **442 项 0 失败**（新增 `ScreenshotEraserSamplesTest` 6 项：半半径步长、`includeStart`、斜向真实距离、零长度、非法容差、短线段）；设备 `screenshot-parity-foundation` 新增 **`eraser-multitouch`**（两指分别按在两个矩形上 → 第二指抬起后对象仍在 → 剩余手指继续擦 → 最后一指抬起才一次删净、只占 1 条历史、撤销全回）。装机 `4761ede0…3be5682`，默认输入法仍 VoxFix、包列表摘要 `b4445c5e…793e034` 未变，4 项用户数据摘要逐字节一致，`Crashed services` 为空。证据 `.android/t12-multitouch-20261107/`。
- 同轮复跑：`screenshot-editing`（quick-drag）、`screenshot-selected`（erase）、`screenshot-pen-feedback`、`screenshot-recording-annotation`、`screenshot-toolbar`、`screenshot-overlay-suites` 全 PASS。
- **仍未做**：真人两指同擦的手感与误擦率；`elements_at_with_tolerance` 的精确轮廓判定仍用各工具 `hit` 代替（§5 第 3 条不变）。

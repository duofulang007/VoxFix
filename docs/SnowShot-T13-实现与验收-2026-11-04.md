# Snow Shot T13：高亮

2026-11-04。父编号 T13。本轮结论：**参数角色已按原版对齐并通过设备断言**——一个工具位、模式单选（画笔／矩形）、颜色、画笔宽或矩形边框；**原版没有独立透明度角色**，透明度走颜色 alpha，手机的透明度滑杆已移除。父项记「待验收」——椭圆高亮与像素叠图未做。

## 1. 原版依据（固定提交 `afdc340b`）

| 原版文件 | 采用的事实 |
| --- | --- |
| `screenshottoolpalette.cpp`（99／120–121） | 两个工具：`Rectangle highlight` 与 `Pen highlight`，共用主栏一个「Highlighter」位（`normalize` 把矩形高亮映射到画笔高亮），由设置项记住上次选择 |
| `stylecontrols.cpp`（81–83、157–160） | 角色表：矩形高亮＝`highlight-mode`＋`highlight-color`＋`highlight-border`（宽度+颜色）；画笔高亮＝`highlight-mode`＋`highlight-color`＋`brush-width`。**没有 opacity 角色** |
| `snow_canvas_types.h`（166–169） | `SnowCanvasHighlightShape { Rectangle, Ellipse }`——引擎支持椭圆，但样式行里没有对应控件，属未暴露能力 |
| 颜色面板（T08 已核） | 色板自带**透明度轨**，所以高亮的半透明由颜色 alpha 表达 |

## 2. 本轮修改

- `defaultScreenshotDrawingStyle(HIGHLIGHT)`：由「颜色不透明＋`opacity=0.35`」改为**颜色自带 35% alpha（`0x59FADB14`）＋`opacity=1`**，与原版「透明度走颜色」一致。渲染仍按 `colorAlpha × opacity`，旧工程读到的 0.35 与实际 alpha 相乘后**像素完全不变**（有断言）。
- `ScreenshotDrawingControls`：高亮不再显示「透明度」滑杆；聚光灯／文字／序号保留（这几项原版确实有独立透明度）。矩形高亮的「边框色／边框宽」、画笔高亮的「线宽」保持不变。
- 模式切换沿用既有「画笔／矩形」两档（对应原版 `highlight-mode` 单选）。

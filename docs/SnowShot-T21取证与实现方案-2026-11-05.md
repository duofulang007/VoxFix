## 2. 原版交互语义（照抄清单）

**customRegionInputActive** ＝ 非矩形类型 ＆ 非 modifying ＆（选区模式或区域运算激活）。

- **Press**：已有选区且不在构建中→先试拖拽命中（移动/边角），未命中才 clearSelection；构建中保留已录顶点；Freehand：清点、`freehandPressed=true`、filter.reset(点)；所有类型追加首点（与上一点距离 >0.01 才追加，上限 16384）并立即出 draft。
- **Move**：Freehand 按住时 `filter.append(pointer)`；构建中经 0ms 定时器调 `updateRegionDraft(pointer, includePointer=!freehand)`（折线/曲线预览带指针点，手绘不带）。
- **Release**：Freehand：append+`flush(true)`+`finishRegionDraft()`（失败清 draft）；折线/曲线 Release 不结束（逐点点击式）。
- **双击**：Freehand 仅吞掉；其它把末点改为双击位置后 `finishRegionDraft()`。
- **removeRegionVertex**（键盘 Backspace）：构建中删末点并刷新 draft。手机无键盘→须做触摸等价并记录差异。
- **cycleRegionType**（键盘 Tab）：4 档循环，仅选区/移动工具激活时。手机同上。
- **Escape**：构建中清点退出；区域运算中取消运算并确认选区、回工具栏。
- **setRegionType**：停预览、清点、清 draft；正在选区时再清选区并回智能选区；写偏好键。**不清已有确认选区**（非选择态切换时）→ A03「选中态与实际模式一致」。

## 3. Draft 与提交

`updateRegionDraft(pointer, includePointer)`：
1. freehandPressed 时 flush 点；自由绘时末点==首点则去掉末点。
2. 路径：Curve/Freehand → `snowCanvasCatmullRomPath(vertices, vertices.size()>=3)`（<3 顶点为开折线）；Polyline/矩形 → moveTo+lineTo，≥3 顶点 closeSubpath。
3. **OddEvenFill**；`ScreenshotRegionGeometry::fromPath(path, type)`；`setDraftRegion(draft, type==Freehand ? 空 : m_regionPoints)`（手绘 draft 不显示顶点）。
4. flushFreehandPoints：上限 65532；**每满 128 点对当前固定窗做一次 RDP（容差 0.125/scale 画布单位）**，窗首保留 1 点接续；finish 时若末点与最后点不同则补 release 端点。

`finishRegionDraft()`：点数 <3 失败；Freehand 先整段 RDP（0.125/scale）再查 <3；draft 路径 simplified 为空（纯直线/共线点击）失败；`commitDraftRegion(canvasBounds)` 后清点、finishDrag、无有效像素选区则回选区模式，否则 confirmSelection。

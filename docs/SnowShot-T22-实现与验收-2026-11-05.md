## 2. 本轮改造与影响范围

- 新 `ScreenshotObjectSelection.kt`：稳定 ID 多选、Shift 增减、空白框选、整组移动/旋转、预览/取消与一次历史提交；保留释放后的旋转组框，连续旋转不跳回轴对齐框。
- 新 `ScreenshotObjectTransform.kt`：旋转、绝对角度吸附、SAT、线顶点投影与释放规则。Rust 的半值舍入按远离零处理，未使用 Kotlin 的银行家舍入替代。
- `ScreenshotDrawing.kt`：对象加 `rotation`（弧度），纳入相等性与历史；`replaceAll` 原子修改多个对象且保留 ID。
- `ScreenshotDrawingLayer.kt`：共用选择入口接新事务，删除作用于全选集，取消/切工具/撤销不遗留预览；截图与贴图均复用该层。
- `ScreenshotDrawingRenderer.kt`：旋转预览、世界命中、导出、顶点坐标往返；滤镜旋转的是遮罩、底图采样位置不旋转；空心箭头露出当前位置原图；聚光灯孔、序号关联文字连接线同步变换。
- `ScreenshotDocumentCodec.kt`：写 `rotation`；旧工程缺键为精确 0；非数值/非有限值拒绝。首轮发现归一化造成旧 0 浮点微差，已修正并加精确零回归。
- `ScreenshotDrawingControls.kt`、`ScreenshotCaptureOverlay.kt`：Mixed 未接之前，多选只保留整组删除动作，隐藏单对象样式，避免只改组内主对象；贴图编辑器使用同一控制类。
- 新 `ScreenshotPenContinuation.kt`、`ScreenshotStrokeGeometry.kt`：平滑画笔首尾接续；不改旧无平滑标记的折线笔画。

受影响编号：T06/T07、T08–T16、T17/T22/T24/T25；选区 operands/T21 不改。

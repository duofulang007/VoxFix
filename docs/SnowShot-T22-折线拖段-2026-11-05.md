# T22 折线箭头拖段

沿用手机暂离期间的本地开发安排。本轮移植无绑定折线箭头的拖段分支。固定提交为 Snow Shot 1.1.8 的 `afdc340b14e7f92a294a95c374d13ada0d8c7a82`。

- `arrow/elbow_core.rs::move_fixed_segment_to_point` 决定固定段的移动轴，`arrow/elbow_update_segments.rs::handle_segment_move` 调整相邻拐点并处理首尾插入。拖动以当前预览为基准，首段插点后更新后续固定段和当前拖段编号。全文和来源表在 `.android/snow-t22-elbow/reference/`。
- 段把手沿用 `arrow_ops.rs::segment_handle_visible` 的 5 逻辑像素阈值。固定段用白色填充和蓝色轮廓，普通段用半透明蓝色。外观来源为已取证的 `item_conversions.rs::arrow_handle_item`。
- Android 沿用现有触摸拖动阈值和取消路径，在对象局部坐标内计算拖段。预览与松手使用同一个路由状态，提交保留对象身份和一次撤销。工程记录固定段的末顶点编号，旧工程缺省为空。工程重新打开和非法编号拒绝纳入原有设备专项。
- 现有工程中可能保存由样式切换或组变形形成的非正交路径。这类箭头保留原路径，暂不显示拖段把手。端点重新路由、绕障、绑定、吸附及折线类型切换时的完整路由重算仍待移植。

回插 USB 后，将 `screenshot-linear-handles` 和 `screenshot-selection-resize` 连同 Mixed 及受影响截图回归一起运行。真实触摸和原版同尺度叠图待验。

本地 JVM 共 221 项，零失败。主包和测试包构建成功，日志在 `.android/snow-t22-elbow/build.log`。待装主包 SHA256 为 `63b411b6ea57b467bbccded05538e763659394b1c4cdf021bf1c0c602c6023bf`。设备专项已编译，待回插执行。

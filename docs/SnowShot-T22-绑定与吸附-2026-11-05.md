### 3.2 文档口径（取证结论）

`BindableElementState::arrow_bindable_state()` 给出的转换是**矩形代理**：`shape = Rectangle`、`x/y` 由中心减半宽高、`angle` 取元素旋转、`stroke_width` 取描边、`z_index` 取绘制序、`background_opaque` 是「填充 alpha 非 0」、`binding_enabled = !locked`、`interior_hit_enabled = true`。所以手机侧不发明椭圆/菱形绑定目标，引擎里那两条分支保留但文档层不喂。

**待核对**：哪些元素会进 `bindables` 列表由 `snow-draw-engine-model` 决定，该文件未取证（GitHub API 未认证限流，raw 直取未命中路径）。当前实现默认排除箭头与直线，**不宣称逐项一致**。

### 3.3 工程字段

- `ScreenshotDrawingStroke` 增加 `startBinding` / `endBinding`，并计入 `equals`/`hashCode`（否则绑定变化在历史里不可见）。
- 编解码只在非空时写 `startBinding` / `endBinding`（`[elementId, mode, fixedX, fixedY]`），空绑定的工程重编码不新增键，旧工程与旧读者都不受影响。
- 解码校验：数组长度必须是 4、mode 必须合法、id 必须 > 0、比例必须有限；绑定只能挂在箭头上，且必须指向另一个存在的非箭头对象，否则抛 `FormatException`。

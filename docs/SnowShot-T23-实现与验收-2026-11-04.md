# T23 水印：实现与验收

状态：实现中（核心链路已通，模板与撤销未做）。本文不把「入口可用」当成完整复刻。

固定参考 Snow Shot 1.1.8 / `afdc340b14e7f92a294a95c374d13ada0d8c7a82`，依据
`document.rs:WatermarkConfig`（默认值与收敛）、`screenshottoolpalettestylecontrols.cpp` 的 watermark 家族
（文字、字号 S/M/L/XL＝12/16/24/30、字体选择、颜色、角度、间距、透明度、模板下拉）、
`screenshotdefaultstyles.h` 的 `defaults.watermark`。

## 1. 本轮实现

| 子项 | 原版事实 | 本轮状态 |
| --- | --- | --- |
| 默认值 | 黑字、16px、30°、间距56、透明度0.16 | 一致；空文字即不可见 |
| 边界 | gap 10–200、angle −90…90、opacity 0–1、字号 6–512 | 一致（`ScreenshotWatermark.normalized()`） |
| 可见性 | 文字非空且有效 alpha ≥ 0.004 | 一致；有效 alpha＝颜色 alpha × 透明度 |
| 排布 | 全画布重复、按角度旋转 | **已按原版 `snow_canvas_watermark_renderer.cpp` 精确移植**：步长＝墨迹边界+gap、网格以选区中心为原点按整数倍步长排布、奇数行错开半格（带符号奇偶）、墨迹左上角压格点回退1像素 |
| 颜色 | 完整调色板 | 复用 `ScreenshotColorPicker`（含滴管），预览／取消回原值 |
| 字号 | 四档预设＋汇总按钮＋字体列表 | 四档＋滚轮±1＋可输入（6–512）＋设备字体列表 |
| 角度／间距／透明度 | 滑杆 | 三条滑杆，值域与原版一致 |
| 工程保存 | 文档级配置 | `ScreenshotDocument.watermark`＋codec 可选键；旧工程无键＝无水印 |
| 导出 | 合成进导出图 | `render()` 已把水印算进输出（修掉「没有标注时导出跳过水印」的缺陷） |
| 模板 | 保存的模板、`{text}`／时间占位、新建模板弹窗 | **未做** |
| 撤销重做 | 引擎级 watermark edit | **已接**：水印配置与对象共用同一快照栈，一次改动一步，撤销/重做/新编辑截断均生效（`ScreenshotDrawing.Snapshot`） |

选择与橡皮擦不会把水印当成对象（命中测试与擦除只遍历 `history.items`），图层 `WATERMARK` 工具不响应拖动。

## 2. 设备断言

`ScreenshotWatermarkChecks`（由 parity-foundation 调用）新增 `watermark-default,watermark-tile,watermark-opacity,watermark-gap,watermark-layer,watermark-ui,watermark-document`：

- 默认值／空白文字不可见／有效 alpha≈0.16；越界值收敛到 512、90°、10、1.0、200。
- 铺满四象限；间距 20→120 时墨迹降到一半以下；45° 与 0° 位图不同。
- 0.16 透明度的实心大字最暗像素落在 196–232（黑 0.16 叠白≈214）；不透明度 1 时 <40。
- 图层导出包含水印；SELECT 点按不选中、橡皮横扫不会删掉水印。
- 参数栏存在、字号预设 24／30 落到配置。
- 工程往返保留全部字段；旧工程无键解码为 null；超长文字（>200）拒绝。

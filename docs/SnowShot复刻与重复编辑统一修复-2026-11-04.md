## 根因与统一修复

| 问题 | 根因与本次处理 |
| --- | --- |
| 图标与原版不符 | 旧版按截图手绘近似；实际窗口又见逻辑像素显示异常、光标/相机形状不符。十枚改用校验后的原始路径，保留填充规则、描边和圆角，设备像素断言验证空心方框/四格 |
| 关闭压住末尾工具 | 总宽漏算右侧12dp。修前设备回归显示末尾right=582、关闭left=572；补齐总宽后断言无交集 |
| 普通点按误开工具组 | 角标已经移除，却保留右下12dp隐藏命中区。普通点击统一执行工具，长按换组，可访问名称同步更新 |
| 主栏拖到底后详细栏不可达 | 永远放在下面，剩余高度最低1px。下方不足时改放上方，增加实际overlay布局断言 |
| 再改早先文字后选错、删错 | addText(index)完成后无条件选择lastIndex。改为保留被编辑对象的index/ID；两条文字→改第一条→删除→第二条保留，修前失败、修后通过 |
| 贴图再次编辑错位/丢裁剪 | 完整底图被缩进裁剪贴图外框，完成导出整张底图。增加按viewport映射的裁切容器，完成只导出视窗，文字输入坐标同步映射 |
| 没新增手画对象就无法完成贴图 | 空history的render返回null被当成失败。空对象也从底图/文字层生成有效结果，不改原图 |
| 贴图漏掉OCR/译文 | 编辑器只处理objects。恢复文字层，提供识别文字编辑/原文块摆放，完成同步文档；设备像素断言确认文字进入成品 |
| 贴图编辑白底白字 | 旧独立面板仍白底，公共控件已经白字。统一深色面板、白图标、蓝色当前工具，撤销/重做按历史禁用 |
| OCR后切绘图再保存漏字 | selectDrawing隐藏resultLayer，合成跳过文字。保留原文层显示与合成，新增切绘图后保存的文字像素断言 |
| 重开/缩放后字号变化 | 渲染按当前View重新换算sp，文档未保存比例。新增可选drawingUnit/fontUnit，保存并恢复；缩小窗口不改变已存字号，手指命中/角柄容差仍按实际显示尺度换算 |
| 添加/减少区域后重开洞消失 | 文档只有外接viewport。保存并校验区域矩形集合，重开恢复；遮罩按当前viewport定位，裁剪另存也保留形状；像素断言洞alpha=0 |
| 并发保存可能删掉有效修订 | 两次写入共用同一revision目录，失败清理可能删另一成功版。跨Store串行化工程保存，校验显式/隐式revision；双线程断言只一个成功且成功版可读 |
| 损坏工程被降级成普通图 | document为null后走普通图分支，底图缺失又回退合成图。PROJECT不降级；缺底图/尺寸不匹配明确失败且保留文件；工程裁剪也不再降级PNG |
| 更新贴图时旧帧引用回收图 | setImageBitmap后立即recycle旧图。更新改由GC管理旧帧；普通图片贴图也保留独立底图，下一次编辑不烘入上一轮标注 |

文档新字段均可选，旧工程正常读取，不批量迁移或重写用户记录。旧PNG没有历史图层，无法反解其原标注。

- 不宣称桌面全工具1:1完成：折线/曲线/自由手绘选区、捕捉光标、像素单位切换、隐藏工具栏、长截屏/录屏仍是之前明确的占位。这次换原版图标，没有把对应功能写成已实现。
- 多选、任意旋转、箭头端点独立编辑、对象复制/层级/对齐分布仍未实现，现有单对象移动、缩放、改样式、删除与重叠切换保留。
- 真人手指精度/长按手感、横竖屏长时交替、真实聊天插图、杀进程后从输入法图片预览重开整个流程仍待验。新建Store重读磁盘的自动回归不等于这些全局操作通过。
- 旧工程没存字号比例时按兼容规则显示，无法追溯最初所有窗口/字体设置；新保存后保留比例。
- 译文仍按段落重排，不支持逐块自由摆位；普通图片不能恢复已烘进像素的对象。分享继续只导出合成PNG，不外发可恢复底图。

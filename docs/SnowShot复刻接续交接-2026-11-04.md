## 4. 当前失败与接续第一步

### 先检查这些未收尾处

1. 为新增套件提供有效的Activity窗口或真实服务窗口上下文，不通过新增权限／改安全设置绕开token问题，再跑完实际采样链路。

3. `ScreenshotColorPanel.sync()` 中 `surface().apply { setColor(color) }` 的接收者作用域值得核查：可能取到GradientDrawable自身颜色而非面板当前颜色。暂停时未修。
4. 采样现在由导出型 `colorSamplingBase` 与当前标注组合；尚未证明滚动OCR／长译文／缩放贴图时与实际可见画面一致。应核对坐标、可见裁切、偏移与采样层自身不入采样。
5. 验证颜色面板与滴管切换不提前提交，返回／外部关闭／锚点分离不泄漏弹窗或位图；编辑已有对象只产生一条历史，取消恢复，不污染新建默认值。

# Snow Shot 工具交互与手机适配

## 工作规则与边界

用户要求所有复刻先查原版效果、实际拥有行为的源码和完整状态，再确定手机适配并实施；不边猜边改。本轮仍只包含 D1–D6、D10、S1、S2、S8 与已经存在的箭头/矩形/画笔。表格、长截图、录屏、视觉模型转换等不扩入。

依据固定 Snow Shot 1.1.8 提交 `afdc340b14e7f92a294a95c374d13ada0d8c7a82`。以下“原版”结论来自该提交；手机规则是适配决策，不能说成电脑版原有手指操作。原版当前没有运行中的进程，因此本轮未重新实操电脑窗口；用户截图可核对编排外观，动态行为按源码核对。

## 先确定的公共状态

| 项目 | 源码事实 | 手机适配/验收点 |
| --- | --- | --- |
| 编排 | 绘图、动作分别存储；堆叠上到下保存，底部工具是初始入口，菜单顺序反转 | 两个切换页各有隐藏区和重置；保留旧布局，不能重置另一页 |
| 工具组 | 鼠标悬停展开上方选项；主入口点击执行当前工具；选完子工具收起并更新主入口 | 手指无悬停：点组入口展开/再点收起；选子工具后收起；外部、返回键收起；切组只保留一组；取消始终可触达 |
| 当前绘图工具 | 再点已激活绘图工具会回到 Select，不是回到重新框截图 | 选择图形状态接管已有对象；不得一次点击同时取消选择和新建标注；选区不会因停用绘图而重画 |
| 第二栏 | `styleEditorRoles` 为各工具提供不同选项，不是一份所有工具共用的面板 | 只出现本工具选项；切工具保留本工具样式；手机限高滚动，避免盖满内容；主栏滚动位置不能每画一笔就复位 |

公共依据：[布局模型](https://github.com/mg-chao/snow-apps/blob/afdc340b14e7f92a294a95c374d13ada0d8c7a82/snow_shot/include/snow_shot/presentation/screenshottoolbarlayoutmodel.h)、[工具激活与分组](https://github.com/mg-chao/snow-apps/blob/afdc340b14e7f92a294a95c374d13ada0d8c7a82/snow_shot/src/presentation/tools/screenshottoolpalette.cpp) 的 `activateToolFromToolbar` / `selectDrawingItemGroupEntry`、[悬停菜单与选完关闭](https://github.com/mg-chao/snow-apps/blob/afdc340b14e7f92a294a95c374d13ada0d8c7a82/snow_shot/src/presentation/tools/screenshottoolpalettebuttons.cpp) 的 `createScreenshotToolPaletteOptionPopoverShell` / `materializeScreenshotToolPaletteOptionPopoverEditor`。

## 已选工具逐项对照

| 工具 | 原版拥有的行为与手机主体 | 后续细节，不冒充已完整复刻 |
| --- | --- | --- |
| 打码 D1 | 矩形/画笔是作用方式，马赛克/高斯模糊是效果，强度是子选项；矩形无需显示画笔线宽 | 手机只实现用户选定的两种滤镜；自动模式、智能消除与其他效果未加入 |
| 高亮 D2 | 画笔/矩形独立子模式；画笔宽度与矩形边框选项不同 | 当前矩形高亮边框、颜色控件细节与原版有差异，后续逐项对齐，不假称整套完成 |
| 聚焦 D3 | 单独工具，遮罩颜色与透明度；多个有效关注区共同作用 | 当前手机矩形关注区与遮罩已接，复杂变换/性能需要真实页面长用验证 |
| 文字 D4 | 前景色、字体、对齐、描边、填充与圆角；文字有独立编辑状态 | 手机已有新增、修改、换行与对象编辑；字体族、描边/背景等完整控件留到细化阶段 |
| 序号 D5 | 五种样式、当前值与字体/填充；引擎还支持序号关联说明文字 | 手机先保留五种样式、连续值、起始值与字号；关联说明文字不擅自扩入 |
| 橡皮 D6 | 命中对象删除，按移动路径补采样，整次手势一次提交撤销；不是修补原图 | 手机删除标注并可撤销；快速跨越对象应补路径采样，不能只检查两个事件落点 |
| 对象选择 D10 | 已选对象可移动/缩放，样式修改进入历史；文字编辑与选择有边界 | 手机已有对象移动、四角缩放与样式撤销；多选框、旋转、原版命中细节未全部搬入 |
| 箭头/矩形/画笔 | 各工具独立样式角色，预览和导出应一致 | 基础绘制已接；额外形状、箭头端点等不扩范围 |
| 识码 S1 | 属于截图动作，不是绘图滤镜 | 手机本机识别，结果主动复制，HTTP(S) 主动打开；不自动跳转或上传图片 |
| 贴图 S2 | 无标题栏、置顶、图片细边框；控件由指针存在状态控制；缩放保持图片比例并按拖动边/角锁定对侧锚点 | 手机中间拖动、边/角单指缩放、双指按手指焦点缩放；轻点显隐控件，闲置收起；不常驻窗口栏，不把图片拉变形 |
| 分享 S8 | 此项是用户选定的手机补充，非原版同名主工具 | 共享当前处理后图片的临时只读 URI，系统选择目标；不自动发送，不改原图或复制记录 |

各工具子项依据：[样式角色](https://github.com/mg-chao/snow-apps/blob/afdc340b14e7f92a294a95c374d13ada0d8c7a82/snow_shot/src/presentation/tools/screenshottoolpalettestylecontrols.cpp) 的 `styleEditorRoles`。橡皮依据：[对象删除工作流](https://github.com/mg-chao/snow-apps/blob/afdc340b14e7f92a294a95c374d13ada0d8c7a82/snow_draw_engine_qt/crates/snow-draw-engine-editor/src/eraser_workflow.rs)。序号依据：[序号文字模型](https://github.com/mg-chao/snow-apps/blob/afdc340b14e7f92a294a95c374d13ada0d8c7a82/snow_draw_engine_qt/crates/snow-draw-engine-editor/src/text/serial.rs)。聚焦依据：[聚焦渲染](https://github.com/mg-chao/snow-apps/blob/afdc340b14e7f92a294a95c374d13ada0d8c7a82/snow_draw_engine_qt/src/rendering/snow_canvas_spotlight_renderer.cpp)。

## 集中实施顺序与验收

1. 收拢工具组状态：重复点、外部点、返回、换组、选完关闭；主栏和取消不被遮罩拦截。
2. 贴图主体：取消标题栏；等比尺寸、触摸边角、对侧锚点、双指焦点、单指接续、屏幕边界、关闭入口；横竖屏保持图片比例。
3. 已有工具公共逻辑：重复选择回 Select、矩形滤镜隐藏无效画笔宽度、橡皮连续命中，保持可撤销及原图不变。
4. 一次定向构建，运行截图 JVM 与原生控件回归，然后保留数据安装。K60 再查工具组真实触摸、无框贴图拖动/缩放/关闭和系统分享预览；控件注入不等于用户真人手感验收。

本轮不以“1:1 完全完成”描述手机适配。完整的桌面细节对齐以上述差异为后续清单，不增加用户未选功能。

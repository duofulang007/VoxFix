最新手机适配与已授权绘图以[手机布局与基础绘图](截图工具手机布局与基础绘图-2026-11-04.md)为准；新增工具先看[待选清单](archive/design/SnowShot工具候选-2026-11-04.md)。下方初版的横向滚动预览、小箭头独占位置等已被替换，不能再作为当前界面约定。

本轮先检查既有逻辑和实现工具栏自定义，不添加尚未选定的新工具。保留工作区已有 OCR、翻译、剪贴板和语音改动，不整体提交或回滚。

用户后续明确纠正：自定义方式必须结合 GitHub 源码和提供的截图复刻，不采用「＋」按钮、文字卡片和说明段落。旧尝试已替换为图标空间编辑器。本文工具建议只保留作候选，当前实现优先范围为自定义方式。

## 源码依据与“两栏”的含义

读取本地固定的 Snow Shot 1.1.8 源码快照，提交 `afdc340b14e7f92a294a95c374d13ada0d8c7a82`，目录 `.android/snow-shot-eval-20261103/reference-1.1.8/snow_shot/`。不是把另一个 `revision.json` 中的新提交当成 1.1.8。

- `src/presentation/toolbar/screenshottoolbarwindow.cpp`：实际启用的绘图、识别、翻译、表格、二维码、图像转换、录屏、滚动截图、保存/复制等入口。
- `src/presentation/settings/settingscatalog.cpp:400–424`：绘图工具与截图动作各有布局配置；允许拖动换位和同位置叠放。
- `src/presentation/tools/screenshottoolpalette.cpp` 的 `applyMainToolbarLayout`、`createActionToolGroup`：两份布局组合到主工具栏，叠放项有主入口与展开菜单。
- 同文件 `createSecondaryToolbarShell`：另外建立随当前工具变化的动作面板和样式面板，不是把全部工具永久排成上下两行。
- `screenshottoolpalettestylecontrols.cpp`：描边、宽度、填充、透明度、字体、箭头、序号、滤镜、水印等细化项。

上游链接：[固定版本](https://github.com/mg-chao/snow-apps/tree/afdc340b14e7f92a294a95c374d13ada0d8c7a82/snow_shot)。网页读取失败后，通过固定提交的 raw GitHub 地址补取 `settingscustomwidget.cpp`、`toolbareditorsettingswidget.h` 和 `screenshottoolbarlayoutmodel.h`，实际阅读了 `ToolbarDropSurface::dropLocation`、`ToolbarPositionWidget::insertionIndex`、`ToolbarEditorSettingsWidget::Private` 与布局移动/叠放逻辑。不宣称核验了上游最新版本。

关键规则：32px工具位、24px图标、位置间隔8px、叠放间隔4px、面板12/4px边距、8px圆角；所有列底边对齐，堆叠按从上到下保存，最下方可用工具才是主栏入口，展开项从底往上排列。旁边是独立位置，列内按纵坐标插入；分隔线不能与工具叠放。Android实现依据这些可观察规则独立编写，不粘贴Qt组件源码。

| 类别 | 主工具 | 对应细化操作 | 手机取舍 |
| --- | --- | --- | --- |
| 选区 | 移动、选择 | 区域形状、比例/圆角、区域增减等 | 先保留现有移动与拉边，不搬桌面全部复杂选区 |
| 标注 | 矩形/椭圆、箭头、线、自由画笔 | 形状、颜色、线宽、填充、箭头端点等 | 箭头、矩形、画笔值得优先考虑 |
| 强调 | 高亮、聚光灯 | 模式、颜色、边框/遮罩、透明度 | 高亮优先；聚光灯适合教程但频率较低 |
| 遮挡/效果 | 橡皮、滤镜 | 模式、类型、强度；含马赛克/模糊 | 隐私遮挡优先，必须确认导出已固化 |
| 文字与步骤 | 文字、序号 | 字体/字号、颜色/描边、对齐；序号值/样式 | 文字与序号适合聊天说明和操作教程 |
| 水印 | 水印 | 文本、字体、模板、角度、间距等 | 可后置，手机不必完整照搬模板系统 |
| 识别 | OCR、表格、二维码/条码 | 原图对照；表格合并/拆分/重置；识别结果操作 | OCR已有；二维码实用；表格要单独验证准确率 |
| 翻译 | 翻译 | 源/目标语言及结果操作 | 已有；先解决长文超时和恢复问题 |
| 输出 | 保存、复制、贴图、图像转换 | 按当前工具呈现对应操作 | 分享值得加；格式/压缩后置；贴图先评估遮挡 |
| 捕获扩展 | 滚动截图、录屏 | 捕获/录制控制及导出设置 | 跨App兼容与资源成本高，暂不优先 |

表中手机取舍是结合本项目的建议，不是上游的功能承诺。二维码不默认打开网址；隐私遮挡不能把可恢复的模糊当作可靠脱敏。

## 当前问题与设计差距

1. **本轮修复**：译文态打开原图，再点“显示原文”，原先只切换子图层，父文字层仍可能隐藏。该动作现在明确回到可见原文，清除原图对照状态。
2. **本轮修复**：设置说明仍声称需要先手动识别、保存不含译文，以及旋转直接清空，已按现有实现更正。
3. **本轮补齐**：截图工具原先硬编码排列，输入法菜单没有独立布局设置入口。新增图标空间拖动、叠放/内部换位、独立分隔线、隐藏区排序/恢复、右上角重置及持久化。工具状态过滤仍优先，处理时取消、编辑时完成编辑会直接显示，不受隐藏或叠放阻塞。实际工具条窄屏自动换行；设置预览保留横向位置，超宽可滚动。
4. **仍未修复的已知故障**：中文约600字符译英文触发60秒超时；本轮未修改推理链路。英文600字符约9秒是前轮单样本结果，不能当中文通过或普遍速度。
5. **仍待验证**：首次下载、断网/强杀恢复；真实跨App旋转/闲置恢复；真实语音与翻译交替；复杂多栏、透视及图片背景；图片插入聊天应用的实际接收。
6. **有意保留的手机差异**：当前没有通用绘图画布，撤销/重做只对应原文/译文编辑，不能代表所有截图操作；译文16sp滚动重排与全量导出优先，尚非桌面复杂背景原位还原。手机版复制入口目前复制文字，不提供截图直接复制；图片可保存后到剪贴板复制。这是现有范围限制，新增直接复制图片前应先明确入口语义。
7. **尚未加入**：绘图工具和各自样式栏；不展示不可用的空工具。将来按工具逐项接入第二级选项，不把所有参数塞进主栏。

## 本轮入口与操作

输入法「功能菜单 → 截图工具栏设置」直达独立布局页，也可从既有截图工具设置页进入。

- 拖到旁边：插入独立位置；拖到某列：按上下位置插入叠放，可改变主入口。用蓝色竖线/横线分别显示落点，没有「＋」按钮。
- 拖到隐藏区隐藏；从隐藏区拖回预览恢复，也可在隐藏区重新排序。分隔线单独占位。
- 从图标直接拖动即可操作，长按也可开始拖动。空白处横向滑动浏览超宽预览，拖动靠边自动滚动。
- 运行时主图标执行最下方当前可用工具，小箭头展开横向图标组选项。随截图/识别/编辑状态过滤，不显示空位。
- 所有工具可收进隐藏区；活动操作的取消、完成编辑会临时直接露出，确保有出口。布局应用于下一次打开的截图，不改动文字、图片或词典。
- 设置页采用用户截图的深色表面、灰白图标和8dp圆角；隐藏区56dp高、灰色填充；标题左对齐、重置图标右对齐。无说明段落、文字按钮、调位弹窗或可见的工具名称；无障碍标签和操作保留。其余未授权的桌面分类不做空壳。

## 5. 今天新踩/ reaffirmed 的坑

1. **Gradle daemon 连续 "GC thrashing"**（默认 512MiB 堆）：命令行加 `-Dorg.gradle.jvmargs="-Xmx2560m -XX:MaxMetaspaceSize=768m"` 即过，别改 gradle.properties。
2. **data class 加字段**：解码构造器用位置传参会错位（今天 autoResize 插在 textHeight 后导致 Long/Boolean 错配）——解码全改命名传参最稳。
3. **钉边推导**：point(=top-left)=center−size/2，钉顶边 ⇒ point.y 不动；别把中心 delta 直接当 point delta。
4. **设备断言探针**：把手/曲线位置必须从实现函数算出（如角半径把手 inset=12+(max−12)*r/max），不是固定常量。
5. **套件残留**：parity-foundation 的 draw-template-check 每跑一次在 `shared_prefs/` 留一个 `parity-foundation-screenshot-draw-template-check-*.xml`（内容全同，用户数据摘要 diff 会看到新增）——跑完用 `run-as rm` 清掉再 diff。

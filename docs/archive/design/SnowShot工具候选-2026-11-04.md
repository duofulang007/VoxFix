# Snow Shot 工具候选：先选择，再添加

> 历史方案：已由后续实现覆盖，当前状态请看[开发入口](../../开发入口.md)，勿直接照旧计划执行。

后续用户已选D1–D6、D10、S1、S2、S8；主体实现与验证见[已选工具接入](../../SnowShot全工具接入-2026-11-04.md)，具体交互与剩余差异看[源码对照](../../SnowShot工具交互对照-2026-11-04.md)。以下为选择前的调研记录，不能用其中“尚未实现”代表当前状态。

用户最新要求：绘图与截图动作要参考上游分开设计；先列打码、聚焦等候选供挑选，不擅自继续扩展。手机必须留出实际编辑空间，高堆叠要能查看和操作。

用户后续取舍：**不做表格识别**。图片复制已有（输入法剪贴板「图片」预览→复制），不再当作新增能力推荐；未保存截图中的直接复制只是入口差异，用户未要求另加，不据此扩展任务。

## 上游依据

固定 Snow Shot 1.1.8 提交 `afdc340b14e7f92a294a95c374d13ada0d8c7a82`，实际读取：

- [工具清单与两类布局](https://github.com/mg-chao/snow-apps/blob/afdc340b14e7f92a294a95c374d13ada0d8c7a82/snow_shot/include/snow_shot/presentation/screenshottoolbarlayoutmodel.h)：`descriptors`、`drawingEditorDescriptors`、`actionDescriptors`、`defaultPositions`、`actionDefaultPositions`。
- [绘图子选项](https://github.com/mg-chao/snow-apps/blob/afdc340b14e7f92a294a95c374d13ada0d8c7a82/snow_shot/src/presentation/tools/screenshottoolpalettestylecontrols.cpp)：形状、颜色、线宽、填充、透明度、滤镜、序号和水印等。
- [实际工具面板](https://github.com/mg-chao/snow-apps/blob/afdc340b14e7f92a294a95c374d13ada0d8c7a82/snow_shot/src/presentation/tools/screenshottoolpalette.cpp)：滤镜模式与类型、取字/翻译/表格等操作。

结论：绘制与截图动作拥有独立排序、堆叠、隐藏配置，运行时可以组合呈现；选中某工具后出现对应的第二级操作栏。不能把每一个子模式都做成主栏按钮。

当前手机仍为一份合并布局，尚未完成两类独立配置。后续适合采用「绘制 / 截图」切换页，共用较大的中央编辑区，各有隐藏区和重置；不能简单上下摆两个完整编辑器挤占屏幕。本轮先完成已授权的三种基本绘图与手机布局，不把分区计划说成已经实现。

## 已授权范围

箭头、矩形、画笔；取字、翻译、保存、文字复制/编辑和原图对照已有。基础绘图支持颜色、2/4/8线宽、会话内撤销/重做与保存固化，尚不是桌面完整对象编辑器，未实现选中某个图形后移动、缩放或修改它。任意位置新增文字标注也不等于现有OCR文字编辑。

## 绘制候选

| 编号 | 工具 | 用途和第二栏 | 手机建议 |
| --- | --- | --- | --- |
| D1 | 打码/滤镜 | 上游含马赛克、高斯模糊、灰度、反色、浮雕、亮度和智能消除；可按区域或画笔作用，调强度 | 先选马赛克/模糊；其余效果单独决定，不因选打码就全部加入 |
| D2 | 高亮 | 荧光笔/矩形高亮，调颜色、透明度等 | 优先，强调聊天或截图里的重点 |
| D3 | 聚焦/聚光灯 | 保留关注区域，其余区域变暗；调遮罩颜色和透明度 | 优先，给别人说明某个按钮或区域 |
| D4 | 文字标注 | 图片任意位置新增文字，调字号、颜色、对齐等 | 优先，与OCR编辑区分 |
| D5 | 序号 | 连续添加1、2、3等步骤标记，调样式和起始值 | 优先，适合教程与问题反馈 |
| D6 | 橡皮擦 | 删除画出的笔迹/标注 | 优先；不是抹掉原图内容的“智能消除” |
| D7 | 形状扩展 | 椭圆、菱形、圆角、填充、描边等 | 按需；实色填充也可用于遮挡隐私信息 |
| D8 | 直线及更多箭头 | 直线、曲线/折线箭头与箭头端点等 | 基础箭头已接，扩展可后置 |
| D9 | 水印 | 文本、字号、角度、间距、模板 | 按需 |
| D10 | 图形选择/移动/缩放 | 上游移动和选择控件，用于修改已经画好的标注 | 建议与绘图配套；目前三种工具只支持重画或撤销，不具备对象编辑 |

“打码”在上游属于滤镜的子模式；“聚焦”是独立绘图工具，可以和高亮叠放。智能消除、普通橡皮擦与马赛克不是一回事，不合并成模糊的“擦除”。

## 截图动作候选

| 编号 | 工具 | 用途 | 手机建议 |
| --- | --- | --- | --- |
| S1 | 二维码/条形码 | 识别截图中的码，复制内容；网址主动选择打开 | 优先 |
| S2 | 贴图/固定到屏幕 | 把截图作为可移动的悬浮参考图 | 按需，要保证不挡触摸和宿主内容 |
| S3 | 表格识别 | 上游有此功能 | 用户明确不做，从待选范围排除 |
| S4 | 滚动长截图 | 连续获取纵向或横向长内容 | 后置，Android跨App兼容不能照搬电脑行为 |
| S5 | Markdown / HTML / LaTeX | 结构化内容或公式输出，图里的f(x)属于公式识别 | 按实际用途挑选，可分别加入 |
| S6 | 录屏 | 录制屏幕操作 | 系统已有录屏时不优先 |
| S7 | 快捷保存/另存为 | 导出文件与保存位置选择 | 现有保存进入输入法图片剪贴板，外部导出可按需补 |
| S8 | 系统分享（手机补充） | 把处理后的图片交给微信、QQ等 | 实用，但不是上游该清单中的同名主工具 |
| S9 | 复制图片（已有，不再候选） | 剪贴板「图片」预览页已可复制图片 | 不重复实现，也不自行新增未保存截图的快捷入口 |

第二张截图左侧的HTML、Markdown、f(x)、二维码、表格属于截图动作的叠放组，不属于绘图。“滤镜打码”在第一类绘图里，不能把f(x)误当成滤镜。

## 手机空间约束

- 自定义：过宽换行、保持每行的堆叠底边对齐；中央独立滚动编辑区，标题和隐藏区固定，高堆叠上下可查看，拖到边缘自动滚动。
- 使用：工具组本体保持普通图标宽度，以角落小标记表示有子工具；点开后为限宽、限高的可滚动网格，优先放选区外，没有独立的宽下箭头按钮。
- 颜色、粗细等留在第二栏，不扩成主栏图标；满屏选区无法完全避开时限制弹层占高，不盖满截图正文。

优先建议：D1、D2、D3、D4、D5、D6；截图动作先考虑S1，需要对照时再选S2。S3已排除，S9为已有能力；其余不在未选择前添加。

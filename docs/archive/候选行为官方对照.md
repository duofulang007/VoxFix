# 候选行为：讯飞小米版实测与修复

日期：2026-10-11。对照 K60 已安装的讯飞小米版 `com.iflytek.inputmethod.miui` 8.1.8322，只在 VoxFix 自有空白试用框中触摸官方键盘。以下是界面观察，不是官方私有算法或源码。

## 官方实测规律

| 输入与状态 | 实际候选或行为 | 应遵循的规则 |
|---|---|---|
| 中文 `n` | 你、能、您、拿、呢、哪、南等 | 单声母先给单字，不提前补成整句 |
| 中文 `c` | 吃、成、才、车等，后面有字母/emoji | 单字候选与短语预测分开 |
| 中文 `f` | 分、发、范、饭等 | 单声母不让“发给我一下”抢首项 |
| 中文 `ni`、`shi` | 当前排序以逆、时等单字开头 | 一个音节仍主要选字；排序受当前官方状态影响 |
| 中文 `nihao` | 你好、emoji、你号、拟好等 | 多音节给词，组合区显示 `ni'hao` |
| 中文 `nihaoq` | 你好亲、你好啊、你好奇等 | 全拼可以接末尾声母，整串继续组合 |
| 中文 `nnnn` | 你你你你、扭扭捏捏、那那那那等 | 重复声母继续生成中文候选，不自动切英文 |
| 中文 `qqqqqq` | 切切切切切切、钱钱钱钱钱等 | 保留完整重复组合，不因缺少整词条就中断 |
| 中文 `nininini` | 你你你你、你你你、你你、妮妮 | 重复完整音节可以整串组字，也可分段选词 |
| 中文 `iiiiii` | 组合区为 `ii'iiii`，候选有“你欧”、i、I | 官方有额外纠错；不能把这个样例概括成“完全无候选” |
| 中文 `hello` | hello、Hello、HelloKitty 等 | 中文模式允许完整英文混输；用户明确要求保留 |
| 英文 `hel` | hel、hello、hell、help、helper | 原输入与补全一起从左端排布 |
| 英文 `qqqq` | 单项 qqqq 位于左端 | 没有词库匹配也不能把唯一候选拉到中间 |

所有测试输入均留在组合/试用框中，截图后删除。官方原先的英文模式已恢复，再切回 VoxFix；没有在聊天或笔记中输入测试文字，没有改动两个讯飞包。忽略目录 `.android/official-candidates-*.png` 保留本轮固定样例截图。

## 找到的根因与改动

1. 旧短前缀索引混入多字词；单字母 `c` 首项直接变成“吃饭了吗”，`f` 变成“发给我一下”。现在一个完整/未完成音节只返回相应单字，多音节仍保留全拼、简拼、混合匹配和常用语。
2. 旧组句只接受完整拼音片段；重复声母无法补齐中文，会退成原始字母候选。现在复用原组句算法，增加合法声母片段，并让重复组合可以生成完整中文。选取部分候选仍只消耗对应拼音，剩余部分继续组合。
3. 选词记忆会重新加入当前候选集合外的旧词。现在记忆只重排本次有效候选，不删除用户记忆数据。
4. 候选按钮 `flex-grow:1` 将单项撑满后居中。现在按内容宽度从左端排布，完整显示、横向滑动和输入变化回到开头均保留；展开候选文字也靠左。
5. 中文模式复用已有离线英文词库，仅当原串确为完整英文词时加入混输。`hello` 给英文候选；`women` 等同时命中拼音的输入仍优先中文“我们”。不会因为任意无匹配串就开启英文预测，也不自动提交输入。

受影响源码：`preview/pinyin.mjs`、`core.mjs`、`english.mjs`、`app.mjs`、`style.css`。对应逻辑、网页交互和真机检查已补充；APK 继续通过既有清单打包这些资产。

## 公开资料与复用边界

浏览讯飞官网未找到能够验证本版候选排序内部算法的教程。可执行参考来自开源输入法：Rime 的方案将拼音、英文和自定义短语分开翻译，再做候选排序/过滤，而不是用一个前缀补全列表处理全部状态。[Rime 雾凇拼音配置，固定提交](https://github.com/iDvel/rime-ice/blob/da1fbe602e38f26db846fa10120ee64c2b0324c0/rime_ice.schema.yaml)。其公开英文过滤器也专门处理英文词挤占中文候选的问题。[英文候选过滤器](https://github.com/iDvel/rime-ice/blob/main/lua/reduce_english_filter.lua)。

本轮沿用项目已经固定在 `da1fbe602e38f26db846fa10120ee64c2b0324c0` 的 Rime 英文词库及 GPL-3.0 许可，没有引入新依赖或移植官方私有实现。前述过滤器仅作行为参考，没有复制代码。

本轮不宣称复刻了官方个人词频、整句语言模型、emoji 排序或模糊纠错；自动分词分隔符的显示也未新增。单字/整词的匹配范围、重复组合、混输边界和靠左显示已针对实际问题修复。真人日常手感另需用户确认。

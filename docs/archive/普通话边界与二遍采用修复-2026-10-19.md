# 普通话边界与二遍采用修复（2026-10-19）

## 原因与改动

沿用[10月18日114次压力测试](普通话语音压力测试-2026-10-18.md)的全部音频，不换模型、不增加日常录音保存。
开工时保留工作区已有改动；本轮修复集中在原生语音，未改键盘前端、录音采集与宿主编辑保护。

| 问题 | K60隔离证据 | 修复 |
|---|---|---|
| 轻声“等一下”、轻声/长句漏“我” | 原VAD裁剪错误，前后补160ms后正确 | 新增32秒有界原音频缓存，VAD边界前后补160ms；相邻补边界不重复取音频 |
| “你好→你”“好的→好”“备份→辈分” | 原VAD与补边界两种音频二遍都正确，85%相似度规则却拒绝短词 | 两种音频识别一致时，短中文允许补一个首尾字，或同长度同音修正 |
| “不要取消订单→要取消订单”、“不要打开通知→开通知” | 两种裁剪的二遍均正确，流式漏字，否定保护反而挡住补回 | 两种音频识别一致时，允许补一个否定字或不超过3字的否定句首；已有否定、删除/替换否定及改动数字仍拒绝 |
| “128元五角→128元5元角” | 当前SenseVoice内置ITN产出错误；关闭ITN后普通汉字正确 | 比较数值与金额单位结构，拒绝错误二遍覆盖正确首结果；保持模型ITN配置，避免影响其他语种和标点 |
| 同音修正首次晚到 | 首次ICU初始化占掉改写窗口 | 在已有语音后台词表线程提前初始化；不延长420ms宿主改写窗口 |
| 粤语新增“哋” | 22次跨语种回放中一条补边界改变了原先正确的措辞 | 检出粤语后采用原VAD音频的二遍结果，不将普通话边界修改直接用于粤语正文 |

“两种音频识别一致”指同一SenseVoice模型对带补边界音频和原VAD音频得到一致正文及语种，
不是两种独立模型，也不是识别置信度。无一致证据时继续走原保守规则。
否定句首补全要求原正文原样保留为后缀、至少保留2字，且新增内容只含一个否定字；不放行任意整句重写或补成双重否定。
短词例外只处理1～4字中文；不放行任意短句改写，不增加具体词名特例。
空首结果、粤语整句采用、英文词界与个人词库保护沿用原路径。

音频窗口只存在本轮识别的内存中，环形容量32秒；读取已淘汰范围时放弃该段二遍。
原有30秒二遍音频上限、350ms同步收尾、420ms宿主接受窗口及30秒空闲释放均保持。
普通打字不会为此启动语音模型。

## 最终结果

修复已保留数据安装到K60。相同评分器重新评估修复前后音频，原114次正文102/114→114/114；
其中含60条基础语料、50次变体/长句/引擎状态回放和4次无语音检查，并非114个独立真人录音。
新增40次成对回放基于24条新合成语料：16条否定/肯定句分别正常和低音量回放，加8条金额/数字正常回放。
最终40/40正确，没有观察到成对肯定句被改成否定句或否定丢失。

# 表情包搜索初稿

本页为第一版的实现与验收记录；其分区界面已由[同屏搜索版](../表情包同屏搜索-2026-10-19.md)替代，当前不显示分组与相关分类。

日期：2026-10-19。入口是工具栏现有笑脸，按钮尺寸、位置和工具栏布局不变。默认进入「表情包」，保留「Emoji / 颜文字」。

## 当前行为

- 顶部搜索按钮在输入法内部打开关键词编辑，提交后显示图片，不把关键词提交给聊天应用。
- 固定分区：精选、萌宠、沙雕、打工、开心、无语、收到、动图。它们是关键词分类检索；并非搜狗输入法内部栏目，也不是热榜。
- 第二行相关分类使用搜狗公开结果的 `tagList`，点击继续检索对应关键词。
- 四列缩略图、点击预览、加载更多（最多五页）、加载/空结果/失败重试。
- 「插入聊天」通过 Android `commitContent` 提交图片，先检查宿主声明的 MIME；应用不支持则明确提示。不会自动点击聊天发送按钮。换框或键盘收起后，迟到的下载不再提交。
- 本版未加收藏、最近使用、合集与热榜；动图分区只是检索词，具体是否动态取决于搜狗返回的资源，不能保证原始 GIF 一定保留。

## 内容源与实现

参考 [o98k-ok/meme](https://github.com/o98k-ok/meme)，核对版本 `eb9631a3858fb978d64ae801ec95dd726735411d`。其旧搜狗 JSON 接口实测 HTTP 200 但正文 `status=1/info=forbid/data=null`；正常公开 `/pics` 搜索页可返回图片及分类。本版独立解析该页面内的 `window.__INITIAL_STATE__` JSON，不执行远端脚本、不加载远端页面进带原生桥的 WebView。

未引入 Go、MCP、服务器、收费接口或登录 Cookie。上游 README 声明 MIT，但固定版本没有独立 LICENSE；本版未复制其 Go 源码。参考范围、版本与图片授权边界已记录在包内 `licenses/meme/UPSTREAM.md`。

网络由 `MemeSearch.kt` 在后台处理；WebView 通过同源 `/meme/search`、`/meme/image/<id>` 取数据。外部图片只允许注册过的搜狗 CDN HTTPS 地址，逐次检查跳转地址，限制响应体、实际图片格式与像素尺寸；图片不按 HTML/SVG 执行。普通打字不发联网请求。首次打开表情包页发送分区词，用户搜索发送所输入的关键词，不上传输入框正文、剪贴板或语音。

图片内存缓存上限 4 MiB，单张下载上限 8 MiB；仅插入过的图片产生应用私有缓存副本，通过只读、临时授权的内容 URI 交给宿主，超过一天的旧发送缓存在下次插入时清理。没有导入个人图库，没有扫描或清理用户图片。

## 源文件

- `preview/meme-search.mjs`、`meme-search.css`：独立面板和请求状态；`app.mjs` 只接入口、内部编辑器与回调，`index.html` 载样式。
- `MemeSearch.kt` / `MemePayload.kt`：查询、公开页面解析、图片限制；`MemeInsertion.kt` / `MemeContentProvider.kt`：原生图片提交及只读共享。
- `VoxFixImeService.kt`：同源请求转交与少量桥接；Manifest 增加普通 INTERNET 权限和非导出的内容提供器；`stageKeyboard` 增加模块与来源说明。

验收未覆盖：用户真实触控、微信/QQ 等跨应用接收、GIF 动态保留、长时间使用和不同网络条件。图片插入的 Android 隔离宿主检查不等于微信/QQ 通过；源站页面及索引可能变化。桌面浏览器试用没有提供线上搜索代理，真实联网功能在手机 IME 内运行。

# 表情包搜索开源与数据源调研

核查日期：2026-10-19。本轮仅查官方站点、项目仓库与公开文档，没有申请账号、调用付费接口、跑仓库或更改应用代码。本文区分“文档承诺”与“可运行验证”，不以 stars 证明可用。

## 结论

建议做独立的轻量表情包功能模块，先接一个内容源，保留更换源的接口；目前不需要搭建通用搜索框架、机器人框架或 AI 检索平台。截图里的搜索、分区、合集和热图是四种内容能力，开源 UI 本身不能提供持续更新的中文内容与真实热度。

中文内容方向优先评估闪萌，SOOGIF 备选：两者官方说明都覆盖搜索、热门和分类，且把输入法列为应用场景。但它们是内容 API 服务，并非开源插件；个人接入资格、当前价格、配额、缓存和分发条件均未核实。开源方向可参考 ChineseBQB 的分类和索引、meme 的源适配，但本次没有找到已验证能直接满足“实时中文优质搜索 + 热榜 + 分区 + Android 输入法发送”的完整成熟开源方案。

## 推荐首版

1. 独立表情面板：顶部搜索，热门/分类切换，缩略图网格，预览，最近与收藏。合集入口等内容源确认支持后再加。
2. 优先用同一服务的搜索、热门、分类。热度有数据才叫热榜，没有则明确叫精选；本机收藏和最近不能伪装成全网热度。
3. 首轮先用真实关键词检验“崩溃、无语、收到、打工、猫猫、当周新梗”等返回结果，检查重复、糊图、水印、动图、加载失败和国内网络速度。不能仅凭官网宣传认定质量。
4. 网络只提交用户在表情搜索框明确输入的关键词。输入法其他正文和语音内容不需要上传。
5. 图片下载、预览、缓存、归因和转发严格按选中服务的协议确定；先确认实际协议，不预设可以混合数据源、自建代理或永久存图。

Android 在微信/QQ 等目标应用中怎样插入并发送图片，需要单独完成平台接口与 K60 验收。网页搜索列表成功不能证明表情已经能从输入法发出去。

## 补充：海外服务与 Android 发送

- [GIPHY 官方 API](https://developers.giphy.com/docs/api/)有搜索、热门、分类和热门搜索词，属于内容服务；要求来源标识，搜索/热门结果有禁止重排或过滤等规则，不能默认作为任意聚合排序的源。中文梗覆盖和国内连接表现未实测。
- [KLIPY](https://klipy.com/migrate)提供 GIF/贴纸等服务和 Tenor 迁移支持；生产接入须申请并遵守归因等条件，不是开源图库。中文内容、当前额度和具体缓存条件需另核。
- [Tenor 官方停用公告](https://support.google.com/tenor/answer/10455265?hl=en)明确 API 于 2026-06-30 停用，不应再选作新模块的 API；网站和 Google 自有应用继续使用不代表第三方 API 可用。
- [doutu-uToolsPlugin](https://github.com/vst93/doutu-uToolsPlugin)可参考搜索、图源切换和选图交互；README 更新记录列至 2021 年，且记载过多次图源失效替换。属于桌面插件，不能将桌面微信/QQ 粘贴表现直接套到 Android；复用代码前还需确认许可。
- 当前源码检查：`preview/app.mjs` 仅有本地 Emoji/颜文字及关键词过滤；主 Manifest 未声明 INTERNET，IME 未发现 commitContent/FileProvider 图片提交实现。现有 Emoji 搜索不等于在线成品图片搜索。
- [Android 官方图片键盘文档](https://developer.android.com/develop/ui/views/touch-and-input/image-keyboard)要求输入法和宿主共同参与：读取宿主支持的 MIME 类型，以 content URI 调用 commitContent；是否插入、是否保持 GIF 动画和是否仍需用户发送，要逐 App 验证。宿主不支持时再评估保存/系统分享路径。

未做：账号申请、报价确认、API 实测、图片授权逐张核对、APK 构建和真机发送。

## 补充：匿名源实测与 VellumStyle 的真实来源（同日 21:50）

### VellumStyle 抓的不是文章，是公众号编辑器的官方表情面板

核查固定提交 `61463c2` 的 `src-tauri/src/wechat_backend/content.rs` 与 `EmojiPickerDialog.tsx`：

- 它是 Tauri 桌面应用，先让用户扫码登录 `mp.weixin.qq.com`，把后台页面留在窗口里；`eval_in_backend_window` 在这**已登录页面的上下文里**执行一段 JS，不经过独立 HTTP 客户端。
- 从 `location.href` 取 `token`，`window.fingerprint` 可空；`POST /cgi-bin/operateremoticon?action=search_all` 与 `action=search_gen`，body 为 `size/offset/query/firstFlush=1/fingerprint/token/lang=zh_CN/f=json/ajax=1`。
- `search_all` 返回 `normal_emoji_result`，其中 `emoji_url` 是加密数据，网页端也只能显示静态缩略图；`search_gen` 返回 `gen_emoji_result`，是未加密的 `search.c2c` 链接，可直接播动图。所以它把两者合并、合成表情排前。
- 点选后再调 `action=get_cdn_url&url=…&thumb_url=…&emoticonType=0|1&aesKey=…`，换取 `mmbiz` 永久链接。
- 因此来源是**公众号图文编辑器的表情素材库**，不是聊天表情搜索，也不是公众号文章配图；它依赖登录窗口常开、页面 token 和 `mp.weixin.qq.com` 同源，且只支持 Windows。

公众号文章里的 `mmbiz.qpic.cn` 图是另一回事：那是文章配图，要自己爬文章、去重、清洗，版权风险最高，也没有“热门”契约。微信表情商店的编辑推荐/热门同样没有公开接口。

### 选型结论

1. **只要匿名、快、省流量、图干净**：h5api（`biaoqing.gtimg.com`）是当前最优；必须标注为“腾讯表情”，不能叫微信同源。
2. **要微信聊天那种图**：没有任何公开源等价；聊天搜索在 LiteApp/mmsearch 里，需登录态。
3. **要官方素材库且愿意维护账号**：只有 VellumStyle 那条路，桌面端扫码 + token，不适合塞进输入法，且属于把编辑器接口当公开 API 用。
4. **要真·热榜/新鲜度**：闪萌、SOOGIF 这类商业内容 API 能力最全，但需申请 Key 与商务条件，本轮未验证价格与配额。
5. 发表情/斗图啦这类站点可以做兜底或离线图库，不适合当主源。

图片授权提示：表情包多为用户上传或影视截图，抓取可用不等于可再分发；商用前需逐源确认许可。

### 官方入口核查（同日 22:07）

- `h5api.sginput.qq.com` **没有官方开发者入口**：根路径 404，响应头只有 `Date` / `Content-Type` / `Content-Length`，没有文档、控制台、Key、CORS 或限流说明；`sginput` 是搜狗输入法，`wxbq` 应是“微信表情”。属于内部 H5 接口，随时可能加 Referer/UA 校验或下线。
- 搜狗输入法皮肤表情开放平台 `open.shouji.sogou.com` 是**设计师上传**表情/皮肤、审核上线的平台，不提供搜索 API。
- 微信表情开放平台 `sticker.weixin.qq.com` 同样是创作者上传/审核后台，301 到登录页。
- 微信开放平台、腾讯云均没有“表情搜索”产品。
- 有官方文档、可申请 Key 的内容 API 是闪萌、SOOGIF；GIPHY 需 Key 且中文梗弱，Tenor 官方已宣布 API 于 2026-06-30 停用。
- 因此 h5api 只能按“未公开接口”接入：超时、失败回退、来源标注一个都不能省；要授权与稳定性只能走商业 API。

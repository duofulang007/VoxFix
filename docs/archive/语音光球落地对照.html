3「卡」是怎么解决掉的

维度改前改后
波形节点58 个 <i>，各自跑同一条 0.8s 动画1 组 4 层光云 + 1 层外晕 + 1 个核心
每帧改的属性height —— 触发 style + layout只写一个 --mic 变量，几何全由 calc() 派生
合成层无 will-change，逐帧重排全部 transform / opacity / filter，已提为合成层
进场 / 退场没有，整块 innerHTML 瞬间替换呼出 300ms 生长；退场 190ms 内收（幽灵节点重放，状态立即清空）
状态切换每次都 render() 重建面板 → 动画被重启只改类名（paintVoice），动画连续不中断
常驻文案每状态 2 行每状态 1 行，「取消预备」零文字
最容易翻车的一处：.voice-cloud 的 transition 绝不能挂 transform。声幅 --mic 是每帧写的，一旦挂了 340ms 过渡，跟手与音量响应都会被拖成「迟钝」——这是「不灵动」的另一个来源。只在 cancel / recognizing 两个态上给 transform 过渡。
同样容易翻车：进场动画一开始用了 animation-fill-mode: both，结果动画的 transform 把 .voice-follow 的跟手 translateY 整个锁死（动画优先级高于普通声明），上滑时云团纹丝不动。改成只写 from 的关键帧、不带 fill-mode 才对。

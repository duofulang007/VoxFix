明细

这一版里各控件怎么工作

控件行为
候选栏 · 剪贴板引用第二候选位显示剪贴板内容（蓝色、带复制图标、带下划线）。 点按＝整段引用上屏；长按＝进入「编辑本次引用」。与拆词互通：编辑框里点「拆词」直接进拆词面板。
编辑本次引用按钮从左到右 取消 / 拆词 / 引用。取消＝关掉不动正文；拆词＝拿框里文字进拆词；引用＝框里全文上屏。
原文行（拆词面板顶部）可直接改字的输入行。改完立刻重新分词，词块按阅读顺序流动重排； 已选中的词按位置尽量保留，对不上的整段重排。它就是这一版的"键盘"，没有第二把键盘。
词块点按＝选中/取消，并同步到正文（composing，正文里带下划线）；手指拖过＝经过（含中间跨越）的词块整段一起选中； 起点已选中的话，拖过就是整段取消。
底行左 · 全选派生状态：点满最后一个词块时才自动变勾。
底行右 · 复制把选中的词按顺序连起来复制到剪贴板，并弹一条「已复制 N 个词：…」。未选中时置灰。
顶部 ↶ 返回回到「编辑本次引用」，稿子保留；此时正文里那段 composing 会撤销，不会污染正文。

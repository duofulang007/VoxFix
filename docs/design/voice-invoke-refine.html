语音呼出与关闭 · 打磨效果图

沿用现有设计，不动骨架：长按空格呼出 → 整片键盘换成语音面板（大色球随音量流动）→ 上滑 55px 取消 → 松手输入 / 长语音点结束。 这一版只解决这套交互里「呼出没预告、面板长得太硬、球看不出在听、取消没有临界点、收尾像蒸发」的问题，共 7 处； 全部落在 app.mjs 的 spaceKey / startVoice / voiceFrame / syncVoiceDrag / exitVoice 与 style.css 语音段内，不引依赖、不换视觉语言。

呼出 有时间预告，不是突然变脸 面板 从空格长出来 色球 听得见：动态 + 静音提示 取消 刻度环闭合，不整球刷红 识别中 收束成点 关闭 沿原路收回
01

呼出：长按先走一圈预告，面板从空格长出来

打磨点 1 · 2

现在是「按住空格 → 面板立刻替换键盘 + scale(.96)→1 200ms」，手指还没确认界面就换了；松开又立刻退回，呼出与关闭都缺一个"起手/收手"的过程。 改为三拍：① 按住后 mic 图标外圈走 320ms 环形进度，键帽同时轻微下沉（.holding），未走满松手＝普通空格，不误触； ② 走满后面板 以空格键为原点向上展开——transform-origin:50% 100% 是现成的，只把进场从"整体缩放淡入"换成"高度展开"； ③ 色球在生长末段从 0.2 倍放大到位，音量接管。

今天我们来看一下语音输入的 松手输入 · 上滑取消
  • 调参放大音量动态范围：现在是 size = rest + level * .10，正常说话几乎看不出球在动，只有大声才明显。改为 rest + level * .22，保留快攻慢放的 .055 / .18 时间常数；同时把球内浮云流速的音量系数从 1.5 提到 2.2（voiceFlow += dt * (listening ? .38 + level * 1.5 : .22) 这一行），小音量也能看到云在加速。
  • 新增静音提示：连续 2.5s 音量近零时，标题转琥珀色「没有听到声音」，提示行给「靠近一点，或检查麦克风是否被占用」，球外浮出一圈缓慢呼吸的虚线环（.hushring）。现在这种情况用户只会看到一颗没反应的球，无从自查。
  • 新增面板内实时转写回显行（球与提示之间，超出省略）：数据就是现在送进 applyText 的那份 chunk 文本，只多渲染一处。中途就能确认识别对不对，错了立即上滑取消，不必等松手后再撤。
  • 保留球的渐变与 voice-orb.mjs 的 time/level/cancel/quiet 四个 uniform、上滑跟手位移、底部布局都不动。

上滑取消：刻度环闭合，而不是整球刷红

打磨点 5

  • 改反馈现在上滑时整个球随 cancel uniform 渐渐变红，越靠近阈值只是"更红一点"，没有临界瞬间，用户只能靠松手后的结果反推。改为 球外一圈红色刻度环：上滑距离映射 --t，到 VOICE_ARM = 55px 时环恰好闭合，同一帧球缩到 0.55 倍并转红、中心浮出回转箭头——越线是"一下"的事，不是渐变。
  • 保留55px 阈值、跟手位移、下滑退回倾听的逻辑与代码结构；只把「整体变色」换成「环进度 + 越界二态」。

  • 注意刻度环走 DOM + conic-gradient，不额外占 WebGL；voice-orb.mjs 的 cancel 参数保留用于球内轻微降饱和，避免真机上色球与红环都全红打架。

落地位置

  • app.mjsspaceKey() 加 .holding 与环形进度（新增 spaceHold 计时，320ms 阈值，与现有短按判定共用一次计时）；startVoice() 保持 voicePanelFresh 语义，由生长动画接管；voiceFrame() 调 size 系数与 voiceFlow 系数、加静音计时；syncVoiceDrag() 输出 --t 给刻度环；exitVoice() 的 ghost 改播「收回」关键帧。
  • style.css新增 .voice-dial、.voice-echo、.voice-hush-ring、.voice-orb.collapsed；把 @keyframes voiceGrow / voiceFade 换成 voiceUnfold / voiceFold（高度展开 / 收合），缓动统一用现成的 --voice-ease。
  • voice-orb.mjs不改结构，cancel / quiet uniform 继续供球内微调，刻度环走 DOM 不占 WebGL。
  • 回归需同步更新 voice.test.mjs、voice-orb.test.mjs、interaction-transitions.test.mjs、workflow.test.mjs（文案与 DOM 断言）；真机复验长按 320ms 阈值手感（K60 触控采样）与收回动画掉帧。

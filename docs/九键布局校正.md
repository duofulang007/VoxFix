# 九键布局校正

2026-10-09。用户指出九键布局不符合讯飞输入法，要求参考讯飞九键。

之前复用了数字面板结构，左上放“1”，右侧放分词和“26键”，没有数字上标，导致键位和比例都不正确。本轮依据用户 APK 的小米版专用布局修正，不以通用 py9.ini 替代小米版。

来源：`assets/layout/720/port/py9-xiaomi.ini`、`assets/layout/720/port/style.ini` 和 `assets/layout/xiaomi_icon.ttf`。原始布局已提取至 `docs/apk-analysis/reference/`。图标字体仅用于本地核对图标含义，没有加入网页字体。

## 键位依据

- 720 参考宽度：左右栏各 126，中间三列各 156；键区 y=99..550，共四行。
- 左列：，。？！@ 等常用符号，显示五项可滚动；底部“符”。
- 中间三行：分词／ABC／DEF，GHI／JKL／MNO，PQRS／TUV／WXYZ；对应数字 1..9 为小号上标。
- 右列：删除、清除、0、换行；旧“26键”按钮移除。
- 底排完整顺序：符、123、空格、中英、换行。
- 第一键的样式 6400 文字为“分词”；图标 EE55 经字体渲染确认文字为“清除”，没有把它误当成中英切换。

网页采用专门的五列／四行九键网格，不改变数字面板及 26 键布局。列比例为 126:156:156:156:126，间距随已有设置变化。清除只删除未提交的拼音码，空闲时禁用；上滑／长按字母组可直接输入数字。分词码中的撇号不再使九键候选失效。

## 验证

- 浏览器实际键区顺序、行列及宽度比例核对通过，没有“26键”按钮。
- 输入 64，再分词，再 426，能够出现“你好”候选；点清除后“原文”保持不变。
- 右侧 0 输入成功。
- 九键词库单测覆盖带分词符与不带分词符两种编码；脚本语法及独立文件打包通过。

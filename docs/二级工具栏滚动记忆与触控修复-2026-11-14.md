# 二级工具栏滚动记忆、触控修复与稳定性（2026-11-14）

## 1. 用户反馈

- 「这个设置点一下就回到了最前面的控件，完全没有记忆，不符合操作逻辑和直觉。」
- 「滤镜打码强度拖动条无法拖动；看看其他控件能不能操作，要符合安卓触屏交互。」
- 「拖动改变时还有屏闪抽搐，二级工具栏不稳定。」

## 2. 根因（三份只读调查核实）

### 2.1 位置记忆

| # | 根因 | 位置 |
|---|---|---|
| 1 | `refresh()` 4 个分支提前 return 不走恢复 | `ScreenshotDrawingControls.kt`（WATERMARK/SELECT/ERASER/else） |
| 2 | 恢复用 `post{scrollTo}`，早于 layout，`scrollTo` 把目标夹进 `[0, extent-viewport]`（此时均为 0）→ **静默夹成 0** | `ScreenshotStyleRow`、`ScreenshotToolbarPanel`、`ScreenshotToolbarEditor`、`ScreenshotCaptureOverlay:1546`、`ScreenshotPinEditor` 五处同病 |
| 3 | `rebuildDrawingStyles` key 含 `selectedIndex`，一点对象就整块新建、scrollX 不交接 | `ScreenshotCaptureOverlay.kt:1540` |
| 4 | 主栏 `setTools` 里 `body==null` 时位置永久丢 | `ScreenshotToolbarPanel.kt:51` |
| 5 | 布局设置页 render 整页重建、隐藏托盘无恢复、切 Tab 回顶 | `ScreenshotToolbarEditor.kt:97-126` |

### 2.2 触控

- 4 个 SeekBar（滤镜强度 / 聚光灯透明度 / 水印透明度 / 选区透明度）都在 HorizontalScrollView 子树里且无 `requestDisallowInterceptTouchEvent(true)`。对照组成立：`ScreenshotCornerRadiusButton:58`、`ScreenshotStepper:106` 有这行 → 能拖。HSV 拦截后 SeekBar 收到 ACTION_CANCEL，正是预览回滚点 → 「按上去了但数值弹回去」。
- **热区回归**：单行化重写时丢掉了各面板 `group()` 里的 `ScreenshotTouchTargets.install(row)`，8 个面板 28dp 格只剩裸命中。

### 2.3 闪动/抽搐

- 同一帧 `placeControls()` 跑两遍（`changed()`→`{rebuildDrawingStyles(); sync()}`，两者末尾各一次）。
- SELECT 按下无条件 `changed()`（DrawingLayer:552）→ 点选对象闪两次。
- `sync()` 无条件 `rebuildToolbar()`（约 57 处调用点），主栏每次整条 removeAllViews。
- `detailsAbove` 临界翻转 → 二级栏上下跳。
- 水印颜色 picker 实时回调每帧 `setWatermark→changed()` → 拖色环整条工具栏都在闪。

## 3. 修法

### 3.1 `ScreenshotScrollMemory.kt`（新）：布局后恢复的唯一实现

`applyAfterLayout(view,value,horizontal)`：挂一次性 layout listener，viewport/child extent 有效后 `scrollTo` 并自摘；调用时已布局好就立即生效。**禁用 `post`**。纯函数 `clamp(scroll, viewportExtent, childExtent)`（布局未就绪返回 null 等下一帧，而不是夹成 0）。替换全部 5 处旧 `post`。

### 3.2 位置交接

- `ScreenshotDrawingControls.refresh()`：`scrollByTool[lastTool]=savedScroll()` → 重建放 `try` → `finally { restoreScroll }` 统一出口；横向位置**按工具归档**（换工具再回来各自回到上次位置）。HSV 分支恢复也走 ScrollMemory。
- `rebuildDrawingStyles` key 改为只看 `inspectedTool`（DrawingControls 全部状态 getter 实时读、子面板每次 refresh 重建，selectedIndex 变化走 refresh 即可）→ 点选对象不再整块新建。`ScreenshotPinEditor` 同步。
- 主栏：`bodyScrollY` 提为字段（`body==null` 不清零），恢复走 ScrollMemory。
- 设置页：Editor 加 `tray` 字段与 `pendingPreviewScroll/pendingTrayScroll`，`exportScroll/importScroll`；Activity 按 section 缓存快照，切 Tab 导出导入；「隐藏的工具」托盘首次有了位置恢复。
- `restoreProject` 补一次 `placeControls()`（它没有配对 sync，其余全部调用点都有）。

### 3.3 触控

- `ScreenshotSeekBarGesture.kt`（新）：`SeekBar.bindUninterruptedDrag(onCancel)` —— DOWN 声明父级不得拦截、UP/CANCEL 释放并回滚预览，返回 false 不影响 SeekBar 原生拖动。四处接入。
- `ScreenshotStyleRow.init` 恢复 `ScreenshotTouchTargets.install(row)`（48dp 热区，布局尺寸不变）。
- `ScreenshotTouchTargets.visit()` 加 `containsSeekBar` 排除：含滑杆的子树整体跳过热区重定向，防止「强度 50」读数区触摸被吸到最近的 28dp 格。与 install 同一提交落地。

### 3.4 闪动缓解

- SELECT 按下：`selectedIndices` 未变只 `invalidate()` 不 `changed()`（DrawingLayer）。
- 水印颜色 picker 走预览通道：`beginWatermarkPreview` + 每帧只 `previewWatermark`（invalidate），dismiss 提交一次、cancel 回滚。
- `sync()` 的 `rebuildToolbar()` 加**签名守卫**：`[state, busySource, translateAfterRecognition, groupEntries.hashCode(), toolMemory.fingerprint()]` 未变则跳过整条重建（`closeStack()` 移到 sync 内无条件调用保住旧行为）；`ScreenshotToolMemory.fingerprint()` 返回 recent 原始串。⚠️ rebuildToolbar 新增状态输入必须同步扩签名；回滚开关：比较改恒真。
- `placeControls`：从 `rebuildDrawingStyles` 删除（由配对 sync 提供）；`detailsAbove` 加 24dp 滞回（`secondaryAbove` 字段，换工具/重新展开重置）；面板 GONE 时跳过两次 measure。

## 4. 验证

- **JVM 502 项 0 失败**（新增 `ScreenshotScrollMemoryTest` 6 项：布局未就绪返 null / 夹取 / needsApply）。
- **设备套件 6 组全 PASS**（K60 `6959dba1`）：`screenshot-refinement`（含 2 条新断言）、`screenshot-parity-foundation`（90 子项）、`screenshot-toolbar`、`screenshot-selected`、`screenshot-color-picker`、`screenshot-recording-annotation`。
- **新断言**（`ScreenshotDrawingRefinementChecks`）：①TEXT 行滚到 180px 后 `refresh()` 整块重建，恢复到 180±2；②滤镜强度滑杆模拟 DOWN→MOVE(越 slop)→UP，`strength>0.9` 且行 scrollX 不变——两条都过，即「拖滑杆不再被横滑容器抢走」「改值不再回行首」被锁定为回归线。
- 装机后 `Crashed services:{}`、默认输入法不变。
- 取证过程中发现 `screencap` 抓不到无障碍 overlay（此前已知限制），视觉验证依赖渲染图与套件断言。

## 5. 真机走查清单（需多弗朗确认）

1. 横滑二级栏到右侧改一个值 → 行不跳回。
2. 滤镜强度 / 聚光灯透明度 / 水印透明度滑杆能拖，行不跟着滚。
3. 水印拖色环不再整条工具栏闪。
4. 点选对象（切换/取消）不再闪两次。
5. 28dp 小格的空隙也能按到（热区回来了）。
6. 布局设置页拖工具 / 切 Tab 不回顶。

## 6. 边界

- 未做弹层状态记忆（调色板格式页、字体搜索词）——按既定范围排除。
- 未重写「每次改值整块重建」架构（只加守卫、交接与滞回）；`rebuildToolbar` 签名守卫的回滚开关在 sync 内比较处。

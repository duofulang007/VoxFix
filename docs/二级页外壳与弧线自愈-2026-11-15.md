# 二级页统一外壳与弧线自愈（2026-11-15）

本轮把「外壳是新的、点进去还是旧原生控件」这条断层补上，同时把用户层与开发层拆开。
不引入 AndroidX，不新增第三方 UI，不动 Snow Shot 1:1 复刻区。

## 1. 结构问题与修法

| 问题 | 证据 | 修法 |
|---|---|---|
| 设置页被当全局偏好仓库 | `ScreenTextSettingsActivity` 的 companion 被 26 处调用，服务/接收器/工具栏都 import Activity | 新增 `ScreenTextPrefs`，Activity 只留 UI |
| 用户层与开发层混在一起 | `MainActivity` 141 行里约 100 行是录音、电平、识别结果 | 拆成「试用键盘」与 `DevToolsActivity` |
| 原生代码无结构红线 | 既有检查只扫 `preview/*.mjs` | 新增 `tools/check_native_boundaries.mjs` + 体积预算 |
| 假控件占位 | 首页不可点 chips、屏幕页 3 个只读行、About 两个静态行 | 删除或改纯文本 |
| 命名混淆 | 个人词库（拼音）vs 个人词典（语音纠错） | 改为「拼音词库」「语音纠错词典」 |

目标分层（依赖单向）：

```
shell / feature-ui / devtools → core-ui, domain, platform
platform                      → domain
core-ui                       → domain
domain                        → 无（不 import Activity/Service/View）
```

自动检查的三条规则（`tools/check_native_boundaries.mjs`）：

1. `ui/` 不得 import `android.app.Activity` / `Service` / `BroadcastReceiver`。
2. `getSharedPreferences(` 只允许出现在 `Prefs|Config|Settings|Store|Memory|Checker|Mode|Picker` 文件与 `Modules.kt`；Activity 一律不许。
3. `*Activity` 只允许被 Activity、`VoxFixImeService` 与清单引用；浮层/面板允许导航。

大文件预算（超出即失败，逼新职责建新文件）：截图浮层 2600、输入法服务 1600、
无障碍服务 1420、长截图 930、录屏 870 行。

## 4. 弧线自愈

| # | 根因 | 修法 |
|---|---|---|
| B1 | `alpha` 只由一次 `onPreDraw` 放行；未放行就永久全透明，而 `isAttached` 为真让恢复入口全部短路 | 布局回调置 alpha + 400ms 兜底；`isAttached` 改为看 parent；新增 `isSettling` 防重建抖动 |
| B2 | `closeSession()` 任一步 dismiss 抛异常 → overlay/screenshot 不清空 → 弧线永不回来 | 每步独立 `runCatching`，置空与 `removeHandle/showHandle` 必须执行 |
| B3 | 弧线开关默认 false，重装后必然没有 | 默认 true（无障碍未授权时仍不显示） |
| B4 | 健康检查只看 listed/bound/live/arc，不判窗口 | code 扩为 OK/DISABLED/CRASHED/ARC_OFF/MODULE_OFF/WINDOW_MISSING/BUSY |
| B5 | 旧实例 `register(null)` 会清掉新实例的 handler | 改 `unregister(handler)` 按身份比对 |
| B6 | 浅壁纸 + 深色页面时 42% 深灰弧几乎看不见 | 垫一层反色低透明描边（手机侧扩展，原版无此行为） |
| B7 | 恢复入口被 screentext 模块门控隐藏 | 键盘菜单「截图工具 · 修复」恒可见 |

「恢复贴边弧线」：首页屏幕页一行，动作序列为
`busy 检查 → 开模块 → 写开关 → 位置/配色兜底 → bound 走同进程重建，未 bound 走摘出再放回 → 1.2s 复查`。
`listed=false` 不代用户打开无障碍，只深链到本服务条目。

## 5. 录屏设置条

9 chip → 主行 4：`格式 / 清晰度 / 声音 / 更多`；「更多」含 `循环`（仅动图）、`文件夹`、`恢复默认`。
帧率、质量、分轨、延迟下线，`load()` 恒取默认（30fps / 80 / 混音 / 无延迟），键与 `save()` 保留。
声音必须在主行：它含双源/麦克/系统/静音四态，删掉会丢失静音能力。

本轮真机未走完整录制流程：调试入口在 Activity 前台时会被会话关闭，浮窗一闪即收。
结构由 `ScreenRecordingChipsTest` 锁定（主行 3/4 项、动图才有循环），
`bitrate()` 与 `ScreenRecordingOptions` 未改，实际录制路径保持原样。

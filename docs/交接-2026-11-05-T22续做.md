## 6. 踩过的坑（别再踩）

1. **`org.json` 在 `testDebugUnitTest` 是桩**（`Method put not mocked`），编解码不能在 JVM 测。把校验抽成纯函数测，JSON 胶水留设备侧。
2. **提交分支的 `finishLinearPoints` 会把已绑定端点推离元素**，提交前必须再 `resolve` 一次。
3. **`am instrument` / `install -r` 后 `ScreenTextService` 必被标 Crashed**，跑完 `bash .android/rebind-voxfix-a11y.sh`，判据只看 `dumpsys accessibility` 的 `Crashed services`。
4. **GitHub API 未认证会 403 限流**，用 `raw.githubusercontent.com` 直取。查文件先看 crate 的 `src/lib.rs` 里 `#[path]` 映射。
5. **`ScreenshotBindingGeometry` / `Decisions` 是 `internal`**，`ScreenshotFixedPointBinding` / `ScreenshotBindMode` 必须 `public`（笔画数据类要用）。
6. 我改代码时用 `io.open(..., newline='')` 写文件，避免 CRLF 被规整产生假改动。

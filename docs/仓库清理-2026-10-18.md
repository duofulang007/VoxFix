## 删除：电脑端语音服务整簇

`voice/` 从一开始就是**电脑端**离线语音与整理服务（Python HTTP 服务 + 模型推理），手机端语音一直走原生
`sherpa-onnx`（`SpeechEngine.kt`），两条链路没有任何共用代码。2026-10-17 那轮把网页里的电脑语音、离线整理、
长句词库从页面移除后，这一簇就只剩文档在提它。

| 删除项 | 原用途 | 判定依据 |
|---|---|---|
| `voice/server.py`、`voice/polish.py`、`voice/evaluate.py` 等 10 个文件 | 电脑端语音/润色 HTTP 服务与自测 | 无任何模块 import；页面不再引用 `/api/voice/*` |
| `preview/voice.mjs` | 浏览器侧 `LocalVoice` HTTP 客户端 | 无 import；`app.mjs` 只 import `voice-orb.mjs`；网页语音是固定交互演示，不录音 |
| `preview/voice.test.mjs` | 上述客户端的单测 | 只 import `voice.mjs` |
| `tools/validation_server.py` | 隔离端口的验证服务器 | 依赖 `voice/server.py` 与 `voice/polish.py`，一起失去宿主 |

同时把 `android/app/build.gradle.kts` 的 `stageKeyboard` 清单去掉 `"voice.mjs"`——它此前一直被无意义地打进
APK 的 `assets/keyboard/`：手机侧 `127.0.0.1` 访问不到电脑服务，这段代码在真机上永远不会被执行。

`voice-orb.mjs`（语音球，手机与网页都在用）**保留**，不要和上面的采集客户端混为一谈。
历史实现可从 Git 追溯，无需在树里留副本。

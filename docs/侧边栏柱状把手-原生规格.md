# 小米侧边栏「柱状把手」原生规格（K60 / HyperOS V816）

抓取日期 2026-11-04，设备 23013RK75C（1080×2400 逻辑 / 420dpi / 1dp = 2.625px）。
数据来源两条，互相对账后一致：

1. 真机像素测量（`screencap` 原始帧，`.android/sidebar-assets/`）；
2. 系统包资源表 `com.miui.securitycenter` → `aapt2 dump resources`。

## 1. 为什么截图截不出来

把手常态是 **半透明到几乎不可见**，而且同一栏位在手指触摸时才显形。机身截图（三指/音量键）
在触摸离开后立刻抓，抓到的就是接近透明的状态；再加上它只有 3dp 宽，肉眼和截图都很难分辨。

实测 `state-idle.png` 中把手栏位（x 1072–1079）与相邻背景的色差只有 G 通道 +5~16，
R 通道基本不动 —— 说明常态是极低不透明度的叠加，不是一条实心白条。

## 2. 三态规格

| 状态 | 形状 | 逻辑尺寸 | px 实测 | 颜色 | 说明 |
|---|---|---|---|---|---|
| 常态（idle） | 细竖条 | 3 × 66 dp | 8 × 182 | `#b3c7c7c7`（70% 灰） | 贴右边缘，几乎看不见 |
| 拖动态（drag） | 胶囊，两端全圆角 | 28.31 × 72.59 dp | 78 × 200 | `#ff979797` 实心中性灰 | 手指按下并拖动时张开 |

### 位置分布

- 右边缘内缩：把手右沿距屏幕右边 18px（≈7dp）；面板右沿距右边 34px（≈13dp）。
- 垂直位置：把手中心固定在 **y ≈ 744 / 2400 = 31%** 处，即偏上三分之一，**不是垂直居中**。
  两次独立抓取（653–835 与 644–843）中心都落在 743–744。
- 面板与把手的横向关系：面板宽 180px，图标列 110px，左右内边距约 37px（≈14dp）。

```
color/sidebar_line_color          #b3c7c7c7   常态把手
color/sidebar_line_color_light    #ff979797   浅色壁纸时（拖动态实测即此值）
color/sidebar_line_color_dark     #ccffffff   深色壁纸时（80% 白）
color/sidebar_wrapper_normal_color #33c7c7c7  容器底 20%
color/sidebar_wrapper_light_color  #33191919  容器底（浅色场景）
color/sidebar_wrapper_dark_color   #33c7c7c7
color/sidebar_shortcut_menu_bg_color #ffffffff / night #ff212327
```

**关键点：把手颜色按壁纸明暗切换，不是固定值。** 深色壁纸走 `#ccffffff`，浅色壁纸走
`#ff979797`，中间态 `#b3c7c7c7`。这解释了「有时几乎看不见、有时是一根灰条」。

## 5. 交互与动效逻辑

- **形态变化是「细线 → 胶囊」的横向张开**：3dp 宽 → 28.31dp 宽，66dp 长 → 72.59dp 长。
  变化量集中在宽度（约 9.4 倍），长度只增加 10%，所以视觉上是「从一条线膨胀成一根柱」，不是拉长。
- **阈值**：拖动量到 `66dp`（等于常态线长）时触发切换/展开动画。
- **展开本身没有可截的中间帧**：把 `window/transition/animator_duration_scale` 全设为 10
  后，以 147ms/帧（设备端 raw 连拍，6.8fps）抓 30 帧，展开前后只有两个完全相同的画面组。
  结论：面板是瞬时呈现，不做位移动画；可见动效只发生在把手的宽度膨胀上。
- **收放触发**：从右边缘内滑 / 点按把手 → 展开；`BACK` 或点击外部 → 收起。

## 6. 对 VoxFix 弧形控件的直接结论

1. 颜色不要用一个固定值。原生在浅色/深色壁纸下换了三档，你的弧形入口如果只定一种灰，
   在某一类壁纸上必然糊掉。建议按背景亮度切换，基准取 `#ff979797`（亮底）与 `#ccffffff`（暗底）。
2. 常态不要追求「看得清」。原生的常态本身就是接近透明的，靠形状和位置让人感知，不靠对比度。
   想提高可发现性，走「触摸时膨胀」这条路，而不是把常态调亮。
3. 膨胀比例 9.4 倍宽度、1.1 倍长度。若你的弧形入口在触摸时只是变色不变形，观感会和原生差一截。
4. 垂直位置在 31% 处，不是居中。居中会更像系统手势条，容易和导航手势混淆。

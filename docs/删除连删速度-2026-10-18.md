# 删除键连删提速（2026-10-18）

## 结论

删除键长按连删从「和滑轨摇杆共用一条曲线」拆出来，单独一条更快的曲线：

| | 旧（摇杆共用） | 新（删除专用） |
|---|---|---|
| 首个间隔 | 110ms（≈9.1 字/秒） | 90ms（≈11 字/秒） |
| 每 tick 递减 | 8ms | 10ms |
| 封底 | 35ms（≈28.6 字/秒） | 30ms（≈33 字/秒） |
| 按住 1.6s 删掉 | ≈23 字 | 31 字 |

长按触发窗口仍是 420ms（与字母键、表情键共用），点按照旧只删一个。

## 改动

- `preview/core.mjs`：新增 `deleteRepeatDelay(step)=max(30, 90-step*10)`；`repeatDelay`/`joystickHoldRate` 原样保留给滑轨。
- `preview/app.mjs`：`scheduleRepeat` 改用 `deleteRepeatDelay`，import 去掉不再使用的 `repeatDelay`；主键盘删除键与选字面板删除钮共用这一处，所以两处同时变快。
- `preview/core.test.mjs`：断言删除曲线起步 90、封底 30，且始终快于摇杆、间隔单调不增。

## 为什么不直接改 `repeatDelay`

`joystickHoldRate` 用同一条曲线算滑轨持续推动的移动速率（≈9.1 字/秒起步、0.8s 封顶 24）。用户这次只要删字更快，改共用曲线会把光标/选区移动也一起加快，属于范围外改动。拆成两条曲线后，滑轨手感完全不变。

## 实测

桌面探针（`preview/index.html` + CDP 触摸，1.6s 按住）：

```
deletes in 1600ms: 31
first-8 gaps: 523,95,78,64,62,47,30,31
last-8 gaps:  31,31,31,31,31,31,31,30
min gap 30 · 600–1600ms 区间 28.0 次/秒
```

`523` 是长按触发前的等待 + 首个间隔，之后按曲线收敛到 30ms 封底。

真机（K60，装机后）：往试用框填入 200 个 `a`，`input swipe` 在删除键上按住 1600ms，读数 **200 → 169**、复测 **169 → 138**，两次都恰好删掉 31 字。说明 30ms 封底在 WebView → 原生 `deleteSurroundingText` 这条链路上没有被丢弃或堆积，节奏与桌面探针一致。

## 回滚

把 `scheduleRepeat` 里的 `deleteRepeatDelay(step)` 换回 `repeatDelay(step)` 即恢复旧速度；`deleteRepeatDelay` 与对应断言可一并删除。

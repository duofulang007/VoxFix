# 应用图标尺寸修正（2026-11-14）

用户反馈：桌面上的 VoxFix 图标「在所有软件中显得太大个，一点都不够高级」。本文件记录实测数据、根因、改法与真机复核。

## 1. 现象与实测

设备实拍（K60 / HyperOS，2026-11-14 用户屏摄），图标白块与黑色图形的像素边界：

| 项 | 实测值 |
| --- | --- |
| 图标白块 | 66 × 66 px |
| 黑色图形（四角框外沿到外沿） | 57 × 57 px |
| 图形占可见宽度 | **86.4%** |
| 四边留白 | 左 3 / 右 6 / 上 6 / 下 3 px（4.5%–9%） |

结论：图形几乎顶满图标，四周留白不足 5%，所以视觉上比同一屏任何图标都「大一号」。

## 2. 根因

自适应图标（adaptive icon）的画布是 **108dp**，但启动器不会显示全部 108dp——它只取中心一部分铺满图标。旧稿按 108dp **全画布**布置图形：图形外沿 57.16dp，占画布 53%，设计意图是克制的。

HyperOS 实际只渲染中心 **66dp**：

```
57.16dp ÷ 66dp = 86.6%   ← 与实拍 86.4% 吻合，误差 0.2pp
```

即设计稿的 53% 被系统放大到 86.6%。这是「按 108dp 全画布设计」的必然结果，不是审美判断失误。

> 66dp 是按旧稿几何反推、并与实拍互证得出的可见区尺寸；Google 文档给的是 72dp 安全区，实际启动器常裁到 66dp 的 keyline 内容区。不同厂商裁切比例可能不同，本机以实测为准。

## 3. 改法

把图形整体按同一比例收敛，使 **66dp 可见区内的占比落在 65.2%**：

```
收敛系数 = 65.2 ÷ 86.6 = 0.7528
```

所有数值由旧稿严格等比换算，没有新增主观取值：

| 项 | 旧稿 | 新版 |
| --- | --- | --- |
| 图形外沿 | 57.16 dp（53.0% 画布） | **43.0 dp**（39.8% 画布 / 65.2% 可见区） |
| 取景框中心线 | 27.63–80.37 | **34.16–73.84**（边长 39.68） |
| 框线宽 | 4.43 | **3.34** |
| 角臂长 | 10.96 | **8.24**（边长 20.8%，比例不变） |
| V 宽 × 高 | 23.62 | **17.78**（边长 44.8%，比例不变） |
| V 笔画 | 5.70 | **4.29** |
| 四边留白 | 25.42 dp（23.5% 画布） | **11.5 dp**（17.4% 可见区） |

构图、比例、圆头描边、V 与框的间隙比全部继承旧稿。低于 32dp 时四角开始融为四个点，是这套构图的下限，与旧稿一致。

## 4. 落地

| 文件 | 改动 |
| --- | --- |
| `res/drawable/ic_launcher_foreground.xml` | 几何按上表收敛，颜色不变（`#FF111111`） |
| `res/drawable/ic_launcher_monochrome.xml` | 同上，供 Android 13 主题图标取 alpha |
| `res/values/ic_launcher_background.xml` | 不变（`#FFFFFFFF`） |
| `res/drawable/ic_stat_voxfix.xml` | 不动。24dp 状态栏小图标本就该顶满，尺寸另算 |

构建：`assembleDebug` 成功（41s，`:app:processDebugResources` 通过）。
安装：`adb install -r -t`，证据目录 `.android/icon-2026-11-14-install/`（装前 APK sha256 `999456a8…c9e78`、默认输入法、包列表均已记录，装后默认输入法仍为 `local.voxfix.debug/.VoxFixImeService`）。

真机复核（`home-next3.png`）：图形居中，四边留白清晰可见，占比与设计值 65.2% 一致，不再顶满。与同屏其他图标视觉重量齐平。

## 5. 备选方案

设计稿 `design/icon/icon-v2.html` 内含四套候选，几何完全相同，只有底色 / 取景框灰度不同：

- **A · 收敛**（已落地）：白底黑标，最小改动
- **B · 分层**：取景框降为 `#9CA1AA`（38% 黑），V 成为唯一主体
- **C · 主色**：`#1677FF` 底 + 白标
- **D · 深色**：`#0F1115` 底 + 浅标

换方案只需替换 `ic_launcher_foreground.xml` / `ic_launcher_monochrome.xml` 的描边色与 `ic_launcher_background.xml` 的底色。

## 6. 页面渲染注意事项

设计稿页面用「只显示画布中心 66dp」的方式模拟真机：容器 `overflow:hidden`，内部 SVG 放大到 `163.64%`（=108/66）并偏移 `-31.82%`。直接看 108dp 全画布会误判比例。

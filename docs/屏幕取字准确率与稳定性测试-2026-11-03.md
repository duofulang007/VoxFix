# 屏幕取字准确率与稳定性测试（2026-11-03）

## 范围与方法

在 USB 连接的 Redmi K60 上，以独立测试 APK 调用与主包相同的随包离线 ML Kit Chinese 16.0.1。
不修改主包、模型、词库或用户数据，不截取用户页面，不读写剪贴板。

新增 `android/screenTextUiTest/src/main/java/local/voxfix/screentest/ScreenTextOcrBenchmark.java`，
使用系统默认字体在内存绘制六组、每组三行的测试文字：普通中文及日期、订单金额与发票号、
英文与邮箱版本号、中文近形字及否定句、地址联系人、财务词汇与数字。
分别用16/24/36/64像素字高和深浅底生成48张不同图片；字号是图片像素，不是屏幕dp。
每张重复五轮，另加每轮两张空白图，共250次。每次新建并关闭识别器，匹配主程序资源生命周期。

准确率只计第一轮48张，合计2488个去空白参考字符，不把重复轮次当成独立语料。
采用Levenshtein字符编辑距离，替换、删除和插入均计错；不对结果猜测改字。
测试文本只有18行，变化来自字号和底色；这些结果不能代表日常页面或复杂排版的总体准确率。

## 准确率

| 指标 | 结果 |
| --- | --- |
| 去空白、保留标点 | 184/2488 字符编辑错误，错误率7.40% |
| 去空白并忽略Unicode标点 | 94/2224，错误率4.23% |
| 三行整图完全一致（保留标点） | 1/48 |
| 16/24/36/64px字符错误率 | 8.20% / 7.40% / 7.40% / 6.59% |
| 浅底/深底字符错误率 | 6.99% / 7.80% |
| 近形字组字符错误率 | 14.53% |

低整图正确率同时受全角标点变半角影响，不应解释成其余47张都无法阅读。
但正文确有近形错字，36px浅底已观察到：屏幕→屏募、请先联系→情先联系、
税率→积率、累计折旧中插入竖线、OpenAI→OpenAl。

数字串连同逗号、小数点逐项比对，45/48张一致；其余三张包括千位逗号遗漏、
`1,200.50`→`1.200.50`，以及财务样本多出数字`1`。
不能用“主要数字没变”推断金额、发票、手机号可免核对。

## 稳定性及边界

两次完整运行共500/500次完成，无识别异常或20秒等待超时；两次准确率相同，48张文字图的五轮输出完全一致，
10次空白图无输出。重复一致也包括重复识错，不表示结果正确。
首轮完整运行耗时21.589秒，OCR任务P50为83ms、P95为110ms、最大215ms。
这些时间从调用识别任务到结果返回，不含截图、绘图、识别器构造、面板展示和人工操作。
五轮P50为81/82/86/82/84ms，没有持续变慢。
每轮结束PSS为155505/102904/166449/165167/161771 KiB；没有单调增长，
短时采样及异步资源释放不足以证明无内存泄漏。

最终自动启动入口复跑250次，耗时21.820秒，P50为83ms、P95为109ms、最大179ms；
五轮P50为81/84/83/83/81ms，轮末PSS为156620/155373/162077/158429/158897 KiB。
本轮10次空白图仍无输出，另一次完整运行也为10/10无输出。

原生控件回归通过：半屏/全屏、跟手拖动与取消/反向、键盘避让、跨行选区、
关闭、大字体、菜单边界、重选失败/空结果保留文字和选区、纯文字恢复、
多指取消及单指恢复、框移动/拉边、细行及移动边界。
它读取当前已安装主包的控件类运行，分离视图检查不等于全局截图流程通过。

测试首次被黑阈强停，系统退出记录为外部force-stop；未计作OCR崩溃。
测试入口增加前台测试页，未修改黑阈/系统设置。MIUI阻止测试包后台拉起页面，
最终由独立测试的UiAutomation启动自己的页面，不访问宿主内容；测试结束关闭页面。
启动器调试及一次由另一控件测试启动而中断的运行，不计入完整运行统计。
最终自动启动入口构建、安装及完整复跑通过，随后串行重跑原生控件通过；测试包已卸载。

## 复跑与证据

使用仓库内JDK/Gradle串行构建`:screenTextUiTest:assembleDebug`并安装独立包后：

```text
adb shell am instrument -w -e benchmark true local.voxfix.screentest/.ScreenTextUiInstrumentation
adb shell am instrument -w -e controlsOnly true local.voxfix.screentest/.ScreenTextUiInstrumentation
```

须等第一条结束再运行第二条，同包instrumentation会互相停止。
原始结果、首次被停止记录、评分脚本及汇总保存在忽略目录
`.android/screen-text-benchmark-20261103/`，不提交用户画面、缓存或APK。

未跑真实截图→框选→复制全链路、90秒全局超时、真实旋转、锁屏恢复、跨App、
长时间后台运行、图片/多列/倾斜/压缩/低对比场景；不据此宣称整体取字已稳定或日常准确率达某百分比。
未改`preview/`，不跑无关网页回归、不重打包分发HTML，分发产物未因本轮变化。

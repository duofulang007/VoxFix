# 屏幕取字录屏黑屏修复

用户需要录制完整操作过程。`ScreenTextOverlay.show()` 为框选与结果共用的全屏窗口设置了 `FLAG_SECURE`，该标记会阻止窗口内容进入截图和录屏。

本轮仅移除该窗口的 `FLAG_SECURE`，保留布局、交互及取字逻辑。其他应用自身的受保护页面仍遵循 Android 限制。

## 验证事实

- `:app:assembleDebug` 构建成功，K60 通过 `adb install -r` 保留数据更新成功。
- 在独立原生检查 `ScreenTextControls` 中增加真实 `show()` 窗口参数断言，防止再次加入禁止录屏标记；测试 APK 构建成功。
- 手机拒绝独立测试 APK 安装（`INSTALL_FAILED_USER_RESTRICTED`），因此新增断言及原生控件回归未执行，不报告通过。
- 本轮未修改 `preview/`，网页分发产物未重新生成。
- 尚未验证用户所用录屏工具的实际视频；安装成功不代表完整录屏已通过。

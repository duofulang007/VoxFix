# 屏幕取字面板与跟手拖动（2026-11-03）

覆盖[弧形工具箱](屏幕取字弧形工具箱-2026-11-02.md)的入口尺寸、结果面板及退出交互。沿用截图、离线OCR、单任务、失效令牌与资源释放；不修改键盘编辑框、八方向盘和语音流程。

## 用户最终约定

- 移除独立“展开”按钮及叉号，只留灰色胶囊、标题“识别结果”、正文、底部“重选 / 全选 / 复制”。有选区时主按钮为“复制选中”，复制成功后返回原页面。
- 竖屏默认约半屏，小屏保留基本编辑空间；胶囊触摸高度48dp，上拖与手指位移一一对应，松手按位置和速度停在半屏或全屏。下拉超过半屏继续约96dp（或足够的下甩速度）关闭；点击面板外、系统返回和无障碍关闭动作也可退出。
- 点按胶囊可切换两档。取消、多指打断不误关闭；原生EditText提供选字、跨行、粘贴、滚动。移除嵌套边框，统一白色面板和正文间距，只有复制为蓝色主操作。
- 键盘出现时扩展可用空间，收起键盘恢复原档；横屏优先正文和操作栏。下拉关闭时，正文、操作栏与遮罩共同跟随，不将按钮留在原位。
- 框选页删除居中说明：框内保持原图亮度、框外变暗；边界限制在图片范围，保留松手后排队移除视图的保护。
- 用户确认保持手机系统三项动画倍率为0，未更改系统设置。手指拖动实时更新，松手后的自动动画直接到位。系统允许动画时，结果面板为240ms原生过渡，侧边菜单展开220ms/收回180ms；本轮不能证明启用动画后的主观手感。

## 入口和窗口

后续按用户反馈降低闲置存在感：去掉弧线白色外描边，闲置为`#407f7f7f`、2dp细线；触摸时为`#b3505660`、2.5dp，松手/取消/第二指打断即恢复。透明窗口仍24×64dp，内滑和长按拖动规则保持。此项覆盖下方早先的轮廓配色，不宣称已精确匹配系统侧边栏颜色。5项入口手势回归及构建通过，已保留数据安装K60；新外观的真实观感待用户确认，未新跑原生控件/跨App测试。

- 细弧可见高度20→28dp，深灰3dp线配浅色轮廓；透明窗口24×64dp。窄窗口减少宿主触摸占用，这不是48dp宽按钮，边缘触发舒适度仍需K60真人判断。
- 菜单可见圆直径42dp，触摸48dp；关闭触摸区补至48dp。整屏用文字页图标，框选用框角图标；左右镜像，修复密度舍入导致的1px溢出。
- 内滑连续呈现，松手展开或归位；长按后仅移动位置。反向从当前进度接续，不从起点重播。
- 针对频繁开关左上角虚影：新窗口首次正确定位和布局前不可见，目标尺寸布局后才显示；移除前先隐藏，取消旧动画及长按回调，禁用额外窗口动画，恢复父级裁剪。控件测试验证这些生命周期约束，实际快速开关残影仍待用户确认。

- [小米侧边栏说明](https://www.mi.com/global/support/faq/details/KA-733477/)：短条内滑展开、长按移动并吸边；说明入口会占用宿主触摸区域。保留细入口，不扩展应用列表。
- [三星Edge说明](https://www.samsung.com/us/support/answer/ANS10002367/)：位置、大小和透明度影响使用便利；本轮不增加设置滑块。
- [Apple Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/)：持续反馈、空间连续、可中断交互。只参考行为，原生Android负责选字和键盘。

官方材料未提供本实现的dp数值或逐帧曲线；尺寸是本项目取舍，不宣称1:1复制。

## 识别排查

独立测试APK在内存生成白底/深底、18/24/36/64/96/128px三行中英数字文字，不读取或截图用户页面。

12张固定图分别比较原图、2倍放大、检测后逐行裁剪并统一高度64px，共36次。忽略空白，每组360个参考字符：Levenshtein编辑错误为原图16（4.44%）、放大18（5.00%）、逐行19（5.28%）；整张三行全部正确分别2/12、1/12、1/12。两项候选无稳定收益且增加耗时，未接入生产。

这些重复短句不能代表日常准确率。已复现“幕/募/暮/慕”“额/颜/领”近形错误，VoxFix及数字金额在本组保持。未加入猜测改字，未通过篡改结果掩盖问题；继续使用随包离线ML Kit Chinese 16.0.1。中文近形错误仍是明确限制，不能写“准确率已正常”。

证据在忽略目录`.android/screen-text-polish-20261103/`。工具`android/screenTextUiTest/`的`ocrOnly=true`和`controlsOnly=true`分别检查固定图与分离原生控件；不向宿主注入触摸、不改剪贴板、不重启输入法。

# 工具栏排序：长按直接拖动（2026-10-18）

## 改了什么

上一版是「长按 450ms → 进入排序模式」：候选栏位置**多出一行**
`拖动图标排序 | 完成 | 长按自定义项无法移除`，工具栏换底色、每格描虚线框，
排完还要再点一次「完成」。那一行正好压在候选区位置，挡视野。

现在没有模式：

- **长按 380ms → 图标直接抬起**（白色底 + 投影 + 1.06 缩放），手指已经在拖了；
- 拖到别的图标上，那一格淡蓝高亮（`--accent-soft` + 1px `--accent` 内描边）；
- **松手即落位**并 `persist()`，没有「完成」按钮、没有提示行、没有 toast；
- 只按住不动再松手＝取消：不换位，也**不触发图标原本的功能**（长按不吃点击）；
- 轻点行为完全不变（点「功能菜单」照旧打开菜单）。

## 几何 / 令牌

- 位置：`#keyboard .toolbar`，高度仍为 `--bar`(45px)，字母键与 footer 不动；
  拖动期间工具栏顶边、`.key-rows` 高度实测不变（回归里逐像素比对）。
- 抬起：`.toolbar-drag`（`--key-bg` 底 + `0 3px 10px #00000024` + `scale(1.06)`）；
  落点：`.drop-target`；自定义项拖出＝`.drop-remove`（浅红底 + danger 描边）。
- 不放过渡动画：拖起来要跟手，动画只会拖慢落位观感。

## 目标与当前实现

VoxFix 是可独立选择的自有 Android 输入法，复刻讯飞小米版的界面与交互，接入本机离线语音。
保留手机上的讯飞小米版 `com.iflytek.inputmethod.miui`。`preview/` 同时是浏览器原型与 APK 内键盘前端；
`voice/` 是电脑离线服务，不能代表手机能力。

- 原生 ARM64 Debug IME：`local.voxfix.debug`，Android 15 / API 35，已在 Redmi K60 安装使用。
- 中文26键使用 librime 1.17.0；个人词库与英文词表由 `stagePinyin` 打包，`preparePersonalData()` 部署。
  个性化选词统一由长期个人词库提供，默认开启，无学习开关或清空控件；支持完整备份/通用文本与合并导入，见[长期词库约定](长期个人词库与迁移-2026-10-17.md)。
- 26键普通候选自然宽度、20px完整文字、横向滑动；匹配剪贴板时右端悬浮入口，整入口点击展开210px连体列表，
  点条目引用、长按编辑。已取消五/六固定格与拖动调位，见[最新候选约定](候选自适应与剪贴板悬浮-2026-10-17.md)。
- 剪贴板支持拆词、连续拖选、最多300条全历史检索和原位搜索；引用与编辑共用「取消 / 拆词 / 保存」编辑框。
- 滑轨只输出左右，短按精调一个字，长按切换锁定/自由；跨行选择用右侧八方向盘。面板保持既定尺寸，支持图标操作与删除。
- 语音使用 sherpa-onnx 1.13.8：Zipformer流式 + SenseVoice二遍整理 + silero VAD + CT-Transformer 标点。
  **SenseVoice 这条 int8 权重不产标点**：固定音频在 `language=zh/auto`×`useITN=true/false` 四种组合下
  输出逐字相同且没有任何标点（疑问句亦然），所以不能把"二遍跑完"当作标点可用。
  标点由独立的 CT-Transformer 离线模型补，它只吃文本、不需要音频，因此尾段直接松手、二遍尚未完成时
  同样生效，松手最多等 150 ms 即退回流式文本，见[标点恢复](语音标点恢复-2026-10-17.md)。
  数字格式转换在统一输出处默认执行，无设置开关；标点必须发生在数字转换之前，否则阿拉伯数字会被模型拆坏。
  明确时间、金额、计量单位复用已有数值解析，流式和最终结果均生效，不等待二遍。模糊口语数值保留原文，
  见[专项](语音数字转换专项-2026-10-17.md)。
  普通打字不加载语音，使用后空闲30秒释放（标点模型随二遍一起回收）；20ms采集，二遍后台整理，松手只采用已完成整理、不等待最后一句。
  二遍按停顿切段：停顿 0.5s 静音才切，提交前先把解码器里最后一块补渲完再重置（否则会丢尾字），
  英文二遍只在词序列可自证时才采用，见[中英混合与英文评测](语音中英混合与英文评测-2026-10-17.md)。
  构建时预优化流式计算图。长按空格300ms进入，上滑取消、松手停麦。见[跟手与冷启动](语音跟手与冷启动优化-2026-10-17.md)。
- WebView固定550dp画布，外层按可见键盘高度裁切，减少编辑区展开时旧画面搬动；主键盘351px。
- 手写与安卓Qwen润色已移除；停用手写源码与测试已删除，历史版本可从Git追溯。
  电脑原型保留离线语音与整理，不恢复模拟器，不另起输入法项目。

## 验证链路

网页交互检查 → APK 构建 → USB 真机。**网页通过 ≠ 原生通过；构建 ≠ 安装；安装 ≠ 真机通过。**

- 网页交互检查：`preview/*.test.mjs`，Playwright + Edge，纯逻辑与几何可无头验证。
- 构建与 JVM 自检：`tools/build_android.ps1`，内部执行 `testDebugUnitTest assembleDebug`；**不自动安装**。
- 真机：先用 `adb forward` 把 IME WebView 的 devtools 端口转到本机，再跑 `preview/*-device.test.mjs`；
  Android 侧改动必须重新 `adb install -r -t` 才算真的上机（构建日志成功不能证明手机上是新代码）。
- 只回归受影响功能；手机操作需要用户实际完成，不能假设通过。破坏性操作先预演再确认。

## 运行与大文件边界

Git 仓库为 `duofulang007/VoxFix`，远端 `https://github.com/duofulang007/VoxFix.git`，私有，主分支 `main`。
只提交源码、脚本、必要文档/许可及浏览器参考图；模型、SDK/NDK、缓存、APK、签名密钥、录屏和生成词库
都不提交（见 `.gitignore`）。提交及同步状态以实际 Git 检查为准。

- `android/app/build/` 是生成产物；APK 在 `android/app/build/outputs/apk/debug/app-debug.apk`。
- `preview/pinyin-data.json`、`preview/pinyin-lite.json` 和根目录 `键盘试用页.html` 是生成数据，
  修改时应追溯生成器（`tools/build_pinyin.py`、`tools/build_preview.py`）。
- `.android/` 保留本机 SDK、NDK、拼音 JNI 与依赖工具，**不含模拟器**；`.model-downloads/` 是下载元数据
  与词库源；`.venv/` 是电脑依赖；`models/` 是运行模型。常规搜索已由 `.ignore` 排除，不要递归阅读。
- 首次克隆后需要另行准备：`.venv`、`models/`（`tools/setup_voice.py`）、`.android/pinyin-rime/`
  （`tools/setup_pinyin_rime.py`）、Gradle/JDK/SDK（`tools/build_android.ps1` 会按固定摘要自动准备）。
  语音计算图预优化使用构建机 `.venv` 中的 `onnxruntime==1.31.0`，依赖固定在
  `tools/streaming-optimization-requirements.txt`；Gradle自动生成并校验 `.android/streaming-optimized/`，不提交模型或缓存。
- 模拟器及其系统镜像、AVD 已按要求移除（合计约 16 GiB），**不要为网页/USB 工作流重新安装模拟器**。

## 当前真实状态

- 独立 ARM64 原生 Debug 应用 `local.voxfix.debug` 已安装在 Redmi K60，Android 15 / API 35。
- 手机录音、离线中文识别、录音停止后整段标点与 Qwen 本地自动整理已跑通指定场景。

- 原生输入法服务已实现并安装，用户已选择 VoxFix。初次语音失败证据保留；修正版实时 ASR composing 上屏、松手补标点/数字格式、退出动画及上滑取消按用户反馈通过，笔记/聊天及断网指定场景也按反馈通过。最终常用 26 键修正版再次获得语音功能保留反馈。
- K60 自建试用框通过真实拼音组合、中文选词替换、英文/空格、连续数字、拼音接标点和长按删除检查；固定测试文字已清理。源码自检 14 项、0 失败；手写固定“一”笔画/边界拒绝、ASR 加载、数字规范化的 ARM64 探针通过。手写真人准确率、全部工具细节及整体像素级复刻未验收。两个讯飞包保持不变，不盲调提示词或重复长模型测试。

## 运行与大文件边界

Git 仓库为 `duofulang007/VoxFix`，远端为 `https://github.com/duofulang007/VoxFix.git`，私有仓库，主分支 `main`。只提交源码、脚本、必要文档/许可及浏览器参考图；模型、SDK/NDK、缓存、APK、签名密钥、录屏和生成词库不提交。提交及同步状态以实际 Git 检查为准。

用户最新要求：后续采用网页交互检查 → 原生 APK 构建 → USB 真机验证，不再使用安卓模拟器/桌面安卓系统。网页通过不等于原生功能通过，原生服务、录音和跨 App 输入仍需编译与真机验证。模拟器程序、系统镜像及 AVD 可从日常开发环境移除；AVD 用户数据与快照删除前须确认不再需要。SDK 编译组件、ADB、NDK、签名密钥、源码与运行模型保留。

2026-10-10 用户明确要求“开始删除”后，已移除 `.android/avd`、`.android/sdk/system-images`、`.android/sdk/emulator`，按删除前文件大小合计 12,235,944,019 字节（约 11.40 GiB）。删除前确认无运行中的模拟器、目标和目录内均无重解析链接；删除后核对三个目标不存在，SDK 编译组件、ADB、NDK、签名密钥、源码与模型仍在。旧模拟器入口不再用于日常开发；不要为网页/USB 工作流重新安装模拟器。

随后按用户要求继续精简，清除已安装工具/模型的下载压缩副本、旧模拟器原生测试产物、旧 APK、重复资产及可重建的构建/转换缓存，再减少 5,138,521,394 字节（约 4.79 GiB）。项目文件总大小降至约 5.69 GiB；保留原始模型、词库源、NDK/SDK/ADB、签名密钥、Gradle 原始依赖、最新 APK 和已编译 JNI。`build_android.ps1` 已改为校验并复用已安装工具，避免清掉压缩档案后每次构建都重新下载；安装摘要保存在相应工具目录的 `.voxfix-source-digest`。源码变更后的正常编译会重新生成必要缓存。

运行 `tools/build_android.ps1` 构建及自检；APK 为 `android/app/build/outputs/apk/debug/app-debug.apk`。构建不自动安装。

`.android/` 现在保留本机 SDK、NDK、第三方源码及必要依赖，不再含模拟器；`.model-downloads/` 主要保留下载元数据和词库源；`.venv/` 是电脑依赖；`models/` 是运行模型。这些不是需要逐个阅读的项目代码，常规搜索已由 `.ignore` 排除。`android/app/build/` 是生成产物，`preview/pinyin-data.json` 和根目录独立HTML为生成数据，修改时应追溯生成器。

AVD 的 userdata 和快照可能含浏览器状态，不自动删除。源码、模型、依赖工具与验收证据都保留；只清理确认可重建的缓存。

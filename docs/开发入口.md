## 当前目标

VoxFix 是安装后可在系统中独立选择的自有输入法，复刻讯飞小米版的界面与操作体验，并接入本机离线语音。
目标不是向现有讯飞包内部集成功能；手机上两个讯飞包保留不动，历史“讯飞集成”表述属于此前记录。

分阶段内容与约束见 [原生输入法分阶段执行计划](原生输入法分阶段执行计划.md)。

## 当前真实状态（2026-10-13）

- 独立 ARM64 原生 Debug 输入法 `local.voxfix.debug`（Android 15 / API 35）已安装在 Redmi K60，
  并被选为当前输入法。键盘前端就是 `preview/` 的原型，构建时按清单打包进 assets，由原生 WebView 承载。
- 26 键中英文、大小写、数字与符号、剪贴板、常用语、表情、键盘选择、夜间模式均已落地；键盘高度、
  字号、间距、圆角与背景按官方截图固定，不再提供尺寸自定义。
- 中文拼音走原生 **librime 1.17.0**：`PinyinEngine.kt` + `cpp/rime_jni.cpp` → `libvoxfix_rime.so`，
  词库为 luna_pinyin 加个人词条，并保留 speller `algebra` 简拼修复。**个人词库与英文词表必须由
  `stagePinyin` 打包，再由 `preparePersonalData()` 落到 `filesDir/pinyin-personal/`**，否则 schema
  编译失败、引擎不可用（症状是前端静默回退，而不是报错）。词库扩容试过 rime-ice 但长句退化，已回退。
- 语音走 **sherpa-onnx 1.13.8**：Zipformer 中英流式（第一遍，边说边进输入框）+ SenseVoice 第二遍
  （松手后整段补标点与数字格式）+ silero VAD 断句。长按空格门槛 300ms，上滑取消、松手结束，
  不新增确认提交或暂存面板。
- 底部滑轨：碰一下就无级拖动宿主输入框光标；按住约 350ms 进入框选，松手保留选区并由输入框自己弹
  复制/粘贴浮框；切入选区时给一次系统轻触感。按键不再弹放大字母气泡。
- **手写已停用**（2026-10-11）：源文件在 `android/disabled-handwriting/`，模型与运行库不打包，
  手机键盘不再展示手写布局，旧的手写布局会自动迁移到 26 键。
- **安卓端本地大模型整理（Qwen）已移除**，手机上不再保留 GGUF 模型；独立输入法不阻塞上屏、不调用大模型。
- 桌面原型（`preview/` + `voice/`）仍在，用于网页交互检查与电脑端试验；它保留手写与本地整理，
  但**不代表手机原生能力，也不是当前主线的验收依据**。

验收事实在 [USB真机验收](USB真机验收.md) 与 [现有功能问题清单](现有功能问题清单.md)；
当前未解决项以后者为准。历史网页记录不作为安卓完成状态。

## 验证链路

网页交互检查 → APK 构建 → USB 真机。**网页通过 ≠ 原生通过；构建 ≠ 安装；安装 ≠ 真机通过。**

- 网页交互检查：`preview/*.test.mjs`，Playwright + Edge，纯逻辑与几何可无头验证。
- 构建与 JVM 自检：`tools/build_android.ps1`，内部执行 `testDebugUnitTest assembleDebug`；**不自动安装**。
- 真机：先用 `adb forward` 把 IME WebView 的 devtools 端口转到本机，再跑 `preview/*-device.test.mjs`；
  Android 侧改动必须重新 `adb install -r -t` 才算真的上机（构建日志成功不能证明手机上是新代码）。
- 只回归受影响功能；手机操作需要用户实际完成，不能假设通过。破坏性操作先预演再确认。

## 运行与大文件边界

Git 仓库为 `duofulang007/VoxFix`，远端 `https://github.com/duofulang007/VoxFix.git`，私有，主分支 `main`。
只提交源码、脚本、必要文档/许可及浏览器参考图；模型、SDK/NDK、缓存、APK、签名密钥、录屏和生成词库
都不提交（见 `.gitignore`）。提交及同步状态以实际 Git 检查为准。

- `android/app/build/` 是生成产物；APK 在 `android/app/build/outputs/apk/debug/app-debug.apk`。
- `preview/pinyin-data.json`、`preview/pinyin-lite.json` 和根目录 `键盘试用页.html` 是生成数据，
  修改时应追溯生成器（`tools/build_pinyin.py`、`tools/build_preview.py`）。
- `.android/` 保留本机 SDK、NDK、拼音 JNI 与依赖工具，**不含模拟器**；`.model-downloads/` 是下载元数据
  与词库源；`.venv/` 是电脑依赖；`models/` 是运行模型。常规搜索已由 `.ignore` 排除，不要递归阅读。
- 首次克隆后需要另行准备：`.venv`、`models/`（`tools/setup_voice.py`）、`.android/pinyin-rime/`
  （`tools/setup_pinyin_rime.py`）、Gradle/JDK/SDK（`tools/build_android.ps1` 会按固定摘要自动准备）。
- 模拟器及其系统镜像、AVD 已按要求移除（合计约 16 GiB），**不要为网页/USB 工作流重新安装模拟器**。

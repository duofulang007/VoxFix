## 目标与当前实现

VoxFix 是可独立选择的自有 Android 输入法，复刻讯飞小米版的界面与交互，接入本机离线语音。
保留手机上的讯飞小米版 `com.iflytek.inputmethod.miui`。`preview/` 同时是浏览器原型与 APK 内键盘前端，
语音只在原生 `DesktopSpeechEngine.kt` 侧真实运行；桌面语音服务已于 2026-10-18 删除，不能再拿电脑端结果当手机能力。

- 原生 ARM64 Debug IME：`local.voxfix.debug`，Android 15 / API 35，已在 Redmi K60 安装使用。
- 中文26键使用 librime 1.17.0；个人词库与英文词表由 `stagePinyin` 打包，`preparePersonalData()` 部署。
  全拼、首字母简拼与混拼共用同一词库召回，数字页符号栏可滚动但不显示滚动条，见[简拼与隐藏滚动条](简拼与隐藏滚动条.md)。
  个性化选词统一由长期个人词库提供，默认开启，无学习开关或清空控件；支持完整备份/通用文本与合并导入，见[长期词库约定](长期个人词库与迁移-2026-10-17.md)。
  现已加入个人语音词典（`VoiceDictionary.kt`，`files/voice-dictionary.json`，与电脑版 `dictionary.json` 同格式）：
  记录「词 / 错法」，由功能菜单「词典」页编辑，1:1 复刻桌面模块（竖屏改为主从两页）。它与拼音候选记忆
  （`entries`）是两套独立来源，互不写入。见[模块与精简记录](桌面词典与CTC热词救援迁移-2026-10-25.md)。
  自动改字学习（`VoiceLexicon`/`VoiceCorrectionTracker`/`VoiceEditExtractor`）已按用户决定删除，
  仅留作历史，见[归档索引](archive/README.md)。
- 26键普通候选自然宽度、20px完整文字、横向滑动；匹配剪贴板时右端悬浮入口，整入口点击展开210px连体列表，
  点条目引用、长按编辑。已取消五/六固定格与拖动调位，见[最新候选约定](候选自适应与剪贴板悬浮-2026-10-17.md)。
- 剪贴板支持拆词、连续拖选、最多300条全历史检索和原位搜索；引用与编辑共用「取消 / 拆词 / 保存」编辑框。
- 笑脸入口已接[表情包同屏搜索](表情包同屏搜索-2026-10-19.md)：分组、相关标签、Emoji/颜文字和整行标签均已移除，仅留搜索框与图片；搜索框、结果与自有键盘同屏，停顿300ms自动查询。图源按用户选择暂留搜狗，微信 App 内同源尚未确认，真实触控及微信/QQ 图片接收待验。
- 滑轨只输出左右，短按精调一个字，长按切换锁定/自由；跨行选择用右侧八方向盘。编辑框完整保留，仅删除正文黄色标记/水滴绘制，见[更正记录](移除框选浮层-2026-10-29.md)。
  到文本首尾再继续推不会把焦点送出输入框（根因与宿主方向键处理见[滑轨越界](滑轨光标越界-宿主方向键.md)）。
- 工具栏长按 380ms 图标直接抬起，拖到别的图标上松手即落位并持久化；没有排序模式、提示行或「完成」按钮，
  见[工具栏长按拖动](工具栏长按拖动排序-2026-10-18.md)。
- 删除键与面板删除钮按住走独立连删曲线（90ms 起步到 30ms 封底），滑轨仍走摇杆分档速度，
  两条曲线互不影响，见[删除连删速度](删除连删速度-2026-10-18.md)。
- 语音现行为 sherpa-onnx 1.13.8 + 桌面R5 SenseVoiceSmall INT8（2线程、自动语种、ITN关闭）+ silero VAD + CT-Transformer标点。
  独立模块位于 `android/app/src/voice/`，由 `DesktopSpeechEngine.kt` 运行；`VoiceRecorder.kt` 与 `PcmCapture.kt` 负责原生采音。
  - 长按空格240ms、上滑取消、松手结束不变；20ms采音按100ms进入VAD。VAD采用桌面整套参数：阈值0.30、语音最短0.12s、静音0.65s、最长4s，前后补400ms。
  - 550ms后可出草稿，每350ms更新；旧草稿覆盖、定稿优先。松手完成最终识别后直接提交，不再使用旧420ms二遍迟到改写窗口。每3分钟内部接续、麦克风不停；键盘出现即预热，空闲5分钟释放（演示宿主 `MainActivity` 为30秒）。
  - 标点仅允许增加标点，不改正文/否定/数字；保持桌面ITN关闭，不额外套旧手机版的数字格式转换。
  - 语音文本层只剩一条管线：定稿 → CTC 救援（`boost=3.0`，惰性会话、闲置释放）→ 个人词典替换 → 标点。
    个人词典是 `files/voice-dictionary.json`（与电脑版 `dictionary.json` 同格式），由功能菜单「词典」页编辑
    （列表 + 词/错法，1:1 复刻桌面，竖屏改为主从两页）。旧自动改字学习、`voice_words`/`voice_corrections`
    运行路径、`voice_rules` 与旧双遍引擎已删除；186 条语音词语/196 条学习记录留在库里作档案。
    拼音候选记忆仍是 `entries`（librime）。键盘出现即预热 R5（K60 约 2.7–3.3 s），空闲 5 分钟或后台回收。
    见[模块与精简记录](桌面词典与CTC热词救援迁移-2026-10-25.md)。日常音频和转写不留档。
  - 主包只打包R5、词表、VAD和标点，不含Zipformer；`tools/prepare_desktop_voice.py`导入本机R5并核验4个资产。
  - 接线、构建及装机事实见[接入记录](桌面R5语音接入与安装-2026-10-25.md)，前期对照见[实时模块验证](桌面语音实时模块与VAD验证-2026-10-25.md)。旧双遍配置与验收保留在[历史链路](archive/安卓双遍语音链路-2026-10-25迁移前.md)，不再作为主包配置依据。
  - 完整准确率与速度的历史基线见[ASCEND 1314 条真机评测](语音ASCEND真机评测-2026-10-25.md)：整句 654/1314、首字 716ms、松手 185ms。2026-10-26 已修复标签清洗、送字隔离、取消与词典保护；定向短句恢复 14/15，另 1 条英文仍失败，未重跑完整 1314 条，见[本轮修复与边界](语音送字与词典审计修复-2026-10-26.md)。复跑用 `tools/prepare_ascend_eval.py` + `tools/score_ascend_eval.py`（计分直接复用桌面 `p0_score`）。

- WebView固定550dp画布，外层按可见键盘高度裁切，减少编辑区展开时旧画面搬动；主键盘351px。
- 横屏独立适配：键盘约 258dp、字母区约 696dp 居中、不保留竖屏底栏，上方是宿主全屏编辑区；
  窗口边界、高度与页面可见状态随旋转恢复，删除后的文本同步已修，见[横屏适配](横屏适配-2026-10-25.md)、
  [删除显示不同步](横屏删除显示不同步-2026-10-25.md)与[稳定性检查](横屏稳定性检查与优化建议-2026-10-25.md)。
- 手写与安卓Qwen润色已移除；停用手写源码与测试已删除，历史版本可从Git追溯。
  桌面语音服务 `voice/`、`preview/voice.mjs` 与 `tools/validation_server.py` 于2026-10-18整簇删除，
  语音只在原生侧真实运行。网页试用页已与手机功能面对齐：电脑语音服务、离线整理、语音热词、长句词库与
  录屏对照均从页面移除，语音在网页侧只做交互演示。不恢复模拟器，不另起输入法项目。

## 验证链路

网页交互检查 → APK 构建 → USB 真机。**网页通过 ≠ 原生通过；构建 ≠ 安装；安装 ≠ 真机通过。**

- 网页交互检查：`preview/*.test.mjs`，Playwright + Edge，纯逻辑与几何可无头验证。
- 构建与 JVM 自检：`tools/build_android.ps1`，内部执行 `testDebugUnitTest assembleDebug`；**不自动安装**。
- 真机：先用 `adb forward` 把 IME WebView 的 devtools 端口转到本机，再跑 `preview/*-device.test.mjs`；
  Android 侧改动必须重新 `adb install -r -t` 才算真的上机（构建日志成功不能证明手机上是新代码）。
- 只回归受影响功能；手机操作需要用户实际完成，不能假设通过。破坏性操作先预演再确认。

## 运行与大文件边界

Git 仓库为 `duofulang007/VoxFix`，远端 `https://github.com/duofulang007/VoxFix.git`，私有，主分支 `main`。
只提交源码、脚本、必要文档/许可及浏览器参考图；模型、SDK/NDK、缓存、APK、签名密钥、录屏和生成词库
都不提交（见 `.gitignore`）。提交及同步状态以实际 Git 检查为准。

- `android/app/build/` 是生成产物；APK 在 `android/app/build/outputs/apk/debug/app-debug.apk`。
- `preview/pinyin-data.json`、`preview/pinyin-lite.json` 和根目录 `键盘试用页.html` 是生成数据，
  修改时应追溯生成器（`tools/build_pinyin.py`、`tools/build_preview.py`）。
- `.android/` 保留本机 SDK、NDK、拼音 JNI 与依赖工具，**不含模拟器**；`.model-downloads/` 是下载元数据
  与词库源；`.venv/` 是电脑依赖；`models/` 是运行模型。常规搜索已由 `.ignore` 排除，不要递归阅读。
- 首次克隆后需要另行准备：`.venv`、`models/`（公共VAD/标点由 `tools/setup_voice.py` 准备，本机R5由 `tools/prepare_desktop_voice.py --source <R5目录>` 导入）、`.android/pinyin-rime/`
  （`tools/setup_pinyin_rime.py`）、Gradle/JDK/SDK（`tools/build_android.ps1` 会按固定摘要自动准备）。
  主包直接打包固定R5 INT8资产；流式 Zipformer 与图预优化流程（`prepare_streaming_models.py`）已随双遍引擎删除，不再是构建依赖。模型和缓存不提交。
- 模拟器及其系统镜像、AVD 已按要求移除（合计约 16 GiB），**不要为网页/USB 工作流重新安装模拟器**。

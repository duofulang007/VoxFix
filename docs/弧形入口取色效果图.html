v2 对调说明：原先把原生的「常态 #b3c7c7c7」当作待机、「拖动 #ff979797」当作激活， 但在中亮度的彩色壁纸上，#b3c7c7c7（199）比背景亮、更跳眼，#ff979797（151）比背景暗、更沉。 对调后待机取沉的、激活取跳的，才符合直觉。同时这让三档方案统一成同一规律：激活一律比待机更亮或更实， 不再出现中档反向。

为什么用中性灰：系统侧边栏三档色全部是 R=G=B（#979797 / #c7c7c7 / #ffffff）， 只靠不透明度区分状态，所以放在任何壁纸上都不串色。现状激活色 #505660 蓝通道比红高 16，属于冷调灰， 叠在暖色或绿色壁纸上会被读成「脏」。状态差异改由 明度 + 线宽 表达（待机 2dp → 激活 2.5dp）。

注意：Android 的 #AARRGGBB 与 CSS 的 #RRGGBBAA 字节序相反，本页色值已换算成 rgba() 渲染；写回 Kotlin 时用左列 Android 原值。

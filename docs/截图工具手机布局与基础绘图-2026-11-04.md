# 截图工具手机布局与基础绘图

## 范围

用户要求：手机全平铺不能横向溢出，叠放箭头不能额外占宽，必须保留实际编辑空间；明确授权新增箭头、矩形、画笔，操作风格沿用 Snow Shot。后续再次明确：其他绘图与截图动作先给候选清单，选定后再添加。候选及上游两类布局说明见[工具候选](archive/design/SnowShot工具候选-2026-11-04.md)。

本轮没有增加打码、高亮、聚焦、文字标注、序号、橡皮或水印；也没有将绘制/截图动作两类独立配置计划冒充完成。当前仍共用一份布局，之后拟以切换页复用同一中央工作区，而非同时铺两块编辑器。

## 已实现

- 自定义区：按当前可用宽度换行，每行内部堆叠列仍底边对齐；横向不滚动、不缩小图标。顺序仍是一条持久化序列，跨行只是呈现变化，不重排或删除用户配置。
- 编辑空间：顶部固定，中央独立可滚动工作区，底部固定隐藏托盘。高堆叠在工作区内部滚动，拖到上下边缘自动滚动；隐藏托盘可单独滚动，不再被高列挤出屏幕。保留原来的蓝色横/竖落点、直接拖动和重置，不加说明文字。
- 截图工具组：主栏只占一个32dp工具位，角落5dp三角表示有子工具，删除原本额外24dp的下箭头按钮。点整枚图标展开48dp触摸格的图标网格，选择后主入口图标跟随所选工具。单工具直接执行。
- 展开面板：限宽、限高、垂直可滚动，优先放在选区外；满屏选区无外部空间时，最多占可用高度约四分之一，且不超过200dp。外部点按与返回先收起选项，不穿透去重新框选。
- 基础绘图：在选区内画直箭头、矩形、自由画笔；红/黄/绿/蓝/黑/白及2/4/8线宽放在独立第二栏。选中工具高亮，同工具再次选择或返回可退出绘图。选区边界裁剪笔迹；多指/取消丢弃未完成的一笔。
- 历史与导出：绘图历史与OCR文字历史分开。非文字编辑时撤销/重做操作笔迹，文字编辑时保持原有文字历史。保存固化已完成笔迹，支持原图及OCR编辑后图片；不改源位图。原图对照、译文重排和文字编辑时暂隐笔迹，回到原文后恢复，避免遮挡编辑内容或误叠到重排译文上。

图标来自固定 Snow Shot 1.1.8 提交 `afdc340b14e7f92a294a95c374d13ada0d8c7a82` 的 `tool-arrow.svg`、`tool-rectangle.svg`、`tool-free-draw.svg`，原始文件与已有许可留在APK的 `assets/licenses/snow-shot/`。Android绘图逻辑独立实现，没有粘贴Qt画布代码。

## 代码

- `ScreenshotToolbarEditor.kt`：换行几何、固定编辑工作区和隐藏托盘。
- `ScreenshotToolGroupView.kt`：无额外箭头宽度的组入口。
- `ScreenshotCaptureOverlay.kt`：组网格、选区避让、第二栏、工具激活、导出与历史路由。
- `ScreenshotDrawing.kt` / `ScreenshotDrawingLayer.kt`：会话内绘图历史、原图坐标、触控、渲染及导出。
- `ScreenshotToolbarState.kt` / `ScreenshotToolbarLayout.kt`：绘图可用状态、新工具迁移。已有顺序和隐藏配置保留，缺少的新工具成组补入。

## 验证与边界

- 16项定向JVM：布局6、状态8、绘图历史2；构建与K60保留数据安装完成。
- K60控件回归包含全平铺320/360/411/640dp无越界、紧凑组宽度、组网格边界及返回、高堆叠360dp短屏下工作区与固定托盘。
- 绘图使用真正视图层级分发触摸，覆盖箭头、反向矩形、画笔、取消、撤销/重做、换色/线宽、文字编辑时让出画面及导出像素。合成图片与假OCR输入不代表真人绘制或真实OCR/翻译端到端通过。
- 当前未实现单个图形的选中、移动、缩放与重新调色，也未实现椭圆/曲线箭头等完整桌面子模式。笔迹属于未保存截图会话，未加入旋转/超时后的笔迹恢复；主动保存后才固定到图片中。
- 本轮未改 `preview/`，未重跑网页回归或重新打包分发页；不把前轮38套结果冒充本轮验证。现有前端未提交改动保留。

证据保留在忽略目录 `.android/toolbar-mobile-delivery-build-20261104.log`、`toolbar-mobile-delivery-device-20261104.log`、`screenshot-toolbar-mobile-flat.png`、`screenshot-drawing-mobile.png` 与 `screenshot-drawing-export.png`。真人手感、真实全局工具组/键盘交替仍待验。

# 截图工具条可操作性重构（2026-11-14）

## 1. 用户反馈（原话要点）

- 一级栏的「文本输入」按钮**没有框线**，手机上很难找到。
- 文本的二级工具栏（颜色 / 字号 / S M L XL / 默认 / B I 对齐 / 0px / 圆角 / 线型）**太复杂、页面太大**，屏幕就这么点。
- **没有滚轮，字号没法调**，需要可用的 UI。
- 「很多二级工具栏连 80% 复刻都没达到」。
- 字体切换**点不动、点不进去**。

## 2. 调查结论：不是缺功能，是形态走偏

| 维度 | Snow Shot 1.1.8（原版，Qt） | 改造前手机实现 |
|---|---|---|
| 二级栏 | **一条横向 property row**：28dp 格 / 4dp 格间 / 组间 8dp（`screenshottoolpalette.cpp:196-211`） | 320dp 宽纵向卡片，TEXT 11 行 × 44dp ≈ **484dp**，面板上限 280dp → 必须纵向滚 |
| 参数细节 | 收在弹层（ColorEditor / StrokeEditor / FillEditor / IconOptionEditor） | 全部平铺成整宽 44dp 行（描边色、填充色、3 纹理、5 底色、2 行对齐） |
| 字号 | `30 px` 摘要按钮点击循环 + 4 个 S/M/L/XL **图标** + 可搜索字体下拉 | chip「字号 42」→ 弹 360×240dp 数字面板；四档是**文字**「24/30/42/54」 |
| 一级栏按钮 | 未选中**完全透明**，靠鼠标 hover 出浅底提示可点 | 同样透明 —— 触屏没有 hover，等于一排看不见边界的图标 |
| 选中态 | antd `Tonal`：浅主色底 + 主色图标，**无描边**（`button_style.cpp:418-430`） | 实心 `#1677FF` 蓝底 + 白图标（语义相反） |
| 热区 | 鼠标无此概念 | 视觉 32dp / 热区 44dp（低于安卓 48dp 最小目标） |

一句话：**把桌面版的「弹层」压平成了「纵向长卡片」**，于是面板又高又碎，每一项都要滑着找。

## 3. 改动

### 3.1 统一度量与色值

新增 `ScreenshotToolbarMetrics.kt`：`ScreenshotToolbarMetrics`（dp 唯一来源）、`ScreenshotUiTokens`（色值，收敛了 `#1C1C1E`/`#1F1F1F`、`#1677FF`/`#1668DC` 这类漂移）、`ScreenshotStyleBounds`（圆角 0–83、描边宽 0–12、箭头比例 10–30、水印角度 ±90、间距 10–200）。字号仍只由 `ScreenshotFontSize` 提供（6–256 / 6–512），不开第二套口径。

### 3.2 一级栏：「找不到 T」的直接解法

`ScreenshotCaptureOverlay.Action`：

- **常驻 1dp 淡描边 `#26FFFFFF`**（手机侧扩展：原版靠 hover 提示，触屏只能常驻）。
- 选中态回到原版语义：`#15325B` 浅主色底 + **主色图标** + 1dp `#991677FF` 描边。
- `RippleDrawable(color, content, mask)` 的 **mask 改成圆角矩形**——改造前 `mask=null`，水波是方块，圆角处溢出。
- 背景改为**预建两份**，只在状态切换时换对象，不再每次 `drawableStateChanged` 都 new。
- 32dp 格 + 4dp 内边距**保持不变**（`ScreenshotParityFoundationSmoke:73-74` 锁死；描边只画在 background 里）。

`ScreenshotTouchTargets`：固定外扩 6dp（32→44dp）改为**按子 View 实际尺寸补足到 48dp**（32→48、28→48、44→48）。布局尺寸不变，所以几何断言全部不受影响。

### 3.3 二级栏：回归一条横向属性行

新增 `ScreenshotStyleRow`（40dp 行 / 28dp 格 / 4dp 格间 / 组间 8+1+8 / 横向滚动 + **右缘渐隐与箭头**）。没有渐隐提示，等于把「纵向找不到」换成「横向找不到」。

- `Pen / Line / Shape / Arrow / Spotlight` 改成继承它，多个 group 压成一行；contentDescription 一字未改。
- `TEXT+SERIAL` 搬到新文件 `ScreenshotTextControls`，`FILTER+HIGHLIGHT` 搬到 `ScreenshotAreaControls`，`ScreenshotDrawingControls` 退化为派发器（283 → 约 130 行）。
- 描边 / 填充 / 对齐收进 `ScreenshotStylePopups`（单触发器 + 锚点弹层），弹层落点用新纯函数 `ScreenshotPopupPlacement`（下方优先 → 上翻 → 四边夹取）。
- 水印 11 行 → 1 行；`secondaryMaxHeight` 280dp → **120dp**。
- `refresh()` 保存并恢复横向 `scrollX`，否则每改一次样式就跳回行首。

### 3.4 数值：加减步进替代滚轮

新增 `ScreenshotStepper`（`[ − ][ 读数 ][ + ]`）+ `ScreenshotStepperMath`（纯函数）：

- 按下即走一步；**400ms 后每 80ms 一步**；tick 0–11 ×1、12–29 ×2、30+ ×4。
- 400ms < 系统 500ms 长按时长，手上有反馈就不会误判成「长按手势」；80ms 与项目已定的删除连删曲线同一手感量级。
- 读数格点击 → 原有精调面板；**保留滚轮分支**（设备套件用它验证 ±1）。
- 事务：按住期间只 `previewStyle`（不触发 `changed()`，否则控制栏重建会把正在按的 View 摘掉），抬手一次 `finishStylePreview(true)` = 一条 undo。
- 接入：字号、描边宽、圆角、箭头比例、水印字号/角度/间距。`ScreenshotDrawingLayer` 补了 `watermarkPreview` 通道（`setWatermark` 每帧都 `history.commit`，按住期间不能调）。

序号**没有**换成步进：范围跨到 `Long.MAX_VALUE`，保留原 chip + 滚轮更安全，文案「序号 N，可滚轮调整」也不动。

### 3.5 字体切换点不动

三层修法（缺一层就复现）：

1. **焦点不能落在搜索框**：弹窗 focusable 时系统把焦点给第一个可获焦子 View（就是 `EditText`），输入法随之拉起（本机默认输入法就是 VoxFix 自己），盖住列表下半部。对照 `ScreenshotColorPicker` 调了 `panel.requestFocus()`，字体面板原本没有 → 现在面板 `isFocusableInTouchMode` + `requestFocus()`。
2. **弹窗不主动要输入法**：`INPUT_METHOD_NOT_NEEDED` + `ADJUST_NOTHING`，只在用户点搜索框时 `showSoftInput`。
3. **高度弹性**：列表按屏高 40% 收缩（至少 160dp），不再固定 240dp。

附带：`Gravity.CENTER` 改锚点定位；顶部加「当前：xxx / Mixed（多选）」提示行；暴露 `panelForTest` / `lastPlacement` 供设备断言。

## 4. 其他模块的同类问题

| 模块 | 问题 | 处理 |

| 一级栏 23 工具折 4 行只露 2 行 | 保存 / 复制 / 撤销要纵向滚才够得到 | 加下缘渐隐（滚到底自动消失）；**不改工具集合与行数** |
| MOVE 选区操作 | 两行 36dp 塞进 80dp 容器 | 行高 40、容器 88、草稿格 98→100 |

| 录制条 / 录制标注 | 36×32、30dp、40×34 三套尺寸 | 后续；标注层复用 `ScreenshotDrawingControls`，本轮自动受益 |

# 截图文字保留修复（2026-11-03）

## 修复

侧边圆弧当前打开的是 `ScreenshotCaptureOverlay`，但 `ScreenTextService.retainText()` 原先只从旧 `ScreenTextOverlay` 读取状态，导致截图工具在旋转或退出编辑后空闲90秒时直接清空会话。

现在先从截图工具获取原文、已完成译文及各自选区，取消未完成任务并使迟到回调失效，再移除截图窗口、释放截图与翻译模型，复用纯文字面板继续编辑/复制。有两份草稿时，标题右侧可切换原文/译文；再次旋转仍保留两份修改。生成中的译文不作为完整草稿保留，回到原文。正在编辑时沿用延后超时的规则。

不增加磁盘草稿或截图历史。主动退出、锁屏、服务销毁仍结束会话；不能保证进程异常终止后恢复。释放截图后的面板不能保存图片或重选，需要返回原页重新截图。

# 截图面板一比一复刻（深色主栏 + 选区第二栏）

日期：2026-11-04。参照用户所装 Snow Shot 1.1.8（固定提交 `afdc340b14e7f92a294a95c374d13ada0d8c7a82`）的两行工具条截图。本轮把主栏改成深色实心按钮，补齐选区第二栏的 12 个图标控件，并修掉选中"选择元素"时出现的空白色条。

## 设计基准

| 项 | 规格 |
| --- | --- |
| 面板 | `#1C1C1E`，圆角 8dp，无描边 |
| 按钮 / 图标 | 32dp / 24dp，间距 8dp |
| 默认图标 | `#FFFFFF` |
| 禁用图标 | 40% 白 |
| 激活 | 蓝底 `#1677FF`，圆角 6dp，白图标 |
| 分隔线 | `#3A3A3C`，1×16dp，左右 12dp（第二栏 8dp） |
| 关闭 | `#FF4D4F` |
| 拖动柄 | 18dp 宽，六点，`#8C8C8C` |

分组角标（工具组右下三角）由 `#A0000000` 改为 70% 白：深色底上原来的黑色三角看起来像图标被啃掉一块。

## 主栏

- 新增六点拖动柄：按住可把整条工具栏拖到任意位置，位置在会话内保持并钳制在安全区内；拖动开始时收起已展开的工具组面板。这是用户报的"编辑控件被工具栏遮挡"的直接解法。
- 分享图标由系统 `ic_menu_share`（灰色、风格不一致）换成自绘白色分享图标；工具栏设置页同步。
- 长截屏、录屏：新增动作与图标，常显，点击提示"暂未支持"。按用户要求只占位。
- "选择图形"更名"选择元素"，与 Snow Shot `Select elements` 对齐。
- 新增"编辑选区"（四向箭头）动作，激活后进入选区编辑模式并展开第二栏。

## 选区数据模型

新增 `ScreenshotRegion`：若干轴对齐矩形，支持并集、差集、外接框、外轮廓路径与导出遮罩。

- 外接框 `bounds` 继续充当 OCR、绘图层、保存视口与贴图的矩形参数，下游零改动。
- 真正多块时导出按区域遮罩（`PorterDuff.CLEAR` 清掉区域外像素），保存时强制合成位图，避免保存链路退回整块矩形。
- 已知边界：截图工程文档的 `viewport` 仍是外接矩形，重开工程后不规则形状退化为矩形。这不影响标注对象，仅影响"洞"的保留。

## 空白色条（用户报的 bug）

根因在 `sync()`：用 `drawingStyles.childCount > 0` 判断样式卡是否可见，而 `drawingStyles` 是 ScrollView，其子 View 恒为 1（内容控件本身），与内容是否为空无关。橡皮擦/选择元素这类没有选项的工具因此显示一张白色空卡片。

修复：`ScreenshotDrawingControls` 暴露 `hasContent`（自身 childCount>0），`sync()`/`closeStack()`/`rebuildDrawingStyles()` 统一走 `drawingStyleCardVisible()`。深色化后即使判断失误也不会是刺眼白条。

## 图标返工（第二轮，按参考图逐枚核对）

第一版手绘近似被用户指出"改错了、排列不整齐"。改用参考图逐枚对照重画，并去掉参考图里不存在的装饰：

| 图标 | 第一版问题 | 现在 |
| --- | --- | --- |
| 添加 / 减少区域 | 正负号浮在两框之间，与前框重叠 | 双框重叠，正负号放在前框正中心 |
| 光标 | 实心箭头 | 改为描边箭头（参考图为描边） |
| 重新截图 | 相机 + 机身外侧回转箭头 | 机身内含回转箭头 |
| 曲线区域 | 正圆 | 不规则闭合曲线 |
| 自由手绘 | 纯云形 | 云形 + 右缘小圆 |
| 物理像素 | 四个实心方块 | 田字格描边 |
| 逻辑像素 | 大方框 | 收窄方框 |
| 主栏分组角标 | 每个工具组右下画 5dp 三角 | 删除（参考图没有；点右下角换组的命中区保留） |

第二栏按钮几何改为参考图的描边样式：36dp 方钮、4dp 间距、8dp 圆角、1dp 描边；未选中 `#3A3A3C`，选中 `#1677FF` 且图标转蓝。主栏仍用 32dp/8dp 节奏（与第一版一致，参考图同密度）。

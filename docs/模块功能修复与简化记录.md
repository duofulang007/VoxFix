# 模块功能修复与简化记录

2026-10-09。用户要求修复已有模块，剪贴板可添加；键盘类型只保留 9 键拼音、26 键拼音、全屏手写。随后明确简洁风格：剪贴板长按管理，减少常驻控件，并希望有输入习惯记忆。

## 已处理

- 剪贴板／常用语添加、编辑、删除、撤销与本地持久保存。每条只显示文字，短按插入，长按约 500ms 出现编辑／删除／设为常用语／复制；滚动移出阈值取消长按，防止误触。右键、Shift+F10 支持桌面操作。添加／导入／清空放入管理菜单，常用语顶部 ＋ 添加。系统剪贴板只在主动点击导入／复制时访问，不被动监控。
- 编辑以原文字身份定位，列表在别的标签页更新后不会因为索引变化覆盖另一条；新添加或编辑后撤销旧删除失效，避免恢复旧快照覆盖新内容。
- 修复数字页打开剪贴板后返回错误落到字母页；符号返回记住来源；点设置会滚动到设置区域；快速“全键盘”真正回到 26 键。
- 修复触摸滚动受根容器 touch-action:none 阻断的问题，剪贴板／候选等列表允许竖向滚动，按键与光标拖动区域保持自定义手势。长按菜单支持 Esc 关闭。
- 去除未接入的键盘类型及在线表情占位页；Emoji／颜文字保留，本地表情搜索可按“猫”“笑”“爱”等关键词筛选，不在中文系统组合输入中重建搜索框。
- 本地选词记忆：记录候选提交的码、字词、次数，两个命中后优先；全拼／九键分开计数。最多保留最近 2000 条，只在浏览器存储；关闭不应用和新增记忆，清空需确认。没有训练语音或手写模型。
- 全屏手写是真实离线单字识别，画布占输入框上方空白区，停笔约 650ms 请求本机服务；新笔／清空取消未决结果，选字后清画布。删除有笔迹时只清笔迹，避免长按连删正文。
- 服务改为独立隐藏后台进程，网页周期检查语音／手写状态，恢复连接后可重新就绪。服务仅监听本机，没有创建启动项或系统服务。

## 手写来源与环境

初步资料包含旧版 PP-OCR 模型规格，实际模型输入检查显示当前为 Melnyk-Net v2，输入 uint8 96×96×1、输出 3755 类，因此实现使用实际 v2 规格，未照旧文档误解码。

参考 [Feelime 当前 HandwritingEngine](https://github.com/feelime/feelime/blob/main/app/src/main/java/com/feelime/ime/HandwritingEngine.kt) 的模型接口；模型来自其 Gitee handwriting-v2 发布，字表来自配套 engine-data/handwriting/vocab.json。模型 SHA-256 为 `04bf65859482f2e9f4836fb872c5a881940a8f6f81bd0994542187617793e932`；字符表为 `83863afd12846c337c8880348f1a7e275450be87ba04cf17445cca3ffd0939bd`，均在加载时校验。

项目隔离环境新增 onnxruntime 1.31.0、Pillow 12.3.0，没有修改系统 Python 或 Windows 手写配置。笔画数据仅送本机，不保存轨迹日志。

## 检查结果

- 浏览器验证剪贴板：添加、编辑、刷新留存、删除、撤销均通过，测试内容已单独删除。简化版常驻编辑／删除按钮数均为 0；真实长按打开菜单，未误粘贴；长按编辑和管理菜单添加可用。
- 键盘选择恰有三项；网页实际画水平笔画后出现“一”等候选，选“一”写入输入框成功。
- 程序验证手写为空／越界／NaN、预处理形状及实际模型；PCM、会话和原文字／拼音／语音生命周期检查继续通过，既有官方语音样本仍产生 18 次更新与最终标点。
- 选词记忆单测验证：第一次不改变排序，第二次提前，不同输入模式隔离，序列化可恢复，非法次数被拒绝。
- 后台服务启动日志就绪，当前网页可连接语音与手写接口。

## 范围边界

手机触屏手感和个人真实笔迹识别率未做广泛评测；手写只支持常用单字，不能保证连笔／生僻字。系统剪贴板权限拒绝时使用手动粘贴入口；未主动读取用户系统剪贴板做测试。没有 APK，没有讯飞私有模型或完整个性化策略。

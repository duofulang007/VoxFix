## 最终界面与行为

- 移除新增的独立“结束”按钮，恢复原单环麦克风/×。×只收起联想、继续语音；原麦克风仍可结束语音，不新增另一套手势。
- 剪贴板共享编辑框只保留“取消 / 拆词 / 保存”。删除保存下面的“输入引用／更新记录／存常用语”和新增的保存成功提示；保存失败仍显示原因并保留草稿。引用与历史编辑的实际行为、语言与来源恢复均保留。
- 底部触控区域始终透明，不存在常驻或拖动时显示的整条背景。保留跟手短线；只有进入既有快速移动档时才出现56×12 CSS px的小胶囊，圆角为固定半径、无描边、无阴影、低透明度。精调不显示胶囊背景，松手后收起。夜间及减少动态效果均覆盖，不增加文字说明。
- 主滑轨仍只有左右移动，长按锁定/解除、自定义编辑框、八方向盘和宿主选区弹出全部保留。没有改变速度、手势阈值或输入法窗口高度。

## 滑轨消失的根因与回归

新增 `preview/cursor-feedback.test.mjs`，使用真实浏览器指针连续执行“拖动→松手→等淡出→再次拖动”，并在按住期间重绘。修复前明确失败：指示节点仍连接、内联透明度0.88，但实际透明度0；节点上有已完成且 `fill:forwards` 的淡出动画。

节点复用后，前一次松手的淡出动画仍压住下一次拖动的透明度。现在显示跟手反馈前取消旧淡出动画，再写入本次状态。回归覆盖淡出结束后重拖、淡出过程中重拖、重绘、夜间、减少动态效果；不靠强制整块重建键盘掩盖问题。

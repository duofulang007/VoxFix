# 滑轨锁定与右侧编辑框：交互约定与实现映射

更新时间：2026-10-13。范围：26 键中文键盘底部滑轨 + 右侧选字编辑框内的缩小滑轨。

## 一、一句话规则

**长按任一条滑轨 = 在「起点已锁定」和「自由移动」之间切换一次。**
两条滑轨共用同一套手势逻辑，区别只有尺寸和位置（键盘底部主轨 49dp 高、编辑框内小轨 54px 高）。

| 状态 | 拖动 | 长按 | 滑轨外观 |
|---|---|---|---|
| 未锁定 | 移动光标（11px/步，两侧 48px 内三档边缘续移） | 把当前光标钉成固定起点、进入框选、呼出右侧面板 | 灰线 / 灰字「移动光标 · 长按锁定起点」 |
| 已锁定 | 只调整选区终点（起点不动），二维拖选与续移照旧 | 把选区收成**活动终点**处的光标并解除锁定 | 浅蓝底 + 蓝线 + 蓝字「起点锁定 · 拖动调整终点」 |

- 「当前光标」= 有选区时活动的那一端（`selectionDirection==='backward'` 取 start，否则取 end）。
- 「活动终点」= 手指最后停住的那一端。反向拖选后它是较小的索引，**解除锁定必须落在它**，不能用 `max(anchor, head)`。
- 一次长按只切换一次；松手不重复触发；明显拖动（≥11px）先取消尚未触发的长按。
- 解除锁定的那一次长按到此为止：同一次触摸里继续拖动不再移动任何东西，抬手后滑轨恢复自由移动。

## 二、面板与锁定是两件事

- **收起面板 ≠ 解锁。** 面板只由两种方式收起：点击编辑框外（遮罩消费该次触摸，正文/光标/选区都不动，也不会按到背后的字母、删除或语音键），或改正文（输入/删除/剪切/粘贴）。
- 锁定只在本次输入会话内保留；收起后重新触碰滑轨，面板按原状态呼出（锚点、选区、文案一致）。
- 未锁定时面板留在屏幕上：上/下选段整体置灰并 `disabled`，复制/剪切在空选区时禁用。面板不再有「完成」按钮，页头只有「已选 N 字 + 全选」。
- 换输入框（`voxfixInputType`）、结束输入会话（`voxfixReset`）、正文让旧起点失效（任意改正文的按键）时安全清理锁定。

## 三、实现映射

| 位置 | 说明 |
|---|---|
| `preview/app.mjs` `lockSelection` / `beginSelectionAdjust` / `unlockSelection` | 锁定、锁定态调终点、解除锁定三个入口；`lockedNow()` 负责「换输入框/正文变了」时静默清理 |
| `preview/app.mjs` 滑轨 `pointerdown` | 读一次 `lockedNow()` 决定走「移动光标 + 长按锁定」还是「直接进入调终点 + 长按解除」 |
| `preview/app.mjs` `selectionEditor()` / `footer()` | 两条滑轨的 `.locked` 类、文案与 `aria-label` 都由同一个锁定状态生成 |
| `preview/style.css` `.selection-mini-track.locked` / `.cursor-zone.locked` | 全部用现有令牌（`--accent`、`--accent-soft`、`--func-bg`、`--muted`），日间/夜间/窄屏同一套 |
| `VoxFixImeService.kt` `gestureLock` / `gestureUnlock` | 原生锁定起点、解除锁定（`selectionDrag.head` 才是活动端，落点用它） |
| `SelectionDrag.kt` | 锚点/活动端/文本快照；`SelectionDragTest` 断言反向拖选后 `head` 是手指那一端 |

## 四、回归与验收

- 网页：`preview/selection-lock.test.mjs`（双轨长按切换、锁定调终点、反向活动端、解除后自由移动、重新定位再锁定、外部关闭不穿透、面板重新打开、断触/失焦清理、26 键几何不变）；`selection-editor`、`selection-drag`、`selection-direction`、`native-ime` 已按新语义改写。

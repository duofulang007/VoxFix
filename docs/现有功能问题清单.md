### 四、本轮踩到的环境/工具坑（重要）

- **Android WebView 的 JavaScriptInterface 方法无法被覆盖**：直接赋值与 `Object.defineProperty` 都无效（属性看起来可写可配置，取值仍回到 Java 方法）。⇒ 真机探针**不能**靠“替换桥接方法”屏蔽副作用；读宿主文本请用 `VoxFixIme.cursorPosition()` 回读（JS 侧 `voxfixCursor(position,total)` 回调可临时接管），验证桥接调用请改成断言宿主输入框内容。

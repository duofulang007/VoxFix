# 画笔端点触摸反馈

2026-11-05。用户反馈：手指盖住端点，按住后没有震动或可见确认，难以判断有没有抓住并接续。

**原版无此行为，以下是手机侧实现。** Snow Shot 固定提交 `afdc340b14e7f92a294a95c374d13ada0d8c7a82` 的 `free_draw_workflow.rs` 有 8px 最近端点命中/悬停反馈与 `continue_from`，没有 Android 手指震动、触摸起笔阈值或原生放大镜。本轮经用户明确授权做触摸适配，不记为原版逐像素复刻完成。原版全文保留在 `.android/snow-t22/reference/`。

## 行为

- 画笔模式下，可接续的平滑、未闭合笔画首尾显示白底蓝边空心圈（可见半径 4dp）。旧折线与闭合笔画不显示可接续提示。
- 手指隐形命中半径由原 8dp 扩到 24dp；最近端点优先、重叠同距离顶层优先。仅 `TOOL_TYPE_FINGER` 使用扩大热区；鼠标/笔保持精细命中。
- 命中时立即请求一次 `performHapticFeedback(GESTURE_START)` 并高亮端点；跟随系统触感设置，不新增权限、不强制开启震动、不在移动中反复震动。无需等待长按计时。
- 手指移动超过系统 `scaledTouchSlop` 才真正起笔；阈值内松手不改对象、不新增历史。保留按下位置到端点的偏移，扩大热区不造成起笔跳位；原对象 ID、样式与原顶点保留，一次撤销退回接续前。
- 使用 Android `Magnifier`，112×72dp、2倍、8dp 圆角；放在手指上方，顶部空间不足则移到下方，间隔36dp、窗口边距8dp。贴图画布较小时使用整个宿主窗口的可用空间，不把放大镜挤在手指下。
- 准星依据原生实际采样源坐标定位；源图在屏幕边缘被裁切时，准星跟着真实端点偏移，不假设端点总在放大镜正中心。
- 松手、取消、多指、换工具、撤销/重做、关闭与窗口分离均清理放大镜。端点提示和放大镜只属于交互层，不进入图片导出、工程或颜色采样快照。

参数是本轮手机适配初值，非原版桌面参数；真人 K60 手感仍需确认。

## 改动范围

- 新 `ScreenshotPenFeedback.kt`：端点圈、一次触感请求、原生放大镜、边缘准星与窗口内避让。
- `ScreenshotPenContinuation.kt`：手指命中与起笔阈值/偏移；普通精细输入保持原语义。
- `ScreenshotDrawingLayer.kt`：同一绘图触摸入口接线，生命周期清理；截图与贴图共同生效。
- 新 `ScreenshotPenFeedbackTest.kt`、`ScreenshotPenFeedbackChecks.kt`：窗口边界、手机触摸事件、震动请求次数、抖动/取消不入历史、原对象/撤销、提示不入导出；新增 `screenshot-pen-feedback` 真窗口检查入口，普通断言并入 foundation。

未改 preview、键盘、语音、模型、工程格式或任何用户数据；未自动提交/推送。

> 适用对象：VoxFix 截图工具全体交互（主栏 28 个动作 + 16 个辅助入口）。

**已确认的 3 条缺陷（真机复现，非推断）**

1. 水印「角度 / 间距 / 透明度」滑杆：拖动一次即被重建，不能连续拖；且每一步各压一条撤销。
2. 矩形单角圆角手柄：从一个统一圆角 6 的矩形开始拖某一角，其余三角变 0（直角）。
3. 删除带文字的序号：只删徽标，关联文字留在画布上（原版 `append_delete_dependencies` 会连带删）。

**已澄清的一条**

## 4. 流程诊断套件（新增，专测“正常操作顺序”）

源码：`android/app/src/androidTest/java/local/voxfix/debug/ScreenshotFlowAuditChecks.kt`
运行：`-e modelCompare screenshot-flow-audit`

它按「构造 → 绑定回调 → 框选 → 操作控件」的真实顺序驱动，不用手工点按，结果可直接对比：

| 检查 | 结果 | 说明 |
| --- | --- | --- |
| 框选前长截屏/录屏禁用 | PASS | `scroll=false record=false` |
| **框选后长截屏/录屏可用** | **PASS** | `scroll=true record=true`，证明上一轮“永久禁用”判断作废 |
| 水印滑杆在改值后仍是同一实例 | FAIL | `sameInstance=false`：面板在拖动中被 `refresh()` 重建 |
| APNG 被平台解码为动画 | FAIL（平台） | 自写 APNG 1409B/4 帧，`animated=false`；Pillow 生成的标准 APNG 同样 `animated=false`，说明是本机 `ImageDecoder` 不支持 APNG 动画，不是容器缺陷 |
| 单角圆角保留统一值的其余三角 | FAIL | `radii=[0,0,20,0]`，期望其余为 6 |
| 删除序号连带删除关联文字 | FAIL | `remainingTextObjects=1`，期望 0 |

前 3 条 FAIL 是**可执行证据**，修复后应转 PASS；APNG 一条按平台限制记录（Android 相册可能只显示首帧，分享到支持 APNG 的浏览器仍可动）。

**本轮已完成的真机操作**：重绑服务 → 调试广播进入截图 → 拖框选中 200 行长页 → 主栏显示两个层级（含长截屏/录制列）。其余工具参数的连续手势（滑杆、圆角、多指擦除）仍需按 §5 人工走查。

> 注意：截图窗口 90 秒无操作会自动回收（`expire`），手工走查时每一步都要触摸一次。

## 5. 手工走查流程（按控件）

每一项都按「步骤 → 预期」执行；判定填 `PASS / FAIL / 阻塞(原因)`。

### 5.1 入口与主栏（C00 / T01–T05）

1. **弧柄**：向内滑展开 → 出现「截图」「无线调试」两个径向按钮；反向滑/点空白收起；长按拖动换边，重开键盘后位置保留。
2. **截图入口**：点「截图」→ 0.5s 内出现遮罩与工具栏；首次进入有“轻点选区/拖框”提示。
3. **框选**：拖一个 ≥2×2 的框 → 出现角点与边框；拖动框内部移动；拖边/角改大小；点击空白重新框选。
4. **整屏**：无选区时点整屏 → 选中全屏且含系统栏；已有文字结果时不出现该按钮。
5. **关闭**：空选区/绘图工具/识别中/编辑态/翻译中五种状态点 × → 都只退出一次，不触发保存。
6. **保存**：框选后保存 → 进入图片剪贴板，缩略图与选区一致；重开工程后对象可继续编辑。
7. **分享**：系统分享面板收到 PNG；取消返回截图不丢失。
8. **复制文字**：识别后复制 → 剪贴板是纯文本，不含图片；原文/译文按当前展示层复制。
9. **显示原图**：识别后切换 → 只隐藏文字层，画布标注仍可见；导出仍含标注。
10. **撤销/重做**：画一笔→撤销→重做；连续改样式一次拖动只回退一步；编辑文字时撤销只作用于文字层。

### 5.2 画笔 T08

颜色（预设 + 完整调色板 + 滴管）、线型（实线/虚线/点线）、线宽、填充（含 4 倍纹理）、平滑/点稳定、端点接续、框外起笔、慢速画圆、快速折线、工程重开。
**重点**：从选框外起笔能画、导出只裁框内；滴管按住拖动取色，松手生效。

### 5.3 形状 T09

三种形状；描边色/线宽；填充开关与颜色；圆角按钮 0–83（点击回 6）；滚轮/上下拖动步进；四角圆角手柄。
**重点**：拖一个角只改该角，其余角保持原值（当前 FAIL）；Shift 等比属桌面专属，不做。

### 5.4 直线 T10 / 箭头 T11

直线 Straight/Curve、两端点拖动、线段中点插点；箭头 15 档首尾、比例 1.0–3.0、Straight/Curve/Elbow、锥形轴、虚线、空心款。
**重点**：短箭头两端头不重叠；曲线箭身不丢头；拐点拖动后仍闭合。

### 5.5 橡皮 T12 / 高亮 T13 / 聚光灯 T14

橡皮：8dp 半径、半透明预览、多指同擦只产生一条历史、不改底图。
高亮：画笔/矩形两模式、颜色 alpha 即透明度、宽度/边框。
聚光灯：五色 + 调色板、透明度、多个洞并集、一次撤销。

### 5.6 序号 T15 / 文字 T16 / 水印 T23

序号：五种类型、编号输入（无数字圆时禁用可见）、64 位、字号 6–256、字体、填充、关联文字与连接线、删除徽标连带文字（当前 FAIL）。
文字：字体搜索、字号 6–256 小数/滚轮、加粗、水平/垂直对齐、描边、填充纹理、逐行圆角背景、自然宽度、长文折行、键盘避让。
水印：文字/模板（`{text}`、时间）、模板存/选/删、字号 6–512、角度、间距、透明度、平铺、撤销、导出。
**重点**：水印三个滑杆要能连续拖（当前 FAIL：拖一格即断）。

### 5.7 选区与对象 T21 / T22 / A01–A12

加减选区（一次性模式、扣空退出）、矩形/折线/曲线/手绘、重新截图（保留文字草稿）、二维码标记开关、隐藏工具栏（原位恢复胶囊）、读数点按切 px/dp。
对象：框选/Shift、组移动/旋转/缩放、顶点/拖段、层级、对齐/分布（按钮启用按“对齐单元数”）、复制/删除、透明度、重置画布、吸附与绑定、Mixed、快速选择。

### 5.8 识别/翻译/识码 T18–T20 / T26

识别：行序、漏行、重复识别、失败保留旧文、格式化（保留/移除换行）、标点（半角/全角）。
编辑：跨行选择、IME 遮挡、撤销/重做、完成、保存重开。
翻译：语言选择/互换、流式输出、取消后立刻再翻译（当前会提示“上一次翻译还在进行”）、长文分段、模型未下载引导。
识码：自动识别、标记显隐、弹层复制/打开、复制后不关闭截图（手机侧差异）。

### 5.9 长截屏 T27

手动拼接（纵向/横向）、角落缩略图、拖边裁剪、继续滚动、直接保存、长图重开、取景框移动、固定栏不重复。

### 5.10 录屏 T28

选区（蓝框可调）→ 开始/关闭；麦克风/系统声/混音/分轨；暂停/恢复；旋转收尾；导出设置（清晰度/帧率）；GIF/APNG/WebP；录制中标注 12 工具；成品进 `Movies/VoxFix` 或 `Pictures/VoxFix`。

### 5.11 贴图 T24

置顶、移动、角/双指缩放、透明度、Scale 菜单（±10%、25/50/75/100、10–500）、旋转/翻转/重置、二次编辑不重复叠图、关闭。

# 离线优化计划与验收

开始日期：2026-10-09；最终电脑端验收：2026-10-10。用户授权：自行验收，通过后继续下一阶段。保留当前流式出字和按住空格交互；基础输入、识别与润色均离线。

## 已实施

- 拼音：保留 jieba 原有条目，补入固定版本雾凇基础词库中频率不低于 3000 的条目，增加日常口语；不再排除超过 8 字的词条。共有 425,870 个词音记录、420,839 个不同文本。
- 共享词条：拼音音节使用整数编号，全拼／简拼／九键在内存建立索引，不再打包重复的简拼词文。生成时不截断每码 60 条；候选栏最多 240 条，展开最多 2000 条。重复查询有缓存。
- 混输：支持全音节、首字母及 zh/ch/sh 声母混合。频率拼接仍无上下文语言模型，不能宣称达到成熟输入法的整句预测水平。
- 常用语：中文个人短语参与全拼、简拼和九键候选。古典名句、科技词语、跑步词语可以独立启用，并按中文内容搜索。当前三个小型词库是起步集合，不是完整行业库或名言全集。自动生成个人短语拼音使用逐字默认读音，多音字可能需要后续补充人工编码。
- 语音：保留原有采样、200ms 分片、流式模型及停顿规则；不添加热词时仍用原来的 greedy 解码。中文热词最多 100 条，每条 1–30 字，保存在当前浏览器，录音时传给本机；有热词时启用 modified beam search。热词不会训练模型，可能增加启动和识别延迟。英文热词尚未接入。
- 二次识别：相似度门槛由 0.6 提高至 0.85；英文词、数字、中文数词及否定词改变时保留流式结果，已经识别出的热词不允许被第二遍删掉。这是保守保护，不能验证任意人名或句意。
- 长语音：新增开始、暂停、继续、结束和取消。暂停关闭音频轨道并挂起采样，本机会话定时保活；有效录音仍限六分钟。主动取消恢复原文，处理错误或页面隐藏保留已经收到的转写。录音收尾有超时保护。
- 润色：Qwen3.5-2B Q4_K_M，非思考模式。独立本机进程，按需加载，单段不超过 600 字，携带少量前文，最多处理 12000 字；先预览再替换，可以撤销。原文改变后拒绝覆盖。异常、截断、保护规则不通过时不采用该段改写。空闲两分钟释放模型。

## 验收证据

- `preview/core.test.mjs`：文字、配置、选词记忆与取消语义。
- `preview/pinyin.test.mjs`：日常简拼、混输、个人短语、可选名句与领域词。
- `preview/voice.test.mjs`：分片队列、暂停继续、收尾及麦克风释放。
- `voice/test_*.py`：PCM 与热词边界、二次识别保护、润色保护、分段不丢字、评测 CER。
- `preview/candidates.test.mjs`：Edge 候选完整显示、鼠标和触摸滑动、320/360px、独立 HTML。
- `preview/workflow.test.mjs`：使用模拟录音接口验证页面流式出字、暂停继续、润色预览／替换／撤销及错误保留。
- `preview/live.test.mjs`：真实 Edge 页面 → 本机 HTTP 服务 → 已安装 Q4_K_M 模型 → 预览／替换／撤销完整链路通过，没有页面脚本错误。使用人工测试文本，不读取个人音频；证据见 `offline-polish-live.json` 和 `offline-polish-live.png`。
- `voice/polish_smoke.py`：真实模型两段人工短文本验收通过；第一次包含模型加载约 3.14 秒，第二次约 1.34 秒，重复赘词已消除，测试数字、否定词与英文名称保留。证据见 `offline-polish-smoke.json`。不能推导手机速度或所有文本都能正确保留原意。
- 模型空闲释放已经在运行服务中观察到，状态从 loaded=true 变为 false，installed 仍为 true；观察开始前已有一段空闲时间，因此记录中的 45.1 秒不是完整卸载等待时间。见 `offline-polish-idle.json`。
- 当前本地验收包括 12 个语音／手写／润色／评测单元测试，3 组 Node 自检、下载续传自检以及候选、模拟工作流、真实服务浏览器验收。Windows 沙箱临时目录曾导致下载自检权限错误，正常权限下复验通过。
- `voice/smoke_test.py` 与 `voice/http_test.py`：真实官方模型样本 10.053 秒，18 次流式更新；静音、取消及来源限制通过。结果见 `offline-voice-smoke.json`。这是电脑样本，不能证明个人语音准确率提升。
- 本轮电脑 Node 测量：词库解析及建索引约 645ms；所测简拼／混输查询约 0–18ms；首次九键查询约 218ms。不是手机性能承诺。

## 下一阶段与尚未验证

1. 使用真实转写错误建立样本集。当前没有用户授权提供的音频和准确参考文本，因此不编造准确率提升数字。可用 `voice/evaluate.py 清单.json 结果.json` 处理明确指定的 16kHz 单声道 PCM16 WAV；它不会录音，输出包含转写内容，只在用户指定位置保存。
2. 润色模型已经安装并经整文件 SHA-256 校验，实际模型和真实服务页面验收通过。后续仍需较长真实转写、方言及个人术语评测，结果不能替代人工判断原意。
3. 2026-10-10 已按用户要求安装项目专用官方 Android 15 模拟器与 adb，按 K60 截图配置屏幕。第八阶段现可进行安卓网页交互验证，详细结果见 `安卓模拟器与K60测试方法.md`。工程仍没有原生 Android IME APK；模型在电脑运行，K60 真实系统输入框、ARM64、HyperOS、内存、发热与耗电仍待原生接入和真机验证。

## 来源与可重建性

- jieba 0.42.1、pypinyin 0.55.0：原项目固定版本。
- 雾凇拼音：[原仓库](https://github.com/iDvel/rime-ice)，固定提交 `da1fbe602e38f26db846fa10120ee64c2b0324c0`；原始许可保留在 `licenses/rime-ice-GPL-3.0.txt`。这里使用生成后的词库数据，未接入 librime 引擎。下载与校验见 `tools/setup_lexicon.py`。
- [Qwen3.5-2B](https://huggingface.co/Qwen/Qwen3.5-2B)，[Unsloth 量化版本](https://huggingface.co/unsloth/Qwen3.5-2B-GGUF)，固定版本及 SHA-256 见 `tools/setup_polish.py`。
- [llama.cpp](https://github.com/ggml-org/llama.cpp)，电脑 CPU 运行库固定 b11529，SHA-256 同样在安装脚本中。安卓运行库需要单独构建，不使用 Windows 二进制。

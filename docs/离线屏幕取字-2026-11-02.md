# 离线屏幕取字（2026-11-02）

## 交付范围

本日后续已按用户确认改为[弧形工具箱与可编辑结果](屏幕取字弧形工具箱-2026-11-02.md)。当前入口、按钮与编辑行为以该文档为准；下文48dp方块、只读选字与早期全局流程结果属于改版前记录，不能作为新交互通过的证据。

同一个 APK 内新增独立无障碍服务 `ScreenTextService`。输入法功能菜单提供开启/关闭；
应用主页也有「屏幕取字」设置入口。首次需要用户在系统设置手动授权，代码不替用户开权限。
开关默认关闭，启用后独立于键盘和输入框存在。无额外 App、悬浮窗授权、Root 或 Shizuku。

点击 48dp 贴边「取字」按钮 → 隐藏入口 → 按需截图 → 定格画面上显示识别结果。
长按正文使用系统原生选字手柄，支持跨行、滚动和全选；自带复制按钮与系统选字菜单的复制均复制后退出，回到原页面。
「框选」在同一张定格图上重新识别所选区域，不重新采集变化中的画面。
拖动入口可换边、调整高度；位置按屏幕比例持久化。

返回、退出、复制完成、关闭功能、锁屏、服务销毁、旋转/配置变化均结束当前会话。
90 秒无触摸自动释放截图，触摸会延续会话；OCR 单任务且持有独立输入图，退出不等待识别，迟到结果不再显示。
服务销毁后入口随系统重新绑定恢复。截图从不写入文件；没有连续扫描、历史、搜索、翻译或分词。
受保护画面遵循 Android 截图限制。`minSdk=30` 不变。

## 技术与上游

参考 [XGesture 固定版本](https://github.com/qpst4/XGesture/tree/7a0dfde12343ef7180b331380f244b37fa5a041e)
的 README、第三方说明、文件级来源、取词协调器/节点提取和系统原生选字实现。
上游主许可 AGPL-3.0，取词部分标明 GestureEVO GPL-3.0-only 来源；Nova Text/FooView 属交互参考。
没有将其代码、视觉资产或手势框架搬入当前仓库，没有修改 FV 源码。

现有项目没有全局悬浮服务，只有键盘窗口；因此新增独立服务，而不把全局入口挂在 IME 生命周期。
仅使用 Android 截图及原生 TextView 选区，识别固定为随包内置
`com.google.mlkit:text-recognition-chinese:16.0.1`，配套 AndroidX 配置。
不采用仅依赖 Play Services 首次下载模型的版本。

选择统一截图 OCR，未加入「节点有文字即成功」的分支：页面上的按钮/标题有文字，不能证明图片、视频里的正文也已取出。
因此服务不申请 `canRetrieveWindowContent`，不读取界面节点，只订阅窗口状态来处理锁屏/入口恢复。

ML Kit 可离线运行，但 SDK/模型不是完全开源；官方说明识别图片和文字在本机处理，SDK 可能发送使用/性能指标。
这项说明同时放在功能设置页和 APK 内 `assets/licenses/screen-text/UPSTREAM.md`。
依赖的官方 POM 标明 ML Kit Terms of Service；没有更改现有项目整体许可或公开发布。

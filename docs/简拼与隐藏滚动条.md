# 简拼与隐藏滚动条

2026-10-09。用户指出数字页左侧符号栏应可滚动但不显示滚动条，同时询问用词组每字首字母输入的方法并要求支持。

这种方式叫简拼，具体为首字母简拼；[搜狗官方帮助](https://pinyin.sogou.com/help.php?list=3&q=2) 使用这一术语。模糊音是 z/zh、n/l 等音节差异的容错，两者不是同一功能。

## 实现

- 数字页 `.number-strip` 保留 overflow:auto，使用 scrollbar-width:none 与 WebKit 隐藏规则，滚动区域不缩小、不改成 overflow:hidden。
- 词库生成时对每个词组按各字拼音首字母建立索引，按原词频排列，保留每码最多 60 项；生成 69,873 个简拼码。
- 26 键中文候选同时查询全拼与首字母简拼；无需新模式或新开关。字典完整匹配优先，简拼匹配其次，原前缀和基础拼接保持兼容。
- 简拼新增索引与词库一并保存在本地，独立 HTML 也内嵌，不向外部服务查询输入内容。
- 已学习的全拼字词若属于简拼候选，可按同模式累计选词偏好提前；全拼／简拼和九键仍隔离，不清空已有选词记录。

## 验证

词库生成自检和 Node 测试确认 zg→中国、srf→输入法、zdy→自定义，大小写兼容，原全拼、带分词符九键仍通过。同模式跨全拼／简拼的排序记忆测试通过。

浏览器实测 zg 和 srf 出现相应候选；没有点选测试词，以免污染用户选词记忆。数字符号条视口高 163、内容高 342，隐藏滚动条后滚轮使 scrollTop 从 0 到 179，内容可滚动。

仅新增词库内词组的首字母简拼；完整模糊音、任意全简拼混输和讯飞私有预测排序尚未实现。

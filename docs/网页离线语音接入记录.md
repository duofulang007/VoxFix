# 网页离线语音接入记录

日期：2026-10-09。用户确认先接网页真实语音，暂缓 APK，交互细节后续调整。

## 需求与实现

沿用已有需求文档：中文、免费、本地离线、边说边出字、轻微纠错、自动标点，长按空格调用。网页声音在当前电脑处理，尚未做 Android 手机运行版本。

链路：浏览器 getUserMedia → 16kHz 单声道 AudioWorklet → 每 200ms 浮点 PCM 分片 → 本机服务 → Zipformer 中英流式 → 停顿或停止后的 Paraformer 二次识别 → CT-Transformer 标点 → 原输入位置更新。选区替换与取消恢复复用已有文字操作。

为保持轻微纠错，第二遍结果需与原文有至少 0.6 的字符相似度，且英文词序列一致；否则保留第一遍。该规则不代表识别置信度，也不承诺修正所有错误。当前无需大语言模型，不润色或删改口头语。

原长按空格、上滑取消、点击空白取消入口保留。录音期间暂时禁止编辑输入框，避免异步结果覆盖用户新输入；取消、无结果或失败恢复录音前文字。放开空格会冲刷剩余采样并关闭麦克风，再等待最终结果。

## 本地数据与依赖

运行环境在项目 `.venv/`，没有修改系统 Python。版本：sherpa-onnx 1.13.6、NumPy 2.5.3。识别使用 CPU。

模型来源及固定归档校验值来自 [Feelime 官方安装脚本](https://github.com/feelime/feelime/blob/main/scripts/setup-assets.sh)，下载来自 [sherpa-onnx 官方发布](https://github.com/k2-fsa/sherpa-onnx/releases)。三个归档均通过 SHA-256 校验，校验值记录于 `tools/setup_voice.py`。模型选用文件合计 279,860,897 字节，约 266.9 MiB；下载归档合计 489,603,156 字节，另行留作校验缓存。

服务只监听 127.0.0.1:18743，不提供公网或局域网访问。不保存音频和识别文本日志；输入只在浏览器会话与服务内存中。录音请求要求本机页面 Origin 和正确 Host，录音会话使用随机标识，分片大小、采样合法性、时长与过期会话有校验。单次最长六分钟。

下载曾遇到直连失败，随后仅在下载命令中使用系统已配置的本地代理，未修改持久网络配置。

## 验证结果

- 五项后端自检通过：PCM 校验、文本间距／保守修正、流式到最终结果、静音不进入二次识别、加载状态与会话数量限制。
- 前端录音生命周期测试通过：采样队列、尾部分片冲刷、最终结果、关闭麦克风、取消后不更新文字。
- 已有文字／光标／布局测试通过。
- 官方 test_wavs/0.wav（10.053 秒）实际模型测试产生 18 次不同文字更新，并得到带标点最终文本；0.5 秒静音无文字。详细原始结果见 `offline-voice-smoke.json`。测试音频包含中英混说，存在识别错误，不是准确率基准。
- 本机 HTTP 链路用相同音频再次得到 18 次更新；非本机页面 Origin 被拒绝，取消后的会话不再接受采样。
- 浏览器页面确认离线服务就绪；“启用麦克风”成功；长按空格实际开启录音、松手结束，无语音时原文字未变，控制台无错误。

## 尚未验证

# 讯飞小米版交互对照与修复

日期：2026-10-10。对照手机已安装的 `com.iflytek.inputmethod.miui` 8.1.8322，K60 Android 15，1440×3200、560 dpi。普通讯飞包与小米版均保留。

## 依据与边界

对照使用当前手机截图、在 VoxFix 空白试用框中操作官方键盘取得的固定文字截图，以及已安装 APK 的公开布局/符号配置。可读取这些界面和打包资源，不能据此声称取得官方私有源码。当前用户实际界面优先于 APK 默认布局；常用符号顺序可能受使用历史影响。

临时截图、官方 APK 和测试包均在忽略目录，不提交。没有读取短信正文、日常录音或转写用于分析/训练。早期坐标测试未确认前台，误触了桌面信息入口，不能记作键盘通过；随后加上自有试用页前台校验。最终用于呼出试用框的临时独立探针只查找自有应用的 EditText 并执行点击，结束不关闭 VoxFix，不用桌面坐标。

## 布局与内容

- 官方键盘从 y=1972 到屏幕底部，约1228px/351dp。2026-10-11 用户取消尺寸/背景自定义要求后，351dp 固定应用于旧配置、导入配置和默认设置；原先“不覆盖自定义尺寸”的规则已撤销。
- 对齐字母行间距、中行缩进、底排符/数字/标点/空格/中英文/回车宽度比例，以及数字页两侧61dp宽度。
- 对齐功能键字号、字母/数字字号、工具栏图标尺寸、底部图标横向位置及离底距离；补齐边框与圆角。
- 候选默认采用3个最小可见位置、22px字体；保持完整文字和横向触摸浏览，不截断长候选。
- 修正中英文角标分别显示对应内容。补齐现有中文、英文、网址三类的公开符号列表；常用符号按当前手机截图排列。没有新增完整官方账户/联网功能或另外扩展20类符号面板。
- 符号网格保持约五行高度，内容更多时滚动；分类区四项成组、下方独立锁定/删除和返回，常用页末尾尖括号占两格。

## 检查记录

网页回归包括数字回调保持、触摸重复删除/松手停止、长按字母默认输入/拖选、符号锁定及返回、括号光标、输入类型变更、语音手势与原有拼音/编辑/录音生命周期。安卓已有14项单元检查与 APK 构建通过。

K60 真实编辑框检查使用 `preview/native-ime-device.test.mjs`，固定文字检查后清理，保留中文键盘；不在聊天或短信里插入测试文字。该检查通过自有 WebView 的触摸接口驱动按键并读取真实 InputConnection 结果，不能替代真人手感验收。完整像素一致、全部工具页和全部 App 仍不宣称1:1通过。

随后用户发现显示数字页、实际输入26键，现场确认屏幕与DOM不同步。增加一处原生绘制就绪回调后，三次数字/字母往返的实际截图键数一致；断开测试后保持26键，试用文字保留。本轮最终安装摘要及检查边界以《USB真机验收》最后一节为准。

SDK 行为依据：[同一输入框 restarting 的生命周期](https://developer.android.com/reference/android/inputmethodservice/InputMethodService)。

## 2026-10-11 尺寸与背景固定

用户报告自己把键盘大小调乱，明确要求这一块按官方固定、不再提供自定义布局。现场读取到旧保存值：高度321、字号25、横向间距9、圆角11，确实偏离官方截图基准。

固定值集中在 `preview/core.mjs` 的 `keyboardGeometry`：高度351dp、字母字号22、横向间距4、圆角7、候选字号22/每屏参考3个、背景 `#edeff2`。横向间距从此前默认6修正为4，依据当前官方截图顶行白色/边框区域的宽度与间隔；背景截图实测 RGB 为 `[237,239,242]`。原生和网页共用同一组按键尺寸样式。

删除尺寸/字号/间距/圆角/背景调整控件，设置页改称“键盘设置”。读取旧设置时只纠正固定几何字段，保留其他字段；导入旧文件也无法覆盖固定值。工具栏、剪贴板、选词记忆等功能设置继续保留。工具栏关闭全部图标时仍保留同样高度；剪贴板候选替换顶部栏，不再多挤占一行而缩小按键。

安装后 K60 实测：键盘宽411.4286 CSS px、高351.0000 CSS px（560dpi/3.5倍）；Q键宽36.5402、高52.0000，字号22px，横向间距4px，圆角7px，背景 RGB `[237,239,242]`；26个字母键、尺寸/颜色调整控件0个，旧保存值已自动纠正。实际截图 `.android/fixed-layout-k60.png` 与官方截图的键盘顶部、背景高度及按键尺寸对照。此记录限定尺寸与背景，不把全部图标/字形/页面认定为完整像素1:1。

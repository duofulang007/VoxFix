# 输入体验六项改善

2026-11-02。按用户要求落实[体验评审](archive/design/输入体验评审与衔接建议-2026-11-02.md)的六个方向；外部来源见[调研记录](archive/design/输入体验外部调研-2026-11-02.md)。保留原有未提交的呼出可见性及英文候选竞态修复，未更换模型、词库或键盘架构。

同日后续纠正：用户要求移除独立“结束”和保存附加说明，并修复重复拖动时反馈消失；滑轨不铺整条背景，只在快速移动档显示小范围胶囊。当前界面、最新产物与验证见[后续修正](滑轨反馈与界面精简-2026-11-02.md)，下方构建哈希为本轮较早版本的历史记录。

## 最终行为

1. **常驻语音衔接数字与符号。** 数字/符号页不再取消常驻语音会话；通过既有 `selectionEditing()` 暂停机制固定已显示草稿并阻止迟到送字。停留在这两类页面时保持暂停；回到字母页后，还须等待选区、拼音组合及候选都结束，再按原有400ms空闲条件恢复。录音中临时打数字、补符号不再需要重新点开麦克风。空格按住说话和切换其它工具页仍按原有结束/取消规则处理。
2. **主键盘候选更新保留字母节点。** 主键盘在页内容改变时按生成的顶层内容比较，只替换变化的部分；稳定字母区不会因候选变化重建。比较的是生成内容，不把按压、滚动、动画等运行状态误当作内容差异。剪贴板等面板沿用原更新路径，避免改变菜单退场行为。原生拼音缓存、候选召回数量、展开分批加载和手机原生横滑惯性都保留。
3. **常驻语音保持原单环入口。** 依后续用户纠正，撤销新增独立“结束”；×仍只收起联想、继续语音，原麦克风负责结束，不增加控件或新手势。原有横屏无底栏约定不变。
4. **剪贴板编辑恢复来源。** 保留取消/拆词/保存三个按钮，按用户纠正删除保存下方附加说明和新增成功提示，失败继续保留草稿。局部编辑切换的输入语言/布局不再污染宿主偏好；引用取消时恢复原组合、候选条横向位置及展开引用列表，历史编辑取消仍恢复原列表滚动位置。引用不改历史，历史编辑不向宿主插入正文。
5. **高频拖动视觉按帧合并。** 同一帧内多次滑轨移动只绘制最后一个指示位置；导航及宿主选区确认仍逐步处理，不跳过、不合并文字操作。工具栏长按开始时固定命中几何，拖动高亮按帧更新，松手先处理最后落点；失焦、取消和尺寸改变都清理拖动态。
6. **补齐完整任务回归和可重复测量。** 新增 `preview/input-experience.test.mjs`，覆盖连续输入、语音夹数字/符号、独立结束、窄屏命中、滑轨同帧绘制、剪贴板编辑取消及引用来源恢复。浏览器记录按键到下一帧的时间和字母区重建次数，原始记录只在忽略目录；没有日常正文/录音采集或调试面板。新增联想仍显示时直接停止的回归。

## 测量口径与结果

使用桌面 Edge、393px 宽本地测试页、20次自动指针输入。修改前字母区重建20次，修改后0次；一帧内24次滑轨移动的指示区几何读取合并为1次，松手无残留拖动态。

输入抬手到下一帧的时间在几毫秒内波动，本轮没有证据证明手机触摸延迟下降，也不使用单次浏览器样本推导百分比收益。`--baseline` 只跳过新行为断言，用于切换到旧代码时记录旧版数据；普通运行必须满足新行为断言。

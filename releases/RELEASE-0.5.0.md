## VoxFix 0.5.0

首个公开版本。

### 本次更新

- **二级页统一外壳**：截图设置、工具栏布局、拼音词库、语音纠错词典、试用键盘全部迁移到统一页头与卡片结构；截图设置从 17 个控件 + 900 字说明收敛成「权限 / 截图 / 离线翻译」三张卡。
- **弧线一键恢复**：首页与屏幕页新增「恢复贴边弧线」，弧线不显示时不用重配系统设置。
- **外壳视觉 v2 与交互动效**：钢蓝 accent、18 圆角无描边卡片、页签 220ms 淡入上浮、开关 170ms 回弹、就绪环 520ms 扫过。
- **开发者工具与用户界面分离**：关于页「当前版本」连点 7 次开启开发者模式，默认关闭。

### 安装

下载 `VoxFix-0.5.0.apk` 直接安装。

- 包名 `local.voxfix.debug`，与旧版一致，**可直接覆盖安装**，词库、剪贴板、设置全部保留
- 首次安装需在系统弹窗里允许「安装未知应用」
- versionCode `5` / versionName `0.5.0`
- 大小 456,641,342 字节（435.5 MB）
- SHA-256 `b6dec4062d93133017c8ab7d5d82b6cba2ffc8ace82142d9ed4174a5e8996e4c`
- 最低系统 Android 11（API 30），仅 arm64-v8a

### 校验

```bash
sha256sum VoxFix-0.5.0.apk
# b6dec4062d93133017c8ab7d5d82b6cba2ffc8ace82142d9ed4174a5e8996e4c
```

> `manifest.json` 是应用内更新使用的版本清单，普通用户无需下载。

## VoxFix 0.5.2

**这是一版必须升级的修复版。** 0.5.1 的本地备份有一个致命缺陷：卸载重装后，备份列表会变成空的。

### 修了什么

Android 的分区存储会给每个通过 MediaStore 创建的文件打上 `owner_package_name`。**App 卸载时这个字段会被置空**，重装后的新实例不再拥有那些条目：

- 文件本身**不会被删**，仍然躺在 `Download/VoxFix/`
- 但媒体库按 owner 过滤，新安装的 App **查不到**这些条目，也就点不了「恢复」

0.5.2 增加了一条不依赖所有权的路径：备份页里的 **「从文件恢复」**。它走系统文件选择器，你亲手选中 zip，授权即成立——无论有没有卸载重装都能用。

### 卸载重装后的正确步骤

1. 在「设置 → 数据 → 本地备份 → 从文件恢复」
2. 文件选择器里：左上角菜单 → **下载内容** → **VoxFix** → 选中 `VoxFix-<时间>.zip`
3. 看到「词库 N → M 条…剪贴板补回 K 项」即恢复成功
4. 回键盘打几个字，确认原来养出来的词还在

「已有备份」列表在重装后可能为空，这是系统机制，不是备份丢了——按上面第 2 步手动选即可。

### 其它

- 修复恢复摘要的计数错误：之前文件已存在时会报「剪贴板补回 0 项」，但索引其实已经补进条目
- 0.5.1 已有的内容保持不变：本地备份（词库 / 语音词典 / 剪贴板图片 / 截图工程）、语音词典导入导出、检查更新失败提示改人话

### 安装

下载 `VoxFix-0.5.2.apk` 直接安装。

- 包名 `local.voxfix.debug`，可直接覆盖安装，数据全部保留
- versionCode `7` / versionName `0.5.2`
- 大小 454,052,338 字节（433 MB）
- SHA-256 `48dfea004f2dab4aeedac792d4cc52f9bee431a922dabd1493676f0bbb8d12a1`
- 最低系统 Android 11（API 30），仅 arm64-v8a

> `manifest.json` 是应用内更新使用的版本清单，普通用户无需下载。

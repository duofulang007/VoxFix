## VoxFix 0.5.3

**备份补全版**：0.5.2 只备份了词库、语音词典与截图，这一版把剩下所有用户数据都补齐了。

### 备份现在包含什么

| 内容 | 说明 |
|---|---|
| 拼音词库 | 词频、自造词、rime 迁移数据 |
| 语音纠错词典 | 词语 + 错法 |
| 图片剪贴板 + 截图工程 | 含 `document.json`，恢复后仍可继续编辑 |
| 电脑推送的剪贴板历史 | `clipboard-import` |
| **文本剪贴板记录** | 新增：自动累积的复制历史 |
| **常用语分组** | 新增：全部分组与条目 |
| **键盘外观设置** | 新增：高度、字号、配色、候选数、工具栏、夜间模式 |
| **常用系统设置** | 新增：屏幕取字、截图配置、模块开关等 8 项 |

「电脑」来源标记（pcClips）也一并备份。

### 卸载重装后的操作

1. 文件管理 → 下载 → 点 `VoxFix-0.5.3.apk` 安装
2. 设置 → 数据 → 本地备份 → 从文件恢复 → 选 `Download/VoxFix/` 里的 zip
3. 摘要里会看到：词库、词典、剪贴板、**文本剪贴板与常用语（键盘下次弹出生效）**、**N 项设置（完全退出 VoxFix 后生效）**

从文件恢复现在会**直接定位到备份目录**，不用再在文件选择器里点三层菜单。

### 恢复语义（不变）

- 词库：合并取最大词频，不清空
- 文本剪贴板与常用语：**并集合并**——本机新复制的保留，备份里的补进来
- 图片剪贴板：按 id 去重，本机已有的不覆盖
- 键盘外观：备份值覆盖本机（下次键盘弹出生效）

### 安装

下载 `VoxFix-0.5.3.apk` 直接安装。

- 包名 `local.voxfix.debug`，可直接覆盖安装
- versionCode `8` / versionName `0.5.3`
- 大小 454,136,404 字节（433 MB）
- SHA-256 `696042f0b41732273f75c04dfa1b21f9bbdede1f96c2de88537c45e44a3d6c66`
- 最低系统 Android 11（API 30），仅 arm64-v8a
